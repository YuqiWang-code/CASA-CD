# 四专家动态变化检测：调研与探索方案

2026-10-28。任务：普通RGB、全监督二值RSCD，LEVIR/SYSU/WHU/CDD；控制推理成本，先验证模块有效性。代码起点为`models_v1`中的主线副本。稠密动态融合已实现，训练安排见[Run1](../../train_scripts/CASA-MoE/Run1/README.md)，正式精度待完成实验。

## 结论

建议采用**共享骨干与TAR底座，原TAR作为基础专家，双曲/欧氏上下文与频率处理作为三种条件修正**。四条路径输出相同尺度、相同64通道的特征；路由决定局部区域采用哪类修正，或保留原TAR结果。

先以稠密软门控验证互补性，再做区域Top-2的真实条件执行。第一阶段承担归因对照，第二阶段承担减少实际执行量；不把四路先全算再乘稀疏权重作为加速实现。本文中的设计是本项目待验证方案，文献提供方法依据，不代表已证明四库提升。

## 当前代码与四专家的对齐

当前`TARStage = TemporalRep1x1 + SiLU + RepLocalBlock`，直接处理A/B；H/E模块则处理已经融合的四尺度T。两者所处层次不同，不能把现有三个完整模块原封不动并排后求和。

保持完整TAR为共享底座，可保留现有CTRL结构，减少共同结构改变带来的混淆。原TAR专家直接提供该结果；另三条路径输出对该结果的修正。四个专家不是四个独立的骨干或四次TAR。

```text
RGB A/B
   |
共享 MobileNetV2 四尺度
   |
共享 TAR：双时相融合与局部细化 → T1,T2,T3,T4
   |
   +-------------- 四条候选路径 ----------------+
   |                                           |
   | E_TAR = T                  原局部变化结果 |
   | E_H   = T + γ·Δ_H          双曲Q/K检索     |
   | E_E   = T + γ·Δ_E          欧氏Q/K检索     |
   | E_F   = T + γ·Δ_F          低高频修正      |
   |                                           |
   +--- 内容路由 π_TAR,π_H,π_E,π_F ------------+
   |
Y_s = T_s + γ_s·(π_H Δ_H + π_E Δ_E + π_F Δ_F)
   |
DCR → 共享预测头 → 二值变化图
```

四个π非负且和为1。π_TAR对应保留原TAR结果，不需要另算一遍TAR。该式等价于对四条候选特征加权，不额外重复叠加输入T。

### 四类专家的明确分工

| 路径 | 处理内容 | 必须验证的价值 |
|---|---|---|
| 双曲QKV | 完整空间Q检索压缩跨尺度KV；几何组织变化上下文 | 是否纠正了欧氏专家未纠正的漏检/误报，而非仅有另一组权重 |
| 普通QKV | 在欧氏空间检索同预算的上下文 | 是否对双曲的径向匹配限制形成有效补充 |
| TAR | 保留共享TAR的局部双时相结果，无额外全局改写 | 是否在背景、细边界或上下文不可靠区域承担合理回退 |
| 频率 | 低频区域结构与三方向高频分别处理，再重建修正 | 是否保留小目标/边界，同时避免放大纹理、阴影和轻微错位 |

H/E先统一检索宽度与KV预算，再比较距离建模差异。首版建议1头32维、相同448个内容原型，复用一次LN、guide及原型池化P；各自保留Q/K和内容输出投影。448是从当前双曲起点延续的比较预算，后续以相同协议比较224/448，不能仅凭token数断定精度或耗时。

不直接复用当前H/E包装器中的局部高通、内部残差、gamma和采用门控：空间局部处理已由TAR承担，频率处理由频率专家承担，采用决策统一交给MoE路由。保留H/E的相对内容读出`AV−V_query`作为修正候选；只在MoE外层保留一套零初始化γ，投影正常初始化。研究含义从“两个完整模块竞争”变成“在同一底座上选择不同变化证据”。

### 高频专家

```text
T_s → 单级Haar DWT
        ├─ LL：低频结构 → 轻量DW/PW处理
        └─ LH/HL/HH：三个方向高频 → 轻量子带处理
                         ↑ LL语义作为调节条件
             ↓ 保留符号、方向与空间对应
           IDWT重建 → 64通道频率修正 Δ_F
```

高频不是变化标签。边缘、屋顶纹理、阴影边缘与配准误差均可能落入高频；低频也可能承载光照/季节漂移。低频条件用于调节高频采用，不设置统一放大量。三方向子带保留有符号系数，不先取绝对值当作重建内容；绝对值/能量仅用于诊断。频率分支仍为一个专家，低高频不是额外增加的第五、第六个专家。

单级Haar优先于整图FFT作为首版，因为它保留局部支撑与可逆的空间对应，也便于后续区域执行。下采样小波对平移敏感，必须检查1–2像素位移是否导致高频误报；增加边界重叠、替换分解方式或增加对齐组件的依据应来自该结果。

## 路由与轻量化

第一阶段使用每尺度共享的小路由器：LN(T) → 1×1(64→16) → SiLU → 1×1(16→4) → softmax。64通道下共1108个参数，不含共享LN；输出为每个空间位置的四个权重。暂不输入数据集编号，不将LEVIR固定分配给某个专家。

该阶段四路按需构造但全部执行，是**稠密动态融合**。它检验动态选择是否优于固定等权，不用于宣称降低激活计算。H/E共享池化与guide减少重复开销，但两个距离检索仍需分别计时。

第二阶段在第一阶段确认互补后，把相邻query组成区域，对区域路由Top-2。采用Top-2保留两类证据及选中权重的可训练相对比例；不从Top-1开始强制排他。实现需满足：

- H/E只对选中区域的Q执行距离与读出；跨尺度KV来自全部特征，不因query未选中就丢失上下文。
- 不被选中的query保留TAR结果；每个像素都有预测路径，不使用容量溢出丢token。
- 频率/局部操作考虑邻域与小波块边界；不能把全图卷积结果切片当作已经节省了计算。
- 在目标GPU、batch1及实际尺寸下比较含分派/索引/重建开销的延迟。区域路由仅是可能减少计算的实现方案，速度结论由测量确定。

TAR/DCR的线性分支继续按原机制折叠；输入相关路由、双曲距离、softmax及频率调节不能整体等价折叠成一个固定卷积。总参数、可学习参数、实际执行算子、推理显存和batch1延迟分别报告。

## 对四库的工作假设

| 数据集 | 现有分析关注点 | 路由应验证的行为 |
|---|---|---|
| LEVIR | 稀疏建筑变化、小建筑及规则轮廓 | 边界处频率修正是否有效，背景是否保留TAR；上下文不应抹掉小建筑 |
| WHU | 建筑尺度跨度与密集邻接边界 | 高频和局部证据是否改善贴邻建筑，语义上下文是否补足大建筑内部 |
| SYSU | 多种地表变化、纹理和植被干扰，历史后期泛化不足 | H/E是否产生真正不同的纠错；路由是否只按训练背景偏好某专家，召回是否持续下降 |
| CDD | 季节、光照及外观差异 | 频率分支是否抑制伪变化而非增强纹理，上下文是否保留真实变化 |

这些是本项目的待验证假设，不预先按数据集硬分配专家。统计应在同一数据集内部按变化/未变、边界/内部、小目标、误报/漏检分组。

## 先回答什么，再决定是否扩大实验

起点使用同一骨干、TAR、DCR、增强、损失与训练预算。结构设计和选样使用train/val；若后续正式仍沿用每epoch test选模，报告明确注明test参与选模。探索结果与Run6正式结果分开管理。

建议按顺序比较：原CTRL；单独H/E/F修正；四路固定等权；四路动态软路由；固定权重下逐个移除专家与路由打乱；最后是相同初始化/协议的真实区域Top-2。先在LEVIR和SYSU验证建筑细节与复杂背景，再扩至四库；稠密阶段与稀疏阶段不能混为同一实现。

若动态路由不优于固定等权，优先审查路由学习与专家幅值；若去掉某专家不降反升，不能仅凭其路由权重大就保留；若H/E输出高度相同，先解决表征冗余，而不是再加专家。不同几何的意义由相同预算的度量替换与纠错差集确认，不能把整条双曲路径收益全部归给度量。

### 关键风险与观测

- **身份项重复**：专家完整输出和外层残差只保留一份T，使用上述等价式。
- **双重门控/零初始化**：避免内部gamma、外层gamma同时将同一修正置零；区分允许的第一个batch零专家梯度与后续持续无梯度。
- **背景占优**：总体TAR路由高并不自动是塌陷。分别看变化、未变与边界的专家使用，首版不强制四个异构专家全局均匀负载。
- **幅值冒充选择**：记录`RMS(γ·π_e·Δ_e)/RMS(T)`、专家输出相似度及移除后的损失/F1变化，路由权重不是实际贡献。
- **高频干扰**：看边界F1和误报/漏检，同时用train/val上的亮度、轻微位移、纹理干扰检查；不能仅看可视化更锐利。
- **专家冗余与过拟合**：跟踪H/E纠错交集、方向/半径干预、主任务梯度和训练/验证差距；专家数量本身不是有效性证据。

## Run1实现

四专家及稠密路由见`model/layers/moe_context.py`。公共原型、专家初始化和训练协议在消融间保持对应。LEVIR/SYSU各9组、WHU/CDD各3组，共24组；仅物理GPU1。真实区域Top-2在本轮互补性结果形成后再决定。检查和启动证据统一保存在`outputs/CASA-MoE/Run1`，模型与脚本冻结到该轮独立runtime。
