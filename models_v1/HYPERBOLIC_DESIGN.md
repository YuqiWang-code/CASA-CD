# 双曲上下文：任务半径、内容原型与纠错采用

工作实现协议`casa_pyramid_40k_taskgeometry_v6`。已完成的Run5结果、服务器项目源码与冻结快照继续对应其实际归档。本实现为待正式训练的新双曲候选；普通QKV沿用Run5结构。

## 问题与处理

| Run5问题 | 核实与实现 |
|---|---|
| 只有TAR融合后的检索，没有独立A/B双曲变化证据 | 属实。模块定位为融合后变化上下文纠错，不主张直接双曲双时相匹配；继续使用TAR信息，不增加未经证实必要的时相分支。 |
| 半径只是投影范数，任务意义不明确 | 方向来自归一化共享投影，空间范数设为`1+p`，p来自已有面积变化标签监督的guide。非零方向下半径为`asinh(1+p)`，表示预测变化占比，不表示置信度或语义层次。 |
| Lorentz质心把区域散布隐式变成半径收缩 | K直接由压缩内容P投影、预测占比再提升；不再聚合密集流形点形成K。区域散布作为独立诊断量，不借质心半径隐式表达。 |
| K与V的统计量不同，代表点目标与距离目标不一致 | K、V共用同一P。保持P不变时，K、V均不随输入对的额外散布变化；K是内容代表的嵌入，不称测地Fréchet中心。 |
| 绝对距离同时决定路由与采用量 | 路由只在压缩KV内softmax；采用由内容差值和占比预测经过轻量门控学习。删除self零logit与log-partition采用规则。 |
| source-count校正压低稀有匹配的绝对采用量 | 数量校正只调整候选间路由；唯一有效原型可获得接近1的条件注意力。门控不读取距离或log-partition，所有候选加同一logit不改变路由、门控和写回。 |
| 每类一个原型混合多个外观，p=.5被当作低置信 | 每区域变化/背景各两个外观子原型。保留有稀疏纯度证据的平方类别选择；支持度改为一阶占比，均匀p=.5的两类总支持与明确类别相同。它不再作为门控置信度。 |
| g下降但最终残差增大，SYSU后期泛化下降 | 采用门控直接接收主任务梯度；记录门控前后差值、最终残差和纠错分组。g不作为最终幅度上界。32维共享内容降低容量，泛化效果仍须完整训练确认。 |
| 整体路径有效不等于双曲关系有效 | 提供固定半径、固定方向、打开门控、关闭全局上下文的同权重验证干预；分别统计漏检、误报、边界、小目标以及被纠正/被损害的像素。 |
| 执行成本高 | 一个32维空间替代四个16维空间；448KV的距离/注意力矩阵元素数是Run5的1/2，内容总宽度由64减为32。保留完整5440Q、原TAR残差与细两层局部分支，效率以实测记录为准。 |

Run5 SYSU双曲epoch7/106的主损失1.161616/0.255196、选模损失2.106134/3.395138、F1 .823320/.803653，以及S1采用量.367728/.218548、残差比.115318/.827665均与日志一致。WHU双曲1px边界F1从Run4的83.3015降至Run5的82.0330。这些现象支持重新设计，不能单独证明某个几何量导致泛化下降。

## 数据流与公式

```text
A/B → 共享MobileNetV2 → 四尺度TAR → T_s
  ├─ 原TAR残差
  └─ X_s = LN(T_s)
       ├─ guide p：已有面积变化标签监督
       ├─ appearance a：同类内容的两种软分配
       │    每区域 [变化×a, 变化×(1−a), 背景×a, 背景×(1−a)]
       │    → 共同内容P → K与欧式V，共256/64/64/64=448KV
       └─ 完整Q：32维方向＋guide占比半径
            → 双曲条件路由 R=AV
            → 内容门控 g(V_query, R−V_query, p_query, A·p_key)
            → W_out[g·(R−V_query)] → gamma → TAR残差
  + S1/S2局部高通DW3/PW1残差
  → DCR → 四级训练/一级推理
```

类占比`m_c∈{p,1−p}`，外观分配`a_k∈{sigmoid(W_a X),1−sigmoid(W_a X)}`：

```text
w_{c,k,i} = (m_{c,i}+eps)^2 (a_{k,i}+eps)
            / Σ_l (m_{c,l}+eps)^2 (a_{k,l}+eps)
P_{c,k} = Σ_i w_{c,k,i} X_i
r_{c,k} = max(Σ_i w_{c,k,i} m_{c,i}, eps)
```

LN在池化前；分配、支持度、guide都保留梯度。四个子原型不会改变每类的原型数量比例。忽略数值下界，常数p时，两个变化原型和两个背景原型总支持为`2p+2(1−p)=2`；p=.5不额外损失总质量。平方选择仍可能强化高分伪变化，子原型容量与内容门控用于处理后续选择，不将其当作已被消除的误差。

对任意密集/原型内容Y：

```text
u(Y) = normalize(W_qk Y),  p(Y) = sigmoid(W_guide Y + b)
z(Y) = [1+p(Y)] u(Y)
H(Y) = (sqrt(1+||z(Y)||^2), z(Y))
Q_i = H(X_i), K_j = H(P_j)
V_j = W_v P_j, V_i = W_v X_i
```

同一guide头仍用面积平均GT的BCE监督。`1`是曲率−1下的单位空间基线，使背景也能保留方向差异；p连续增加表示变化占比预测增加。非零投影半径范围为`asinh(1)`至`asinh(2)`，投影整体放大不能任意放大半径。零方向取原点，保持几何合法；不将该退化点的半径解释为占比。p=.5可表示半面积变化，不被定义成低置信或忽略区域。

原型的`p(P)`是共享分类头对压缩内容的预测，不等于区域GT面积均值，也不等于`Σw·p(X)`。这样相同P有相同K和V；该原型预测的校准程度仍需验证。

```text
l_ij = −d_H(Q_i,K_j)^2 / (2 tau^2)
       + log(r_j) + scale_bias[source] − log(M_source)
A_i = softmax_j(l_ij)
R_i = Σ_j A_ij V_j, p_ctx_i = Σ_j A_ij p(P_j)
g_i = sigmoid(G([V_i, R_i−V_i, p(X_i), p_ctx_i]))
U_i = W_out[g_i (R_i−V_i)]
T'_i = T_i + gamma ⊙ U_i + local_i
```

g是每位置标量，G为66→1的1×1卷积；不加入额外门控监督、特殊激活或距离阈值。门控对主任务的梯度包含`g(1−g)`与当前修正方向和主损失梯度的内积，任务需要的修正可增加g、有害修正可降低g；这是一条学习路径，不保证训练后的门控总能识别有益内容。

gamma零初始化、投影正常初始化。初始网络与CTRL共同路径相同；第一步先学习gamma，随后门控与检索获得任务梯度。全局内容恒定时`R−V_i=0`，保留常量场。局部分支沿用Run4/5，不把既有边界收益交给全局压缩重建。

## 验证与归因

`test_hyperbolic_context.py`覆盖占比半径、投影尺度不变性、固定均值散布不变、稀疏选择、子原型梯度、共同logit平移不变、稀有匹配、零/常量场和全部分支梯度。`test_CASA.py`覆盖共同初始化、主任务梯度、参数分组及部署折叠。

模型诊断分别记录半径、径向/角向匹配差异、区域方向方差、子原型分离及重复率、路由TV、门控和残差。区域方向方差只用于观察混合，不预设“多样性=不可靠”。单像素区域的两子原型可以一致，重复率如实记录。

`analyze_hyperbolic.py`仅使用train/val，固定等距样本，阈值.5；默认128张，不使用test设计模块。分析已训练的新结构权重：

```bash
python models/analyze_hyperbolic.py \
  --checkpoint /path/to/new_model/best_model.pth \
  --dataset-root /share_datasets/CD/LEVIR-CD-256 \
  --split val --samples 128 --output outputs/CASA-Pyramid/next/analysis/hyperbolic.json
```

- `context_off`仅关闭全局残差，保留局部支路。
- `fixed_radius`将Q/K占比半径设为p=.5对应值，保持guide支持度和门控输入的占比预测，检查径向坐标贡献。
- `fixed_direction`保留占比半径，固定方向，检查角向关系贡献。
- `gate_open`保持检索、内容和其余权重，将g设为接近1，检查采用决策的作用。
- `euclidean_metric`保持同一空间坐标、原型内容及门控，只将测地距离换为空间坐标欧氏距离，测量当前权重对度量的敏感性。
- 像素分组包含原模型漏检/误报、全局上下文纠正/损害、1px边界及GT连通面积≤64px的小目标，报告各组门控及半径均值；空组返回null。

这些是固定权重干预，不替代相同协议重训消融。旧Run5权重与新结构不兼容；使用归档实现研究旧结果。

## 已知限制

半径现在有明确、可测的预测含义，但不自动获得层次关系或伪变化纠错能力；独立双时相证据仍由骨干/TAR提供。双子原型可能趋同，同类多种外观仍可能超出容量，须观察重复率和错误分组。门控通过内容学习而非读取真实正确性，仍可能过拟合。短批次检查仅验证有限数值和任务梯度，不能证明泛化提升；SYSU长期泛化、四库有效性和几何独立价值需正式训练及重训消融。

[Law等，ICML2019](https://proceedings.mlr.press/v97/law19a.html)的闭式质心对应平方Lorentzian距离；[OCR，ECCV2020](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123510171.pdf)提供受分割监督的区域内容聚合背景。占比半径、同内容K/V、外观子原型及独立内容门控为本项目方案，文献不作为其四库精度已改善的证据。论文见[文献索引](../docs/参考文献/文献索引.md)。
