# FINAL_DECISION：结构决策与九问回答

本轮不改任何训练代码，也不启动训练；以下是**冻结权重反事实**给出的决策依据。

## 一、九问逐条

**Q1 V5 的全局 F1 重算是否复现？**
复现，且方向不同。V5 用"逐图 F1 平均、空图记 0"，重算为整数混淆矩阵后（LEVIR 48 张/SYSU 36 张 val）：
BASE SYSU 0.7964/0.7760、LEVIR 0.9211/0.9187（seed 2334/2335）。V5 结论里"NOCTX 掉 10.1 pp"
不再成立：SYSU 上是 −9.8/−1.6 pp、LEVIR 上是 −16.7/−4.3 pp，**seed 间差异很大**。
V5 报告的"SYSU 上 NOCTX/UNIFORM 更好"在整数口径下反号（UNIFORM −4.6/+0.0），
所以那一批臂的排序不能再用。

**Q2 真实上下文在哪库、哪些像素上帮助或损害？是否传播伪变化？**
机制在起作用：去掉 context 回写，两库都掉点（LEVIR 更严重、seed 更不稳）。但这一臂同时去掉了
discrepancy/gate/level/V 聚合，**无法归因到某一个几何算子**。伪变化传播没有单独证实：先验隔离
（SUPPORT-OFF/COUNT-OFF/GUIDE）都在 ±0.3 pp 内，没有"去掉先验就减少大面积误检"的模式。

**Q3 同 checkpoint 同预算下，K 池化/V 池化/距离/V 聚合各贡献多少？标定欧氏是否足够？**
KE/VE/KVE/DE/DECAL 全在 ±0.2 pp（两库四列一致）⇒ **池化几何与距离形式没有可测贡献**；
用同一 z 坐标的欧氏距离 + 一个拟合温度（DECAL，a=0.64–0.71）就能替代测地距离。
V 聚合（Lorentz vs 欧氏）符号随数据集翻转：LEVIR 上 Lorentz 好 0.9–1.1 pp，SYSU 上差 1.0–1.1 pp
⇒ 不是稳定收益。注意力侧同结论：换几何 JS 0.01–0.05，去掉距离才 0.08–0.27。

**Q4 224/128/56/32 的任务与效率曲线？损失出现在哪一尺度？**
任务层几乎平坦：SYSU 0.7862/0.7859/0.7857/0.7861；LEVIR 0.9199/0.9201/0.9204/0.9204。
损失表现为精度↔召回平移（SYSU 精度 +1.0 pt、召回 −0.8 pt），不是总量下降。
逐尺度拆分未做（只做了总量），所以"损失出现在哪一尺度"本轮无证据。

**Q5 压缩后的注意力/V/残差/预测与全量参考的关系？**
未做全量参考展开，无法回答；但预算曲线已说明"压缩到 32 与 224 的任务输出无差异"，
这使"压缩造成可回收损失"的前提不成立（见 Q4）。

**Q6 修复后 ADA 是否优于 FIX？是否终止？**
表示保真层**是**：同预算（每尺度 4 区域、B=32）下 K_SSE −7.4%、V_SSE −9.1%，
四个 checkpoint 方向一致，RAND 比 FIX 差（+4.2%/+3.1% 说明不是"非均匀"带来的）。
但下游无收益可回收（Q4）。**判定：技术上过门，工程上终止**——不进入 S11，不列为待训练候选。

**Q7 confidence 梯度是否在真实路径复现？三项先验各自效果？**
是。真实 R_LEAN/R_COMPACT 的 `support_head` 权重/偏置**恒为 0.0**；单元测试里 OLD 臂梯度严格为 0，
SHARE/NONZERO/LOGSHARE 分别 0.202/2.419/0.0344 ⇒ 断点是 `abs` 零点 + `clamp` 边界双重所致。
三项先验：SUPPORT-OFF 0.0–0.4 pp；`−log N` 与尺度偏置在 SYSU 上去掉各 +0.29 pp（两 seed 同号，
CI 排除 0），LEVIR 0；GUIDE 为负。

**Q8 最终保留/删除/暂停哪些机制？有没有足够简单的待训练候选？**
见"二、决策表"。没有足够简单的、有仿真证据支持的待训练候选：唯一有正向证据的是
"Lorentz V 聚合（LEVIR）/欧氏 V 聚合（SYSU）"这种随数据集翻转的项，不足以立项。

**Q9 哪些是事实/推断/假设/未完成？**
- 事实：S9a 的 16 臂配对 CI；S9b 的预算曲线；S8b 的保真度；S13 的权重与梯度。
- 推断：几何差异主要等价于一个温度尺度因子（C2c/DE/DECAL 支持，但未在真实 logits 上做行中心化
  幅度校准的正式臂）；`−log N` 有害的原因（未做逐尺度消融）。
- 假设：S8b 的保真度优势可迁移到下游（本轮未验证，且 S9b 表明无空间）。
- 未完成：全量参考展开、S8b 下游反事实、逐尺度/小目标分层、效率测量。

## 二、决策表

|---|---|---|
| 双曲距离（测地 vs 欧氏） | **删除/替换为标定欧氏**（作为正式训练的对照臂保留） | DE/DECAL ±0.2 pp；DECAL 用 a≈0.64–0.71 吸收 |

| `−log N` + 学习尺度偏置 | **候选删除**（SYSU +0.29 pp，两 seed 同号） | S13 冻结反事实 |

| 流形卷积/S12 | **不启动** | 触发条件（损失集中在边界/邻域）未证据化 |

## 三、如果只做一件事

**把"双曲"从结构里降级为对照**：正式训练用同一套 `TAR + 检索 + DCR`，只把测地距离换成
"同一 z 坐标的平方欧氏 + 一个可学习温度"，并把 Lorentz V 聚合保留为默认、欧氏聚合作为消融臂。
这与本轮所有证据一致：几何换不换在任务层看不出来，而机制（上下文/检索/回写）是唯一大项。

## 四、正式训练方案（只产方案，不启动）

- 共同底座：MobileNetV2 四尺度 → TAR(cg) → 检索（Q=融合 T，KV=差分 D）→ DCR → 四级监督，
  与 Run10 相同的协议/划分/预算（224 与 32 两档）。
- 臂：`CTRL`（原样，测地+Lorentz 聚合）、`EUC-DIST`（标定欧氏距离）、`EUC-AGG`（欧氏 V 聚合）、
  `EUC-BOTH`、`NO-PRIOR`（SUPPORT-OFF+COUNT-OFF+SCALE-OFF）。
- 数据：SYSU、LEVIR 各两 seed（2334/2335），先只跑这两库；WHU/CDD 在结论稳定后补。
- 判据：只用 val 选模（与 Run10 一致），test 只在方案冻结后评价一次；
  报告整数混淆矩阵的 F1/IoU/Kappa + 参数 + 时延；配对 bootstrap 按场景重采样。
- 必查：`strict_fp32_fold_v1` 的部署折叠一致性 ≤2e-4、no-op 守卫、替换层梯度非零。
