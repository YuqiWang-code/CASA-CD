# S9a-final：同 checkpoint、同预算下的算子反事实

## 做法（对 V5 的三处修正）

| 项 | V5 做法 | 本轮做法 |
|---|---|---|
| F1 | 逐图 `2TP/(2TP+FP+FN)` 后平均，空图记 0 | 逐图存整数 TP/FP/FN/TN → 全部图像求和 → 全局 F1/IoU/Kappa |
| 判定阈值 | `interpolate(sigmoid(out[0]), 256) > 0.5` | 冻结 evaluator 的 `outputs[0] > 0`（四级输出本来就是 256²，不插值） |
| 注意力差异 | 每图覆盖 `base_prob`，只比最后一张；`js` 多乘 0.5 | 以图为外层，同图 BASE 与臂配对；`js = sqrt(0.5KL(p‖m)+0.5KL(q‖m))` |
| 温度标定 | 行中心化未真正做 | `a = Σ⟨C(H),C(E)⟩/Σ‖C(E)‖²`，float64 拟合，val 不参与 |

`max|Δlogit| = 0.000e+00`、二值差 0（4 个 checkpoint × 4 张）：拆开的 forward 与官方 forward 逐位一致。

## 读法

1. **上下文机制是唯一大项**：去掉回写，LEVIR 掉 4.3–16.7 pp、SYSU 掉 1.6–9.8 pp，且 seed 间波动很大
   （LEVIR-2334 的 NOCTX 甚至低于 Oracle 随机基线附近）。这说明"检索+回写"整体在起作用，但它不是一个
   稳定的、可归因到单一几何算子的量。
2. **池化几何、距离形式都没有可测贡献**：KE/VE/KVE/DE/DECAL 全部落在 ±0.2 pp 内，两库四列一致。
   这与 S7c 的探针、C2c 的"差异主要是尺度因子"完全吻合。
3. **V 聚合符号随数据集翻转**：LEVIR 上欧氏聚合反而更差（−1.0 pp），SYSU 上更好（+1.0 pp），
   净效应 ≈0 → 不能声称 Lorentz 聚合有独立任务价值；保留它只是"不更差"。
4. **先验三项几乎不起作用**：SUPPORT-OFF/DISTONLY 都在噪声内；只有 `−log N` 与学习尺度偏置在 SYSU
   上有 +0.29 pp 的正贡献（去掉更好），LEVIR 上为 0。这与 S13 的发现一致：mass 模式下 support 项
   在推理时几乎不影响预测。
5. **距离项在有先验时仍然重要**：UNIFORM/PRIORONLY 在 LEVIR 上稳定 −1.0~−2.1 pp，说明
   "距离+先验"这一组合提供了 LEVIR 所需的排序信号；但换成欧氏距离（DE/DECAL）不掉点，说明
   **有价值的只是"距离"这个形式，不是"双曲"这个几何**。
