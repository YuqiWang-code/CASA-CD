# S8b-final：同预算自适应分区（B=32，表示保真层）

## 对 V5 `s8b_partition.py` 的三个实质修正

1. **membership 用在线 raw guide 概率重建**：`m_{i,c} = p_i` / `1−p_i`，权重 `w=m/M_{r,c}`，
   不再复用原网格已归一化的 weights（移动边界后原权重没有意义）。
2. **分裂目标用整尺度固定分母**：`J_s(R)=Σ_c J(R,c)/max(M_{s,c},ε)`，`M_{s,c}` 是该尺度全部像素的
   类质量，与 R 无关 ⇒ `gain=J(R)−J(R1)−J(R2)` 可加、跨区域可比。
3. **优化目标与评价分离**：划分时分别用 E 代价（`Σm‖z‖²−‖Σmz‖²/M`）或 H 代价
   （`2(a−M)`，`a=√(−⟨S,S⟩_L)`）；评价时所有臂一律用**实际会输出的 Lorentz 重心**，再算欧氏 SSE、
   平方测地、弦代价、方向余弦。两条曲线分列。

另外：候选切分全部是 dyadic 中线二分，**FIX 网格本身就在候选集内**，所以"自适应在同一目标下不如
FIX"只可能是实现错误；`RAND` 用来验证"不是预算本身在起作用"；`DP` 用同一棵树上的动态规划给出
同预算最优，作为 greedy 的上界诊断。

## 设置

R_FULL-2334/2335 × SYSU/LEVIR，每 checkpoint 12 张 val（分层 bg/small/mid/large），
四个尺度，每尺度 4 个区域（= 8 个原型，B=32），每区域恒两槽。

## 读法

1. **自适应确实比固定网格保真**：K 侧 SSE −7.4%（ADA-K-E）、V 侧 −9.1%（ADA-V-H），余弦同时升
   0.011（K）/0.007（V）；方向在 4 个 checkpoint 上一致，不是单点噪声。
2. **不是"随便换划分"就行**：RAND 在两侧都比 FIX 差（+4.2% / +3.1%），说明收益来自"按几何量切分"，
   不是来自"非均匀"。
3. **greedy 已接近同预算最优**：DP 只比 ADA 好 0.2–1.0%（K 0.5849 vs 0.5912），说明 dyadic 中线
   候选集本身限制了上限，而不是贪心选得差；这也意味着想再提升必须换候选集（例如任意矩形），
   代价是开销。
4. **E 与 H 目标给出的划分几乎相同**：ADA-K-E 与 ADA-K-H 的 K_SSE 差 <0.1%，说明在这批真实特征上，
   两种代价的排序几乎一致（与 S9a "换几何不掉点" 一致）。
5. **K 侧优化顺带改善 V 侧**（147.4 vs 159.5，−7.5%）：K 与 V 来自同一 `LN(D)`，方向结构高度耦合；
   这与任务书 §6 里"K/V 驱动是否互补"的期待相反 —— 本数据不支持分别优化两侧。

## 停止门判定

任务书 §6 的停止门是"B=32 无一致实际中心保真优势 → 不再做自适应下游"。本轮**有**一致优势，因此
技术上过门；但结合 S9b（固定 32 与 224 的任务 F1 无差异）与 S9a（换池化几何不掉点），
可回收的下游收益非常有限。故建议：**不进入 S11，不把自适应分配列为待训练候选**；
若将来出现"32 预算掉点"的证据（例如换数据、换监督、单列小目标召回），再回头用本脚本重估。
