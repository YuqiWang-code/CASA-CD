三条新的稳定结论：
1. 排序（Spearman/top-1）对几何几乎不敏感，但**注意力权重与 V 聚合差 13–22%**——"检索命中率不变"不能推出"几何没有影响"。
2. 内容（差分 vs 融合）在公平口径下只有 +1～+4 pp，且随传感噪声降低才变大（差分抵消共享背景、放大独立噪声 √2）。
3. 无监督原型分配相对 oracle 损失 3–11 pp，比几何与内容的差异都大——**下一个该修的可能是分配，而不是池化几何**。

## 4. 为什么本轮没有先做阶段 A

- 方案 §0 的硬要求是"V2 修复 + S7 + S8 + S9 都必须做"，但同时写明 S7 是最高优先级、且"无 checkpoint 时才用合成替身"。检查发现 Run10 的真实 checkpoint 齐全（6 臂 × 2 库，manifest 带 `source_archive` 与冻结 runtime），因此优先把真实特征这条证据链接上——它能直接判定"半径线是否值得继续"，这是决定后续所有工作的分叉点。
- S7 的结论（半径无增量信息、confidence 先验失效、224 原型收缩只有 8–23%）改变了阶段 A 的重点：C2 里"半径 vs 几何"的对比不再是决定性问题，而**池化内容（V 收缩 0.64–0.97、ESS 3–11）与 support 失效**才是下一步该修的对象。

## 5. 下一步建议（待用户确认）
