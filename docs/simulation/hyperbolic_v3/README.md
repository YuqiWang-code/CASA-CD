## c2b：修正了什么

| v2 的问题（方案 §2 A1/A2 点名） | v3 的做法 |
|---|---|
| 范数按"整场景"统计（`P(:,:)` 把后两维合并） | 逐 token `‖z‖`，并报中位/CV/最小最大 |
| 所有键共用同一个径向增益 | 每 token 独立乘子，跨方法、跨 κ 共用同一批 |
| 目标半径只取 V1 的 (0.47, 0.345) | 两档：V1 档 + S7 实测档 (Q 0.79, K 0.86) |
| `mean(argmax 相同)` 被写成"argmax 异"当几何证据 | 改名为 `top1_agree`，并新增 `1−Spearman`、JS **距离**、V 聚合相对误差 |
| 只有"欧氏 vs 测地"一个对照 | 四族：测地 / 欧氏(z) / 欧氏(Poincaré) / 测地+逐 token 保范 |
| 支持度只做一个"oracle vs 无" | 四档 × 变化比例 1/3/5/10/20/50%，类先验=真实类占比 |

## c2b 结果（`results/log_c2b.txt`，`res_c2b.mat`，`figures/fig_c2b_01_retrieval.png`）

**排序几乎一致，但注意力与 V 输出差别明显——这是 v2 没看到的部分。**

κ=0.20（实测 CV 附近）时，测地相对欧氏(z) 的三个差异量：

| 半径档 | 1−Spearman | JS 距离 | V 聚合相对误差 | top1 一致率 |
|---|---|---|---|---|
| V1 档 (0.47/0.345) | 6e-4 | 0.0094 | 0.012 | 0.930 |
| 实测档 (0.79/0.86) | 4e-3 | 0.133 | 0.220 | 0.882 |

- κ=0 时同样成立：V1 档 JS=0.0060 / Vrel=0.011，实测档 JS=0.110 / Vrel=0.226。
- 也就是说：在真实半径区间，**"排序不变"不等于"算子不变"**——注意力权重与 V 聚合
  会差 13%–22%，而 v2 用 0.006 的 JS 得出"几何不重要"的结论，是因为半径档取错了。
- 逐 token 保范归一化（把每个 token 拉回目标半径）是比换几何更大的干预：
  实测档下 top1 一致率掉到 0.43–0.54、JS 0.10–0.21。
- 类正确率本身对几何不敏感（0.96–0.99），所以**不能靠检索命中率判断几何是否有用**，
  必须看 JS / V 聚合 / 下游。

四档先验（`+类先验` 用真实类占比，`+尺度计数偏置` = −log N_s）：

| p | 距离 only | +类先验 | +尺度偏置 | +both |
|---|---|---|---|---|
| 1% | 0.993 | 0.993 | 0.993 | 0.993 |
| 5% | 0.777 | **0.958** | 0.782 | **0.958** |
| 10% | 0.818 | **0.892** | 0.825 | **0.892** |
| 20% | 0.745 | **0.835** | 0.725 | **0.835** |
| 50% | 0.487 | 0.527 | 0.547 | 0.540 |

- 类先验只在类别不平衡时有用（p≤20%），平衡时几乎无效；这与模块里 `support` 的作用面一致。
- **尺度计数偏置 −log N_s 会把尺度正确率从 1.000 压到 0.725**：它按尺度大小做偏置，
  在"查询确实来自某尺度"的任务里是纯损失。模块的 `source_bias` 含同一项，
  值得在 S9 的 B4/B6 里单独查（本仿真只说明它有代价，不说明真实模型里它错）。


## c3b：修正了什么

| v2 c3 的混淆（方案 §2 A4 点名） | v3 的做法 |
|---|---|
| 每臂各跑一次 K-means | 每 (scene,scale,content) 只拟合一次，两几何共享中心 |
| 各臂重新生成场景 | 同一 seed 生成一次，四臂复用 |
| 在拟合点上评价（泄漏） | fit/eval token 隔点互斥；另保留"朴素同点"版作量级对照 |
| 生成器令 T1=u1、T2=u1+Δ ⇒ D 恰好等于 Δ | T1/T2 各有独立传感噪声（σ 三档），另加非变化外观扰动、弱变化、配准误差 |
| bootstrap 重新生成场景 | 按场景重采样 1000 次，场景级 AUC 配对 |
| 只报 pooled AUC | pooled + macro-scene 同时报，并列 AP / 弱变化召回 / oracle 上界 |

## c3b 结果（`results/log_c3b.txt`，`figures/fig_c3b_01_fair.png`）

四臂 = 内容 {T2, D=T2−T1} × 几何 {欧氏(z), 测地}，30 场景 × 3 档时相噪声 σ：

| σ_sensor | T-E | T-H | D-E | D-H | 内容效应(D−T2 @H) | 几何效应(D: H−E) |
|---|---|---|---|---|---|---|
| 0.70 | 0.8383 | 0.8372 | 0.8469 | 0.8402 | +0.30 pp [−3.2, +3.8] | −0.67 pp [−2.3, +0.8] |
| 0.35 | 0.8865 | 0.8839 | 0.8873 | 0.8969 | +1.31 pp [−2.1, +5.3] | +0.97 pp [−0.0, +2.2] |
| 0.20 | 0.8912 | 0.9031 | 0.9197 | 0.9449 | +4.18 pp [+0.6, +8.8] | +2.52 pp [+1.1, +4.1] |
| 均值 | 0.8720 | 0.8747 | 0.8846 | 0.8940 | +1.26 pp | +0.94 pp |

- **V2 的 +22.84 pp 无法复现。** 公平口径下内容效应只有 **+1.3 pp**，最好一档（低时相噪声）也只有 +4.2 pp；
  机制清楚：差分抵消共享背景、但把独立时相噪声放大 √2，所以 σ 越小差分越占优。
- **几何效应 ≤ +2.5 pp**，且只在"D 内容 + 低时相噪声"这一格 CI 排除 0；高噪声下为 0。
  几何×内容交互在 σ=0.2/0.35 为 +1.3 pp（CI 排除 0）、σ=0.7 时 −0.6 pp（不显著）。
- **最大损失不是几何、也不是内容形式，而是"无监督原型分配"**：oracle（GT 造原型）0.84–0.97，
  无监督 0.84–0.94，差 3–11 pp。这条比"该不该用测地距离"重要得多。
- 朴素同点版（V2 协议）把 AUC 抬高 +2.3…+10.8 pp（平均约 +6 pp）——这就是 V2 数值虚高的来源。

**口径提醒**：以上是合成对照，AUC 的 pp 不能当 F1 的 pp；几何效应 CI 含 0 只表示证据不足，
不等于"等价"（要主张等价需预先规定等效区间）。
