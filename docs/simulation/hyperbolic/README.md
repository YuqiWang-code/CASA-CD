# 双曲几何仿真（CASA-CD）

回答一个问题：**在 CASA-CD 这个模型里，双曲几何到底能提供什么欧氏做不到的东西？**
不是"双曲是否更好"，而是逐条机制的可复现证据。

## 运行

```
>> run docs/simulation/hyperbolic/run_all.m     % 或在编辑器里点 Run
```

`run_all.m` 是唯一入口：依次跑 H5 → H1 → H2 → H3 → H4，生成 `figures/*.png`，
并把完整控制台输出写进 `run_all_log.txt`（R2022a 实测 78 s）。

单条假设也可以单独跑：`h5_geometry.m` / `h1_hierarchy.m` / `h2_decisive.m` /
`h3_prototypes.m` / `h4_temperature.m`。

`hyper_setup.m` 是所有脚本共用的工具箱（函数句柄 struct `H`）：Poincaré exp/log map、
Möbius 加法、测地距离（c=1 与任意曲率 c）、Lorentz 直接提升、测地应力嵌入、
ridge logistic 探针、AUC/Fisher 比。**不依赖任何工具箱**。

## 三处必须知道的实现约定（否则数字对不上）

1. **本项目的"直接 Lorentz 提升"在 Poincaré 盘里的像是**
   `π(Z) = Z / (1 + sqrt(1+||Z||²))`，于是 `d(0,π(Z)) = asinh||Z||` **精确成立**
   （实测偏差 0.00e+00）。也就是说半径不是新信息，它就是特征范数。
2. 曲率 c 的推广是 `π_c(Z) = Z/(1+sqrt(1+c||Z||²))`，`d_c(0,π_c(Z)) = asinh(sqrt(c)||Z||)/sqrt(c)`
   （实测 1.78e-15）。c→0 退化为欧氏。
3. 同半径两点：`d_geo = acosh(1 + 2S/a²)`（本工具箱 `S = ||x−y||²`，`a = 1−r²`），
   对 `S` 严格单调 → **同壳层时双曲距离与欧氏距离的排序完全相同**。

## 图：看什么，结论是什么

### `fig_h5_rearrangement.png` — H5-Q1：几何到底有没有被打开（run_all 的第一张图）
横轴是 Q/K 的径向发散度（κ），纵轴是双曲距离矩阵与欧氏距离矩阵的 Spearman。
- 同壳层（κ=0.02，等价于 LN + 共享投影）：Spearman **0.9526**、top-1 排序一致率 86% → 几何被关掉。
- 4 个壳层 0.7/1.6/3.2/6.4：Spearman **−0.6293**、top-1 一致率 0.256 → 排序被重排。
- κ 扫描：[0.9526 0.3346 −0.2771 −0.6581 −0.7135 −0.6342 −0.4908]。
结论：**双曲注意力和欧氏注意力在"同半径"假设下是同一个算子**（τ 只能吸收尺度差），
"几何惰性"是代数必然，不是半径小。

### `fig_h5_q2_arms.png` — H5-Q2：半径分层值不值
5 臂 top-1 检索（224 KV，弱/强变化原型）。
- LN+测地 0.710 / LN+欧氏 0.710，**0/224 个 argmax 不一致** → LN 之后两种几何完全等价。
- 裸特征：欧氏 0.705 但**弱 KV 召回 0.000**（被范数支配）；裸测地 0.353（塌了）；
  裸测地 + 显式半径 bias（λ=+2.0）→ 0.719 / 弱 KV 0.071。
结论：真要让半径起作用，需要**显式半径 bias**，收益也只是追平 LN；curvature 不是杠杆。

### `fig_h5_shells.png` — H5-Q3：M2（弱变化被吞）在每种几何下会不会发生
1% FPR 下的召回，弱/强变化幅度 0.35 / 1.25。
| 特征空间 | AUC | 弱召回 | 强召回 | 平均半径 弱/强 |
|---|---|---|---|---|
| 欧氏 contrast（原始） | 0.783 | 0.027 | 0.590 | 1.80 / 3.47 |
| 测地 contrast，同壳 KV | 0.758 | 0.026 | 0.443 | 0.57 / 0.74 |
| 测地 contrast，半径分层 KV | 0.753 | 0.027 | 0.406 | 0.57 / 0.74 |
| LN 后（同壳）测地 | 0.644 | 0.016 | **0.090** | 0.41 / 0.41 |
| LN 后（同壳）欧氏 | 0.644 | 0.016 | **0.090** | 1.00 / 1.00 |
结论：**归一化（LN）才是吞掉强变化的原因**（0.590 → 0.090），不是曲率；
半径分层救不了弱变化（0.027 vs 0.026，AUC 0.753 vs 0.758）；
弱变化在所有几何下召回都只有 1.6%–2.7% → **M2 是内容问题，不是几何问题**。

### `fig_h5_tree_shell.png` — H5-Q4：同壳约束到底毁掉什么
4-ary 深度 3 的树嵌入（85 节点）：
双曲 2D 应力 0.4471 → 强行同壳 0.2843（0.64×），欧氏 0.4585 → 0.5937（1.30×）；
半径-深度 Spearman 0.753 → **0.000**。
结论：同壳约束毁掉的是**径向/层级通道**，两种几何都一样毁；所以 LN + 共享投影
丢的是层级信息，不是曲率信息。

### `fig_h1_disk.png` / `fig_h1_dims.png` — H1：层级是否天然可分
左：当前 KV 树（root→4 个尺度→224 叶，所有叶深度 2）的 Poincaré 2D 嵌入——
128 格的尺度被挤到内侧成一大团，另外三个尺度是细弧；右：四叉树 KV 是干净的同心环。
- 维度预算：树 B 上 H²（应力 0.2934）≈ 欧氏 5 维（0.208→0.08 之间），不是"双曲 2 维吊打 50 维"。
- 树 A（当前设计）欧氏 48 维仍打不到 H² 的应力（NaN），但原因是**所有叶子同深度**：
  root-leaf 距离对 4 个尺度都是 2，跨尺度叶-叶距离全是 4 → **尺度信息根本不在树度量里**。
- 直接提升：`max|radius − asinh||z||| = 0.00e+00`，尺度可分 AUC 半径 1.000 vs 原始范数 1.000，排序完全一致。
结论：H1 对当前 KV 结构**不成立**；只有把 KV 改成真正的嵌套四叉树才谈得上层级。

### `fig_h2_arms.png` / `fig_h2_effect.png` — H2：内容增益 vs 几何增益（核心判决实验）
5 折 CV ridge logistic 探针，18 个场景（2 变化一致性 × 3 类不平衡 × 3 seed），
held-out 半边像素打分（无标签泄漏）。
- 内容（差分原型 `|P−Q|`/差向量）：**+22.84 ± 7.92 pp**（p=7.5e-10），两种几何下一样大
  （欧氏形式 +22.84 pp，p=1.2e-9）→ **内容增益是几何无关的**。
- 同维度几何对比（H2c，1-D 原型 contrast 每尺度）：测地 − 欧氏 = **−4.28 pp / −1.16 pp**，
  即等维度下测地**更差**，与 Run14（−0.167pp）一致。
- 池化的 `hyp_vs_euc_dist +9.50 pp`（p=0.00011）随原型噪声从 −14.25 pp 单调收窄到 −0.14 pp
  （H2b）→ 那是**少样本原型估计偏差**的产物，不是几何优势。
- 标量对照臂 `r-only`（`r=asinh||Δ||`）：0.574/0.645/0.590 vs 完整双曲 0.683/0.643/0.636，
  `hyp_vs_scalar +15.48 pp`、`hyp-den+r` 与 `hyp-den` 持平 → **双曲表示不等于范数的换参数**，
  但它多带的（方向）欧氏特征本来就有（`hyp_vs_euc_den +0.98 pp, p=0.2` 不显著）。
- 支持度先验：`sup_geo +14.80 pp`、`sup_euc +20.48 pp` → **先验才是第二个大杠杆**。
- 饱和诊断：π(Q) 中位半径 0.855，r>0.95 的比例 0.000，`Spearman(欧氏 contrast, 测地 contrast)=0.839`，
  `Spearman(测地 contrast, 半径)=0.007` → 半径几乎不携带变化信息。

### `fig_h3_distmat.png` / `fig_h3_retrieval.png` — H3：224 个类条件原型的检索稳定性
10 个训练场景估原型、2 个 held-out 场景做查询。
- KV 范数按尺度 [0.07 0.09 0.22 0.48]，π(P) 半径均值 **0.069**（全在原点附近）。
- 8960 个对的 `Spearman(欧氏, 测地) = 0.9994`，argmax 不一致 **0/40**。
- 四臂（geo+prior / geo / euc+prior / euc）在每个噪声下**完全相同**
  （0.600/0.600/0.500/0.600/0.350），λ 恒被选成 0.000，跨尺度混叠率恒 0.300。
结论：同壳层 + 近原点 → 检索是欧氏检索的单调换参数，几何与先验在此测试里都不提供信息。

### `fig_h4_tau.png` / `fig_h4_curvature.png` — H4：τ 与曲率在学什么
- H4-A：`AUC(τ)` 在 τ∈[0.05,32] 上**精确恒定**（偏差 0.00e+00），而概率移动 0.497
  → τ 只改校准，不改排序，**不可能带来 AUC**。
- H4-B：用 BCE 拟合 τ（斜率 a）：1%/3%/5% 阳性率下 a = 1.58/1.56/1.54（比值 0.97），
  截距 b = 1.24/1.40/1.60（log-odds 移 1.65，截距走了 0.36），同一测试集 AUC 恒 0.7609
  → **先验由 bias 吸收，τ 连先验都不拟合**。
- H4-C：曲率只重标定半径（恒等式误差 1.78e-15）；固定特征下 `Spearman(d_c, d_1)` 全在 0.9998–1.0000；
  同壳层时对每个 c 精确为 1.0000。
- H4-D：AUC 随 c 单调下降 0.8311 (c=0.25) → 0.7820 (c=1) → 0.7516 (c=4)，
  且每个 c 上 τ 都是惰性的。结论：**曲率越接近欧氏越好**，τ 与 c 都不能替代对方。

## 一句话总结

在当前结构下，双曲几何提供的**唯一真实自由度是"半径分层"**，而它被 LN + 共享投影关掉了；
打开它（去掉归一化 + 显式半径 bias）的收益只够追平归一化。真正带来 +20 pp 的是
**KV 的内容（差分原型）** 和 **支持度先验**。详见 `docs/temporary/双曲仿真结论_20261117.md`。
