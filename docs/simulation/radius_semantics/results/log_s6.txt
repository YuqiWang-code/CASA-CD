===== S6 半径归因与四个旋钮 =====

[A1] 池化半径精确式 rho_pool = asinh( A*sinh(rho) / sqrt(cosh(rho)^2 - A^2*sinh(rho)^2) )
     其中 A = sqrt(c+(1-c)/n)；小半径时退化为 asinh(A*sinh(rho))
        n|c         0.00   0.30   0.52   0.80
          1        0.470  0.470  0.470  0.470
         16        0.121  0.256  0.339  0.416
         64        0.057  0.250  0.329  0.415
       1024        0.013  0.245  0.327  0.414
  解析式与数值差最大 1.1e-02（n 小、c=0 时因方向只是"近似不相关"而有偏差）

[A2] 由实测反解：rho_K=0.345 ⇐ A = 0.7575 ⇒ c(n=1024) = 0.573
