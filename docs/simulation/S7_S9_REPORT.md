## 2. 结论 A：半径对"是否变化"没有超出 guide 后验的增量信息

探针（train 32 图拟合 → val 120 图评价，逐像素，按尺度）：

| 臂/库 | 尺度 | guide p | 仅半径 | p + 半径 |
|---|---|---|---|---|
| R_FULL-2334 SYSU | s0 / s1 / s2 / s3 | 0.9943 / 0.9949 / 0.9938 / 0.9931 | 0.7166 / 0.7761 / 0.9034 / 0.9059 | 0.9928 / 0.9920 / 0.9886 / 0.9911 |
| R_FULL-2334 LEVIR | s0 / s1 / s2 / s3 | 0.9979 / 0.9989 / 0.9991 / 0.9981 | 0.6209 / 0.5344 / 0.6974 / 0.9637 | 0.9959 / 0.9989 / 0.9991 / 0.9980 |
| R_FULL-2335 SYSU | s0 / s1 / s2 / s3 | 0.9844 / 0.9858 / 0.9850 / 0.9828 | 0.6575 / 0.5470 / 0.6151 / — | 0.9829 / 0.9843 / 0.9852 / 0.9838 |
| R_FULL-2335 LEVIR | s0 / s1 / s2 / s3 | 0.9981 / 0.9963 / 0.9969 / 0.9895 | 0.5524 / 0.5529 / 0.6808 / 0.8715 | 0.9951 / 0.9960 / 0.9530 / 0.9950 |

读法：**加入半径后 AUC 一律不升**（−0.000 ～ −0.044），即径向坐标在像素级是 guide 后验的冗余量；单独用半径时跨库跨 seed 从 0.48 到 0.96 剧烈漂移（LEVIR 浅层 ≈ 0.53–0.62，SYSU 深层 ≈ 0.90）。这与 V2 的 S3/R2 在"替身特征"上得到的"半径≈纹理、不是变化"一致，但这次是**真实训练权重**。

→ 按方案 §7 决策表：「S7 半径无独立信息」→ 暂停 OEM、径向重锚、单纯扩大半径这一整条线。

## 3. 结论 B：confidence 支持度先验在 R_COMPACT / R_LEAN 中完全失效

| 臂（support 模式） | support 均值 | 最小 | 最大 |
|---|---|---|---|
| R_FULL-2334 / SYSU（mass） | 0.356 | 2.1e-04 | 0.998 |
| R_FULL-2334 / LEVIR（mass） | 0.659 | 4.7e-02 | 0.9998 |
| R_RES-2334 / SYSU（mass） | 0.440 | 2.0e-03 | 0.983 |
| **R_COMPACT-2334 / SYSU（confidence）** | **0.0** | **1.0e-06** | **0.0** |
| **R_LEAN-2334 / SYSU（confidence）** | **0.0** | **1.0e-06** | **0.0** |

`confidence` 模式取 `|2·sigmoid(support_head)−1|` 再 clamp；恒为 1e-6 说明 `support_head` 输出在所有像素都是 0（零初始化后从未离开 0）→ `log(support)` 是**对所有原型相同的常数**，被 softmax 完全吸收。所以：

- R_COMPACT / R_LEAN 与 R_FULL 的差别里，"confidence 先验"这一项**实际上没有参与**；把它们的差异解释成"32 原型 + confidence 先验不亏"不成立。
- 这也解释了为什么"support 强度 λ 在合成里总被选成 0"：真实模型里这个先验本来就没被训练起来。
- 需要单独验证：这是 `support_head` 零初始化 + 缺少梯度的实现问题，还是训练目标里该项权重不足（`auxiliary_weights["guide"]=0.1` 只管 guide）。

## 4. 结论 C：池化收缩是温和的，且来自"方向高度一致"而非"半径分散"

逐 cell（8/4/4/4 网格）统计，val 120 图平均：

| 臂/库 | kind | ratio（原型半径 / 成员加权半径） | 池内半径 CV | 方向一致性 A | ESS |
|---|---|---|---|---|---|
| R_FULL-2334 SYSU | K | 0.923 / 0.859 / 0.860 / 0.871（s0→s3） | 0.054 / 0.079 / 0.080 / 0.062 | 0.957 / 0.912 / 0.911 / 0.922 | 53 / 46 / 11 / 3 |
| R_FULL-2334 LEVIR | K | 0.875 / 0.777 / 0.792 / 0.903 | 0.071 / 0.106 / 0.113 / 0.088 | 0.936 / 0.870 / 0.878 / 0.941 | 48 / 40 / 11 / 3 |
| R_FULL-2334 SYSU | V | 0.785 / 0.667 / 0.638 / 0.755 | 0.075 / 0.106 / 0.118 / 0.094 | 0.952 / 0.907 / 0.892 / 0.940 | 同上 |
| R_LEAN-2334 SYSU | K | 0.653 / 0.667 / 0.713 / 0.750 | 0.176 / 0.173 / 0.156 / 0.142 | 0.710 / 0.724 / 0.771 / 0.817 | 708 / 176 / 43 / 11 |

- 224 原型（R_FULL/R_RES）的 K 收缩只有 8–23%，V 收缩 3–36%；只有 32 原型的 LEAN/COMPACT（网格 2×2）才收缩到 0.61–0.80。
- 池内成员半径 CV 只有 0.05–0.12（R_FULL），方向一致性 A = 0.87–0.96 —— 成员本来就几乎同向，所以 Lorentz 重心几乎不损失半径。这与 V2 S2 的结论一致：半径加权类算子（Einstein/OEM/re-anchor）缺少可作用的空间。
- ESS 在粗尺度只有 3–11，说明"每 cell 两类原型"在粗尺度上是由极少数有效样本决定的；这与小目标/弱变化丢失的方向一致，值得 S8 的自适应预算去检验。

## 5. 结论 D：Q 半径的真实量级与分布

| 臂/库 | s0 | s1 | s2 | s3 | CV |
|---|---|---|---|---|---|
| R_FULL-2334 SYSU | 0.971 | 0.871 | 0.891 | 0.940 | 0.19 / 0.14 / 0.17 / 0.12 |
| R_FULL-2334 LEVIR | 0.933 | 1.131 | 1.167 | 1.222 | 0.13 / 0.14 / 0.16 / 0.13 |
| R_FULL-2335 SYSU | 0.778 | 0.746 | 0.770 | 0.878 | 0.18 / 0.15 / 0.15 / 0.13 |
| R_RES-2334 LEVIR | — | — | 1.214 | 1.341 | 0.16 / 0.15 |

- 真实 Q 半径 **0.75–1.34**，比历史 diag 里记录的 0.54 大得多，也已超过随机初始化权重的理论上界 1.093（V2 r1 的 `asinh(σmax·√(C/D))`）——训练把权重谱推大了，所以"随机权重上界"不能当真实上界。
- 系统性差异：LEVIR > SYSU，且随尺度（s0→s3）上升；这与"更靠外的层级=更粗的语义/更大的感受野"方向一致，但结合结论 A，这个层级结构对任务判别没有贡献。
- CV 0.12–0.20，与 V2 r1 的合成 CV_Q（0.267）同量级；K 成员 CV 0.05–0.12 却小得多，再次说明"Q 与 K 半径不匹配"不是主因。
