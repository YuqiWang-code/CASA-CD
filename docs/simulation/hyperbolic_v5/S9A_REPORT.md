## 判读

1. **几何算子几乎不改变预测**：把 K 池化、V 池化、K+V 池化换成欧氏均值，F1 变化
   SYSU −0.36…+0.13 pp、LEVIR −0.01…+0.03 pp；把距离换成欧氏平方 −1.35 pp（SYSU）/
   −0.05 pp（LEVIR），加上 train 拟合的单标量 a 后 −0.60/−0.03 pp。
   这些差异远小于同一模型上"机制被破坏"的代价（见下一条）。
2. **机制本身是必要的**：NOCTX（把 context 残差置零）掉 SYSU −10.1 pp / LEVIR −5.9 pp；
   UNIFORM（注意力均匀）掉 −2.3 pp / −12.1 pp。也就是说 HRA 的**有无**比它的**几何形式**
   重要一个量级。
3. **先验项的作用与数据集相关**：DISTONLY（去掉 support 与尺度偏置）在 LEVIR 与 BASE
   持平（0.6758 vs 0.6756），在 SYSU 掉 −1.05 pp；PRIORONLY（去掉距离）在 LEVIR 掉
   −12.8 pp，说明 LEVIR 的检索主要靠距离项，SYSU 更依赖先验/偏置。
4. **V 聚合换成欧氏会放大 FP**：AGG 的 TP 在 SYSU 从 832 升到 895，但 FP 从 1850 涨到
   2463，F1 仅 +0.55 pp；LEVIR 则 −1.5 pp。所以"Lorentz V 聚合"没有证据说它更好，
   但换成欧氏也没有稳定的任务收益，属于可替换项而不是改进项。
5. **注意力与任务解耦**：KE 让注意力 JS 到 0.057/0.028，UNIFORM 到 0.34/0.27，
   但 F1 的变化只有 −0.26/−0.01 pp（KE）对 −2.3/−12.1 pp（UNIFORM）——注意力分布
   的小改动几乎不传到预测，改变到"均匀"才致命。

## 限制

- 绝对 F1 低于训练日志（SYSU 0.47），因为这里用 256² 双线性插值 + 固定 0.5 阈值，
  与训练评测口径不同；本表只做**同图配对比较**，不引用绝对值。
- 每库 8 张图、单 seed 权重；`a` 由 3 张 train 图拟合（无 val 泄漏），但样本量小。
- VE/AGG 的"注意力 JS=0"是因为它们只改 V 聚合、不改注意力；其影响体现在
  `max|Δlogit|`（AGG 2.55/3.95），报告里不要用注意力 JS 判断 V 侧改动。
