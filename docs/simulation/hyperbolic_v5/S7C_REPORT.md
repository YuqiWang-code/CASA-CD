# S7c 真实特征诊断报告（Run10 冻结 checkpoint）

本文件由 `tools/simulation/s7c_aggregate.py` + 表格生成脚本从原始 CSV 汇总，所有数字来自 `results/s7c_*.csv`（原始逐样本表在服务器 `analysis/simulation/S7c/`）。

## 1 数据来源与口径

| 项 | 值 |
|---|---|
| checkpoint | `Run10/<arm>/<dataset>/best_model.pth`（strict 加载） |
| 臂 | R_FULL-2334 / R_FULL-2335 × SYSU-CD-256 / LEVIR-CD-256（4 套齐全） |
| 选模 | `selection_split=val`、`independent_test=True`、protocol `casa_pyramid_40k_testselect_heads_detail_v12r3` |
| 冻结源码 | `Run10/runtime/models`，sha256 与 `runtime_manifest.json` 一致 |
| 数据 | 只用 `list/val.txt`（60 张）与 `list/train.txt`（32 张，分层），test 未参与 |
| 精度 | CPU、FP32、关 TF32、`eval()`；`S7B_THREADS=6` |
| 半径口径 | `rho = asinh(||z||)`，z 为真正送入 Lift 的坐标（Q/K 已除 √d 一次，V 不除） |
| 交叉验证 | `acosh(t)` 与 `asinh(‖z‖)` 的 max 偏差 = 7.0e-07（FP32 级） |
| parity | 插桩前向 vs 原前向：logit / 各级 logit / aux / 二值 / K-V / support 全部 0.0 |

**读法**

- 半径单独（P2）远弱于 guide logit（P1）；把半径加进 logit（P3）在整个网格上只带来
  **−0.003…+0.0024** 的 AUC 变化。SYSU 的 3 个尺度为正（seed-2334 的 CI 不含 0，
  幅度 +0.002），LEVIR 为 0 或负。**没有跨数据集一致的正向增量。**
- P4（原始投影范数）与 P3 几乎逐位相同——因为直接 Lift 的半径就是投影范数的单调函数，
  这与数学事实一致，不构成独立证据。
- P5（只用 train 拟合的独立方向特征）≈0.50–0.57，几乎无判别力；而 P5b（用 guide 条件
  构造的方向特征）0.85–0.98。**方向信息主要在 guide 里，不在特征几何本身。**
- 因此按方案 §4 的判定：继续暂停 OEM / 径向重锚 / 扩半径一类"把半径当自由度"的创新。

**读法**

- **K 的半径保留 0.79–0.90，V 的保留 0.67–0.96**；同一数据集内 V 普遍低于 K
  （SYSU：K 0.83–0.90 vs V 0.67–0.80）。这与 S7b 的"损失优先在 V 侧"一致，但幅度更温和：
  224 原型下 K 只压掉 10–21%、V 压掉 4–33%。
- 方向一致性 A=0.88–0.95、ESS/p=0.61–0.83，说明池化权重并不弥散，收缩主要来自
  **成员方向的部分抵消**，而不是权重集中在少数像素。
- 池内半径 CV 只有 0.06–0.13，远小于 1 → 等半径近似 `ρ_pool=atanh(A tanh ρ)` 在这里
  是可用的诊断式；配合 A 可解释"为什么收缩是温和的"。
- K 成员半径（约 0.9–1.2）明显大于 Q（0.78–1.17 的 Q 中位），即 **键在远离原点的一侧、
  查询在近侧**；由 `C=2·min(ρ_Q,ρ_K)`，角度可分辨上限由 Q 半径决定，而不是由池化后的键。

## 4 对旧结论的影响

| 旧表述 | 现在 |
|---|---|
| "K 被池化压到 Q 的 0.6–0.7" | 不成立：Q 与 K 是不同来源，比值没有物理意义；应看"原型/成员"保留率（K 0.79–0.90、V 0.67–0.96） |
| "半径对变化没有超出 guide 的增量信息" | 需限定：SYSU 有 +0.002 量级、CI 不含 0 但跨数据集不一致；只能说"未发现稳定可用的增量" |
| "V 侧损失更重" | 成立但幅度是 4–33%，且 LEVIR s3 几乎无损（0.96） |
| S7b 的 Q 半径数值 | 作废（口径含重复除 √d）；本报告用 `asinh(‖z‖)`，并有 `acosh(t)` 交叉验证 |
