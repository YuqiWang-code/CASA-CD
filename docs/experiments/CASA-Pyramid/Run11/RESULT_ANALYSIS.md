## SYSU 误报与内部漏检

H-simple 相对 CTRL 的 F1 提高 **0.4971** 个百分点，精确率提高 1.0722 个百分点，总体召回变化 −0.0111 个百分点。在排除 GT 两像素边界带后的内部统计中，FP 从 7,392,124 降到 6,745,170，FN 从 10,120,812 降到 10,039,912。收益主要来自误报减少。H-simple 比同构 E-simple 高 0.4944 个百分点。

## WHU 建筑边界

E-simple 的 1 像素边界 F1 为 83.6980%，比 CTRL 提高 0.6226 个百分点。H-simple 为 82.1768%，低于 CTRL 0.8986 个百分点，边界精确率和召回均下降。H-simple 的整体 F1 与 CTRL 接近，仍有清楚的边界差距。三种结构的内部加权版在 WHU 的整体 F1 均低于各自的普通损失版。
