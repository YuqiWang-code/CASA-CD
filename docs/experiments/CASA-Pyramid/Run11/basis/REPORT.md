# Run4 / Run10 冻结权重验证干预（2026-11-04）

**建议：移除 Run10 的后验修正，保留逐位置全局检索、可变半径和局部细节路径；保留粗层写回强度。SYSU 的下一步优先检验前景内部漏检，而非叠加边界模块。**

## 口径

- Run4（eb3babe）与 Run10（8e8e559）各用实际归档源码及双曲版 best_model.pth，阈值0.5，FP32、eval、关闭TF32。全量val：WHU 743、SYSU 4000、LEVIR 1024、CDD 2998；四库val文件列表分别与train、test无文件名交集。原checkpoint由历史test选模。
- 后验关闭：令几何修正为0，保留一阶guide池化、K/V共用权重和其他路径。Run4本来没有后验，记为不适用。
- 固定检索半径：每图、每查询尺度、每头，以原查询平均内在半径替换全部Q和K半径，方向不变；原型压缩与Run10后验不变。它检验检索对径向信息的依赖，不能单独证明双曲度量优于欧式。
- 全局写回关闭：令全局gamma为0，保留TAR和局部细节。Run4同时去掉AV−V_query整项；额外测量查询间平均注意力，保留V_query减项和原型平均采用权重，用于区别逐位置检索。
- 缓存同一批TAR输入；每个数据集首批完整预测与原predict对齐。逐图保存干预纠正及新增的FP/FN，并核对净变化等于新增减纠正。误报/漏检为像素数；覆盖<10%按8连通真值组件计算。边界F1用1输入像素容差；边界带FP/FN指GT形态学梯度带内分割错误，二者口径不同。

## WHU边界与SYSU漏检

**WHU：保留全局写回。** Run10关闭后，虽然全图净FN减少14,226，GT边界带内FN却增加883，净FP增加39,709；边界F1从82.5798%降至81.1356%，边界精确率从84.5902%降至80.9704%，召回从80.6628%升至81.3016%。主要代价是多报边缘，不能用全图FN下降判断轮廓更好。Run4关闭写回后FP、FN同时增加；用平均注意力替代逐位置检索，即便保留本地减项，WHU F1仍下降48.4668pp，说明该权重严重依赖逐位置读出。固定半径让两轮WHU的全图FP、FN同时增加。

**SYSU：全局检索减少漏检，代价是更多误报。** 关闭写回后，Run4/10分别净新增2,772,068/2,482,098个FN像素，覆盖<10%组件增加283/354个。Run10固定半径仅减少27,950个FP，却新增199,266个FN；Run4固定半径减少95,170个FN但新增332,233个FP。固定半径在两轮都降低F1与边界F1。Run10原始模型较Run4多漏739,229像素，其中678,292（约92%）位于GT的2像素边界带之外；同时覆盖<10%组件由1,352降至1,284。两份权重的差异主要指向已标注前景内部覆盖不足，不能简单归为小目标整块漏检。跨轮存在共同训练和结构差异，不能把它全部归因于某个模块。

**后验修正：可以先删。** 四库关闭后最大F1变化仅0.0110pp。WHU少漏325像素、多报54像素，但边界F1下降0.0222pp；SYSU少报2,500、多漏707，覆盖<10%组件数不变。这里统计的是实际翻转净量，逐图CSV另保留新增与纠正的毛量。

## 下一版具体改法

1. **结构只做减法。** 删除P0锚点构造、局部几何后验、压缩温度和posterior BCE。归一化TAR后计算p=sigmoid(guide)，每区域按p与1−p各做一阶归一化池化，K/V共享权重；支持度保持权重乘原guide的加权均值。保留完整Q、224个跨尺度KV、可变径向Q/K、现有中心化写回、各层gamma及细节分支。先以冻结等价性验证新直连池化与posterior_off输出一致。
2. **优先检验内部漏检，单独对照。** 结构简化组保持共同训练设置，辅助目标回到0.1 raw-guide BCE。另设一个训练损失候选：仅对首级分割BCE中位于GT两像素边界带之外的前景像素赋权1.25，其余权重1，按总权重归一化；Dice、其余级与推理路径保持原样。先和相同简化结构的未加权版本比较，避免把训练收益算给几何。
3. **验收按实际错误而非只看一个F1。** SYSU比较固定0.5和匹配误报量下的前景内部FN、召回、组件覆盖；WHU检查1px边界F1与FP是否守住。用Run4完整模型作历史参照，并保留相同训练设置的CTRL和匹配欧式组，判断几何是否有可归因增益。冻结干预只评价现有权重对路径的依赖；结构删减或损失变化的训练结果仍待验证。
