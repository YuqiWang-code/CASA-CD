# CASA Run3 与 Run5 模块分析

## 当前模型

当前代码采用 Run3 结构（模型源码基线 `bd1d9a7`，正式运行基线 `6776fa2`）：

- 普通模块：LayerNorm 后的两时相绝对差生成软分配；完整 Q 查询压缩 K，以时相差分 V 聚合。
- 双曲模块：同位置双曲距离生成软分配；Q/K/V 在球内进行几何压缩、距离注意力与变化位移聚合。
- 两个模块均保留每个 4×4 区域两个原型、N 个 Q、N/8 个 KV、局部分支和残差。
- 训练采用四级 BCE+Dice，模块参数 WD0、主体 WD1e-4。训练接口、profile 与测试程序和此结构一致。

参数量：CTRL 3,100,404；双曲模块模型 3,134,332；普通模块模型 3,143,036。服务器 CPU 检查通过，Run3 两个模块 checkpoint 均能严格加载，部署折叠最大误差 5.96e-8，二值差异为 0。当前无训练。

Run3、Run4、Run5 的源码归档、checkpoint、正式指标和冻结 TXT 均保留。历史权重使用对应轮次源码；当前快照为 `models_and_metrics_CASA_current.txt`。

## 正式结果的变化

相对同轮 CTRL 的 F1 增益，单位为百分点。每项均为 seed 2333 的单次实验。

| 数据集 | 双曲：Run3 → Run5 | 普通：Run3 → Run5 |
|---|---:|---:|
| LEVIR | +0.37 → +0.26 | +0.06 → +0.14 |
| SYSU | −0.31 → −0.67 | −0.78 → −0.56 |
| WHU | +0.37 → −0.55 | −0.01 → −1.02 |
| CDD | +0.02 → +0.05 | +0.03 → +0.04 |

退步主要集中在 WHU；双曲模块在 SYSU 的相对收益也降低。普通模块在 LEVIR、SYSU 的相对收益改善，但 SYSU 仍未超过 CTRL。Run5 的绝对 F1 并非全面下降。

## 辅助监督与上下文选择的目标冲突

分配头同时接受主分割损失和变化占据率分类监督。分类监督要求每个位置预测变化比例；主任务要求这些分配能产生有利于最终分割的 K/V 原型。两种目标没有等价关系。

0.1 的辅助系数不能直接解释为较弱的影响。辅助项直接作用于分配头；主分割损失到分配头的路径经过原型归一化、池化、注意力、输出投影、残差门和解码器，梯度可能较小。

对 Run5 最佳 checkpoint 的 CPU 抽查：每库在均匀分布的 64 个候选位置中，选取 8 张含真实变化的验证图，组成 4 个 batch。计算同一分配头参数上主损失梯度与已乘 0.1 的辅助梯度。余弦为负表示两者的局部优化方向冲突；比值为辅助梯度范数除以主任务梯度范数。

| 模块与数据集 | 层 | 梯度余弦中位数 | 冲突 batch 数 | 辅助 / 主任务梯度范数比中位数 |
|---|---:|---:|---:|---:|
| 双曲 SYSU | 3 | −0.654 | 3/4 | 7.41 |
| 双曲 SYSU | 4 | −0.773 | 3/4 | 3.96 |
| 双曲 WHU | 1 | −0.619 | 4/4 | 16.80 |
| 双曲 WHU | 4 | −0.324 | 4/4 | 1.25 |
| 普通 SYSU | 1 | −0.438 | 3/4 | 3.42 |
| 普通 SYSU | 2 | −0.315 | 3/4 | 1.33 |

这表明辅助分类目标在实际验证样本上可能主导或干扰原型分配。普通 WHU 并非所有层都有明显冲突，因此该机制不能独自解释全部退步。完整样本索引和逐批次结果见 [梯度诊断数据](CASA_Run5_assignment_gradient_analysis.json)。

## 几何稳定与判别信息

Run5 的共同中心与联合 RMS 阻止了整体幅值增长导致的半径集中。完整四库日志中，半径 CV 最低约 0.160，裁剪比例最高约 5.27%，没有 Run4 的整体饱和。

该变换同时移除了分支中的共同偏置与整体绝对幅值：对两时相共同增加相同向量或共同乘正比例，归一化后的表示保持不变。Q/K 和 V 都重复执行这一步，原有双曲坐标、距离和变化位移的分布随之改变。原始欧氏残差仍然保留，但几何检索分支不能再利用这些被消去的量。

稳定的半径分布说明数值与分布状态得到控制，不能直接说明上下文对分割更有价值。被消去的分量是否包含有用判别信息，需要独立消融确认。

Run3 完整四库日志中最低半径 CV 约 0.060，没有 Run4 的整体上限饱和。Run3 某些层的注意力仍偏平均，但其 WHU 测试成绩高于 Run5。半径 CV 与注意力熵适合作为退化诊断，不能替代任务指标判断。

## 泛化问题

WHU 普通模块：Run3 最佳验证 F1 为 94.62%，测试为 93.94%；Run5 最佳验证为 94.80%，测试为 93.41%。验证改善而测试下降，说明模块的验证收益没有稳定迁移到测试集。

SYSU 的后期泛化下降也出现在 CTRL 中。Run5 最佳验证 epoch 为 CTRL 9、双曲 4、普通 11；三组最后验证 F1 为 78.75%、78.98%、79.56%。系统性的泛化问题不能只靠调整双曲半径解决。

两种模块在 SYSU 的错误方向不同：双曲相对 CTRL 的精确率下降 4.27 个百分点、召回率提高 2.82 个百分点，主要表现为误检增多；普通模块精确率提高 0.99 个百分点、召回率下降 1.88 个百分点，仍有漏检问题。

## 对照与结论范围

同样的 CTRL 在 Run3 与 Run5 间，F1 变化为 LEVIR +0.31、SYSU +0.95、WHU +0.48、CDD −0.03 个百分点。当前脚本固定 seed，但未固定确定性算子，跨轮 CTRL 确有波动。因此相对同期 CTRL 的增益比直接比较跨轮绝对分数更有参考价值，仍需多次重复。

Run4 没有完整正式结果，Run3 到 Run5 同时改变了分配头、辅助损失和双曲归一化，不能从现有结果独立量化每项改动的贡献。梯度抽查覆盖最佳 checkpoint 的 8 张含变化验证图，反映局部优化压力，不等同于完整训练轨迹或 Adam 的实际参数更新方向。

LEVIR 普通模块的第 3、4 层在四个抽查 batch 中也均有负梯度余弦，但辅助/主任务范数比中位数分别只有 0.11、0.29，正式相对增益仍为正。梯度方向冲突与作用强度需要一起看，不能把出现负余弦直接视为测试退步的充分原因。

## 后续验证方向

以当前 Run3 结构为基线，在 WHU、SYSU 分别检验分配头、辅助分类损失和几何归一化，每次只改变一项，并同期重复 CTRL。普通模块重点关注上下文选择是否减少漏检；双曲模块分别检查误检、几何信息保留和稳定性。实验启动需采用新的独立轮次。
