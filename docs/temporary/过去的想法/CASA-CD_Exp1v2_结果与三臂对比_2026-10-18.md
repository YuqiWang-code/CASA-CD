## 3. 机制归因（数据支持）

1. **小目标方向在两库都赢了**：small pooled R 相对 CTRL **LEVIR +1.80pp / SYSU +2.77pp**；
   Hit@25 **+2.10pp / +2.47pp**。这是本项目在 SYSU 小目标上**首次同时超过同期 CTRL**。
2. **碎片化被压回去了**：SYSU <256px 未匹配 4393 → 3152（回收了 v1 回归的 86%），
   ObjP 0.4189 → 0.4776；LEVIR 也维持 551 → 563（优于 CTRL 的 585）。
3. **代价只在"大目标/整体像素召回"**：SYSU large pooled R −0.34pp、medium −4.33pp（相对 v1），
   LEVIR large −0.42pp（相对 CTRL）⇒ 净像素 F1 被抵消到 −0.03/−0.16pp。
   机制解释：证据注入在 1/4 尺度上以**负 γ** 工作（抑制），抑制不分尺度地对齐到了大目标。
4. **统计口径提醒**：0.03–0.16pp 的单 seed 差异属于本项目一贯的噪声量级
   （项目纪律明确"单 seed 不做显著性声明"）⇒ 诚实表述是：
   **v2 在像素 F1 上与 CTRL 持平，在小目标召回与碎片化上明显更好。**

## 4. 结论与下一步

* v2 证明了两件事：**(a) 结构张量测地证据确实携带小目标增益**（两库同向）；
  **(b) 碎片化归因正确**（改池化+跨尺度门即回收 28%）。
* 剩下的唯一缺口是"净像素 F1 不升"，其来源是**注入形态**（负 γ 的全局抑制在大目标上也有副作用）。
* 因此下一臂应改**形态**而非强度：
  **B（监督形态）** —— 把 `d_shape` 作为辅助监督目标（λ=0.2 固定、不注入），
  让梯度压回浅层结构表征。这是本项目唯一被验证有效的形态（Run7 E9：SYSU +0.63pp），
  **需用户批准新增 1 条损失**。
  备选 **C（Beltrami/各向异性扩散）**：进一步压碎片，但仍是注入形态，不解决大目标代价。
* 纪律：**不得**调 γ、阈值、σ、seed 去把这 0.03/0.16pp 挤回来。
