# CASA-CD 专题深度调研：双曲几何能否区分真实变化与伪变化、能否检测极小目标变化？

**版本**：2026-10-14｜**性质**：文献核验 + 代码审阅 + 可证伪实验设计，**非新实验结果**。  
**任务边界**：全监督 RGB 双时相二值变化检测；仅 CDD-CD-256、LEVIR-CD-256、SYSU-CD-256、WHU-CD-256；不新增 loss、不更换种子/评估阈值、不引入推理 teacher、不越过 deploy ≤5M。  
**仓库快照**：[YuqiWang-code/CASA-CD](https://github.com/YuqiWang-code/CASA-CD)，核对版本 `23eb250cd48bb012ffaafc908dd1daafa560aec2`，提交时间 2026-10-12 04:39 UTC。服务器可能存在尚未提交的修改，须以服务器实际身份最终确认。  
**本次问题**：①双曲空间能否区分真正地物变化与光照/阴影/季节/视角/配准等伪变化？②能否让 1–255 px 尤其 1–15 px 小目标变化更容易被识别？③在 TinyViM 高频 `RepDW` 和 Stage3 CAACP 的两处具体怎么做，什么样的证据才能证明“双曲几何不可替代”？

## 0. 结论先行：可能有用，但现有论文没有证明“负曲率本身能可靠识别小目标或伪变化”

**可直接确认的研究基础：**

1. **有直接遥感 BCD 先例，不是空白。** 2024 年 IEEE JSTARS 的 **HES-Net** 用双曲相似性注意力（HSAM）处理双时相特征，在 CDD、LEVIR-CD 上报告改进，讨论了季节复杂区域、小面积变化和模糊边界；2026 年 IEEE TGRS 的 **HyperCLIP-CD** 又引入双曲图文语义对齐。**因此“首次把双曲空间用于遥感变化检测”绝对不能写。** [R1][R3]
2. **细粒度树木变化也有先例，但它不是像素级小目标分割。** **CVPR 2025 HSN** 使用孪生特征差分→低维投影→Poincaré 球→双曲二分类，基于 UAV 单棵树 ROI 判断“这棵树是否变化”，而**不是**预测 256×256 的每个变化像素。它的光照、阴影鲁棒性描述有价值，但不能直接推导 CASA-CD 的 small-object pixel Recall。该论文以 ROI 二分类 F1=0.7372 报告结果，而非 LEVIR/SYSU 二值分割 F1。[R2]
3. **伪变化来自至少两种不同物理机制。** TGRS 2026 **RGCDNet** 明确将辐射/阴影和配准误差区分，分别采用辐射抑制与几何协同配准。它的“geometric”是成像/配准几何，**不是**双曲流形。只把两个特征的距离换成双曲距离，不能自动消除空间错位。[R4]
4. **高频≠小目标。** TinyViM 的高频支路保留局部纹理，纹理、边缘、阴影、噪声均可激活；真正的小目标是**有时相一致的目标结构证据**，而非“大高频幅值”。[R8]
5. **只做 `d_H(F_A,F_B)` 创新性不足，并可能数学退化。** 在固定双曲半径、固定曲率下，双曲测地距离随特征夹角单调变化；若随后执行 CAACP 的逐图 rank，排序可能与 `1-cos` 完全相同。通过双曲映射**不会凭空增加原始特征的信息**；它只能改变模型的归纳偏置、可分性和特征训练过程。
6. **最先应验证的是“跨时相局部关系是否改变”，再研究“负曲率是否优于同式欧氏”。** 可在高频阶段把几何关系作为 **Run7 已有 HFAE 辅助头的训练期条件信息**（部署整头删除），低频只**替换原有 CAACP score 算子**，不增加第二条不可折叠的推理支路。这样比“推理期 64×64 双曲高频注意力 + 新解码器”更符合项目约束。

**当前证据裁决**：文献提供**存在性证据**（双曲表示可能改善特定变化任务）；但对 CASA-CD 四库中**区分真实/伪变化和提高 tiny/small recall 的直接证据仍缺失**，还不能断言一定提高 Precision/Recall/F1。

## 1. 逐项厘清：“双曲几何识别变化”到底识别什么？

### 1.1 三类“伪变化”，误判原因不同

| 伪变化类型 | 典型现象 | 点对点 `1-cos` 的风险 | 局部关系几何的潜在作用 | 其自身的失败风险 |
|---|---|---|---|---|
| 辐射/光照 | 同一地物整体变亮/变暗、曝光改变 | A/B 对应特征整体偏移 | 若**邻域内部关系形状**基本保持，可抑制共同变化 | 深层特征未必对亮度是等距变换；阴影边界可能改变局部关系 |
| 阴影/季节/纹理 | 阴影位置变化、树叶纹理或季节变化 | 大面积高差异但 GT=不变 | 若仅外观改变而邻域结构稳定，关系统计可较稳定 | 季节变化本身可改变几何纹理结构，甚至比真实小变化更明显 |
| 配准/视角 | 房屋、路缘成双边缘，1px 位移产生差异带 | 对应空间位置比较错误 | 适当的局部容差或匹配可能降低误报 | **双曲距离本身不解决错位**；邻域关系若按位置硬对齐，可能对错位更敏感 |

关键限制：若时相 A 的所有特征经历的是**同一个距离保持变换**（isometry），其内部两两测地距离不变；然而真实的亮度/阴影/成像改变**不一定**是双曲空间等距变换，不能把数学等距不变量直接称作“光照不变”。

### 1.2 不是单靠“双曲半径”就能知道是真变化

Poincaré 球内，向量的半径能参与编码语义层级/不确定性；但它不自带“真实变化=外圈、伪变化=内圈”规则。**CVPR 2025 HypCD** 的半径/角度用于类别发现；**CVPR 2026 HyperProtoSeg** 的原型、可信核心和边界用于持续测试时分割。这些任务都有与 CASA-CD 不同的监督/类别结构。[R9][R10]

在仅有 **change / unchanged** 二元 mask 的 CASA-CD 中，“小目标、建筑、阴影、背景纹理”不是天然提供树状类别标签的数据结构。用额外多个双曲原型硬把它们当作层次结构，属于**待证假设**而非公理。

### 1.3 “原始图像映射”与“特征图映射”有很大区别

合理的做法：

`A/B (RGB) → 共享 TinyViM → 1/4/1/8 高频特征 & 1/16 特征 → 双曲空间暂时映射 → 几何关系标量图 → HFAE 辅助梯度 / CAACP 固定网格权重 → 原本的欧氏特征与 SS2D/TAR/DCR`。

不建议整个编码器、SS2D selective scan、全部卷积的激活长期待在双曲空间；既会破坏原有预训练和 kernel 假设，也难以满足 5M 与推理延时。此处可研究的是**流形辅助的变化判别**，不是“模型全部双曲化”。

## 2. 针对“真变化 vs 伪变化”的直接论文：全文与实验该如何解读

### [R1] HES-Net（必须精读，已发表）

- **论文**：Qian Yang et al., *Hyperboloid-Embedded Siamese Network for Change Detection in Remote Sensing Images*, **IEEE JSTARS 2024**, 17:9240–9252，SCI 期刊（非 CCF-A）。
- **出版社/DOI**：https://doi.org/10.1109/JSTARS.2024.3390427
- **核实内容**：提出 **HSAM（Hyperbolic Similarity Attention Mechanism）**，把双时相深层特征映射到双曲空间，由双曲距离构成注意力，再经差异增强解码；在 CDD 和 LEVIR-CD 的同论文协议报告改进，作者强调季节背景、小区域和边缘细节。作者正文消融报告相对自身 Siam-UNet：单加 HSAM，CDD/LEVIR 的 F1 分别提升 **2.25 / 2.88 个百分点**；加入 DFEM 后整体提升更大。**这是 HES-Net 内部口径，绝不可当作 CASA-CD 的可预期提升量**。
- **对本课题的直接警告**：它已覆盖“点对点双曲距离→变化注意力”和“增强小区域细节”；CASA-CD 不得只把 `1-cos` 改成 `d_H` 就主张新颖。另其计算/硬件/训练预算与 TinyViM 不相同，不能凭论文结论说本项目零推理代价。
- **代码**：本次未核实到作者官方独立 GitHub，**不编造链接**。
- **证据评级**：**直接 BCD 先例，高；小目标效应来自定性及一般性能，并非分面积精细量化**。

### [R2] HSN / UAVTC（CCF-A CVPR 2025，已发表）

- **论文**：Yante Li et al., *Deep Change Monitoring: A Hyperbolic Representative Learning Framework and a Dataset for Long-term Fine-grained Tree Change Detection*, **CVPR 2025**，pp. 27346–27356。
- **官方**：https://openaccess.thecvf.com/content/CVPR2025/html/Li_Deep_Change_Monitoring_A_Hyperbolic_Representative_Learning_Framework_and_a_CVPR_2025_paper.html
- **原文 HTML（可读取公式/实验表）**：https://arxiv.org/html/2503.00643
- **作者 GitHub（已核实存在）**：https://github.com/liyantett/Tree-Changes-Detection-with-Siamese-Hyperbolic-network
- **源码核对**：该仓库 `Train.py` 使用 ResNet18 提取 A/B 特征 → `abs(x1-x2)` → 全连接 → `hyptorch.nn.ToPoincare` → `HyperbolicMLR` 的**二分类路径**；`hyptorch/pmath.py` 中确有 Poincaré `expmap0`、`dist`、`mobius_add`，不是仅名字包含 hyperbolic。作者公开仓库也含 `hyptorch/nn.py`。但未看到能够直接拿来对 256² 每像素做输出的 BCD 全流程。
- **关键**：UAVTC 一共 245,616 个成对**树木 ROI**，其中约 72% 为变化对、28% 不变对；报告 F1 0.7372，任务是单棵树变化**分类**。即使 CAM 对树木/阴影有区分，也不能据此声称其精准检测“1–15 px 变化目标”。
- **原文几何证据**：第 4.4 节报告不同骨干的相对 δ-hyperbolicity：ResNet18 0.172、ResNet34 0.144、ResNet101 0.114、VGG16 0.212，用于说明**树木 ROI 表征**具有某种树状几何性；这**不是** CASA-CD TinyViM 1/4/1/16 像素局部特征的实测 δ。
- **结果纪律提示**：论文实验说明欧氏 Siamese 使用 SGD+momentum，HSN 使用 AdamW。因此仅看跨模型 F1 差异无法严格分离优化器与几何的作用；这不是否定论文结果，而是提醒本项目必须用**相同优化器、预算、seed 与同式欧氏对照**。
- **证据评级**：**环境伪变化与双曲层次表示的直接相关先例；非像素小目标 BCD**。

### [R3] HyperCLIP-CD（IEEE TGRS 2026，已发表）

- **论文**：Qian Yang et al., *HyperCLIP-CD: Hyperbolic Multimodal Representation Enhancement for Remote Sensing Change Detection*, **IEEE TGRS 2026**, DOI 10.1109/TGRS.2026.3670127。
- **出版社**：https://doi.org/10.1109/TGRS.2026.3670127
- **公开摘要所示**：提出基于 CLIP 的双分支视觉/文本表示与双曲图文语义对齐（HMSA），评价提到 LEVIR-CD、CDD 及语义变化数据 SECOND。说明双曲多模态变化表征已被引入这一领域。
- **不同点**：依赖图文语义层次/CLIP，不等于本项目的无附加重型 teacher 的 TinyViM 高频小目标关系，**不能直接移植推理架构**。
- **代码**：本次未核实作者官方仓库。
- **证据评级**：高层创新边界，**没有直接可核小目标分组数据**。

### [R4] RGCDNet（IEEE TGRS 2026，已发表，但不使用双曲）

- **论文**：Xia Zhang et al., *RGCDNet: Radiometric–Geometric Collaborative Learning for Change Detection in Remote Sensing*, **IEEE TGRS 2026**。
- **出版社**：https://doi.org/10.1109/TGRS.2026.3683370
- **作者给出代码仓库（已核实存在）**：https://github.com/4043-lab/Change-detection
- **公开摘要**：MSR-SS 侧重光照阴影辐射干扰，CRM 使用多尺度双向形变/融合配准抑制几何失配。作者公开说明 LEVIR/SYSU/WHU 的实验，但其指标不是与 CASA-CD 同划分同训练协议的控制结果。
- **核心启示**：双曲**特征空间几何**不能替代**影像空间的几何对齐**，不能把“伪变化可抑制”写成单纯负曲率必然成立。

### [R5] CASP：Exploring Context Alignment and Structure Perception for Building Change Detection（IEEE TGRS 2025）

- **官方摘要**：https://doi.org/10.1109/TGRS.2025.3540013
- **作者代码（已核实存在）**：https://github.com/ptdoge/CASP
- **相关机制**：利用差异引导对齐与结构感知融合降低错位误报、增强建筑形状表征。**不是双曲流形**，但可当“只做结构与对齐，不引入双曲”的科学对照动机。

### [R6] HA2F（IEEE TGRS 2026）

- **官方 IEEE 页面**：https://ieeexplore.ieee.org/document/11328896/
- **DOI**：https://doi.org/10.1109/TGRS.2025.3650706
- **相关机制**：双模块的层间特征选择、变化敏感区域与阴影/无关区域抑制；在 LEVIR/WHU/SYSU 上测试。**不等于双曲几何方法**。
- **代码**：IEEE 正文给出 Hugging Face 代码资源：https://huggingface.co/InPeerReview/RemoteSensingChangeDetection-RSCD.HA2F；GitHub 未核实。

**判断**：至少三个 2024–2026 的工作已经从“不同特征空间、结构、对齐、阴影”多个角度处理变化中的伪差异。CASA-CD 新工作必须清晰回答：**哪一种伪差异真的在局部关系分布中表现不同？双曲负曲率相对欧氏几何为什么提高了区分度？**

## 3. 针对“小目标、边缘和高频”的高水平工作

### [R7] TMACNet（ISPRS JPRS 2024，小目标变化，非双曲）

- **论文**：*Small object change detection in UAV imagery via a Siamese network enhanced with temporal mutual attention and contextual features: A case study concerning solar water heaters*。
- **出版社**：https://doi.org/10.1016/j.isprsjprs.2024.09.027；ISPRS Journal of Photogrammetry and Remote Sensing，2024，218：352–367。
- **机制**：双时相差异分支、时间互注意力、上下文注意力，面向 UAV 小目标变化，说明**小目标需要时相关联与周围上下文，而非仅提高高频幅度**。
- **迁移边界**：其太阳能热水器目标检测设定与 CASA-CD 四库二值分割不相同；没有流形几何独立性证据。
- **代码**：未核实到作者正式 GitHub。

### [R8] TinyViM（CCF-A ICCV 2025，高低频解耦的已知架构）

- **论文**：Xiaowen Ma et al., *TinyViM: Frequency Decoupling for Tiny Hybrid Vision Mamba*，**ICCV 2025**。
- **CVF**：https://openaccess.thecvf.com/content/ICCV2025/html/Ma_TinyViM_Frequency_Decoupling_for_Tiny_Hybrid_Vision_Mamba_ICCV_2025_paper.html
- **作者代码**：https://github.com/xwmaxwma/TinyViM
- **已验证动机**：Mamba 更偏低频，借 Laplace mixer 让低频进 Mamba，完整高频通过轻量 RepDW 局部分支；高频并不专门判定变化。在 CASA-CD 中应保留 dense 高频，不能把高频 64² 再聚成 TopK 后拿去替换 SS2D scan。

### [R9] Hyperbolic Category Discovery（CCF-A CVPR 2025）

- **CVF**：https://openaccess.thecvf.com/content/CVPR2025/html/Liu_Hyperbolic_Category_Discovery_CVPR_2025_paper.html
- **作者代码**：https://github.com/Visual-AI/HypCD
- **可借鉴**：双曲角度与测地距离共同建模层次，提醒我们不能只看一个 `d_H`；但其 generalized category discovery 不是遥感变化二值分割，不可直接声称会增强 tiny 目标召回。

### [R10] HyperProtoSeg（CCF-A CVPR 2026）

- **CVF**：https://openaccess.thecvf.com/content/CVPR2026/html/Gole_Hyperbolic_Prototype_Learning_with_Uncertainty-Aware_Consistency_for_Continual_Test-Time_Segmentation_CVPR_2026_paper.html
- **可借鉴**：双曲原型空间与可信 core/不确定 boundary 的分区；提醒“几何得分应考虑可靠性”。
- **边界**：作者做测试时持续适应、另有方向一致性损失；CASA-CD 不做新 loss 和在线更新，也不建立昂贵训练-部署原型库。当前没有核实其官方 GitHub。

### [R11] Flattening the Parent Bias（CCF-A CVPR 2024）

- **CVF**：https://openaccess.thecvf.com/content/CVPR2024/html/Weber_Flattening_the_Parent_Bias_Hierarchical_Semantic_Segmentation_in_the_Poincare_CVPR_2024_paper.html
- **代码**：https://github.com/tum-vision/hierahyp
- **关键负证据**：双曲分割在某些设置里改善了层级节点置信度校准，但像素分割准确率**与平坦欧氏基线相近**。这说明“几何更合理”不自动推导为“像素 IoU 更高”。

### [R12] HyperGRAM（CCF-A CVPR 2026）

- **CVF**：https://openaccess.thecvf.com/content/CVPR2026/html/Na_Hyperbolic_Gramian_Volumes_for_Multimodal_Alignment_CVPR_2026_paper.html
- **代码**：https://github.com/uta-smile/HyperGram
- **方法论提示**：作者明确指出纯双曲不一定改善类别区分，其方法采用欧氏/双曲混合几何。**建议 CASA-CD 先做“同式欧氏局部关系 + 双曲局部关系”可证伪对照，不设双曲必赢的结论。**

### [R13] HyperCLIP（CCF-A CVPR 2025，非遥感 BCD）

- **CVF**：https://openaccess.thecvf.com/content/CVPR2025/html/Peng_Understanding_Fine-tuning_CLIP_for_Open-vocabulary_Semantic_Segmentation_in_Hyperbolic_Space_CVPR_2025_paper.html
- **相关机制**：双曲径向位置可以对应图像级/像素级语义层次，但这来自 CLIP 图文特征；不能拿它的径向语义直接解释 CASA-CD 的二值变化。

### [R14] FreMamba（SCI IEEE TGRS 2025，频率两支路，非双曲）

- **IEEE**：https://doi.org/10.1109/TGRS.2025.3642908
- **相关机制**：高频 HSGE、低频 LSGA + Mamba，强调全局上下文与局部几何细节协同。但这是**高光谱变化检测**，`geometric` 指图像空间细节/边缘，不是双曲黎曼几何，也不属于 CASA-CD 要运行的数据集。

**综合文献裁决**：

- **双曲直接变化检测**：HES-Net、HyperCLIP-CD；树木变化 HSN，仍有开创性，但不能照搬。
- **真伪变化分离**：RGCDNet、CASP、HA2F 从物理/配准/结构层面提示必须做强伪变化诊断。
- **小目标检测**：TMACNet、TinyViM 提示小目标的关键是早期结构细节、时相证据与上下文，而非使用某种数学空间的名称。
- **双曲几何的独立价值尚有争议**：Flattening the Parent Bias、HyperGRAM 是必须认真放入 Related Work 与消融设计的反向证据。

## 4. 代码对照：CASA-CD 此刻实际处于什么位置

## 5. 关键数学论证：什么情况下双曲只是余弦变换？

### 5.1 Poincaré 球的映射和距离

取曲率 `−c` (`c>0`)，欧氏切空间向量 `v∈R^d`，原点指数映射为：

\[
\operatorname{Exp}^{c}_{0}(v)=\tanh(\sqrt c\|v\|)\frac{v}{\sqrt c\|v\|},\quad \operatorname{Exp}^{c}_{0}(0)=0.
\]

这里采用 `g_0=4I` 的常见指数映射约定，不同开源库可能对切向量定义含 `1/2` 缩放，**实施时须与相应库约定统一**。Poincaré 球内距离：

\[
d_c(u,v)=\frac{2}{\sqrt c}\operatorname{asinh}\left(
\frac{\sqrt c\|u-v\|_2}{\sqrt{(1-c\|u\|_2^2)(1-c\|v\|_2^2)}}
\right).
\]

推理时对输入缩放、范数截断、球边界夹紧，距离计算强制 fp32，防 NaN/Inf。

### 5.2 固定半径退化：单点双曲得分常常没有新信息

如果两个点到双曲原点的距离同为 `r`，夹角为 `θ`，双曲余弦定理给出：

\[
\cosh(\sqrt c\,d_c)=\cosh^2(\sqrt c\,r)-\sinh^2(\sqrt c\,r)\cos\theta.
\]

固定 `r,c` 时，`d_c` 随 `1−cosθ` 严格单调增。因此直接将 `1−cos(F_A,F_B)` 改为固定半径 `d_H(F_A,F_B)`，再走 CAACP 的 `argsort().argsort()`，在没有数值 tie 时可能**逐像素完全同序**。即使 F1 变动，也未必能证明负曲率的独立作用。

**必须做 Rank-Parity 单测**：在固定半径输入上比较两者 rank；任一候选若没有区别于同式欧氏的可测信息，不能叫“新的双曲变化判别”。

### 5.3 负曲率不是信息增益器

对固定编码器输出 `F`，一个可逆的指数映射 `Exp(F)` 并不增加关于 GT 的信息；在理想无限容量分类器下，最优可分能力不会因坐标变化凭空增强。若下游网络受参数、距离函数、优化、数值形式限制，双曲映射**可能改变归纳偏置、几何分离、梯度分布**，于是有实际性能差异。**因此必须比较相同容量、相同训练协议、相同邻域公式的 Euclid/Hyp 实现**。

## 6. 一个更值得尝试的机制：跨时相局部测地关系形状变化（GTRC）

### 6.1 思想：比较“各时相内部的邻域关系”，而非只看 A/B 中心向量

给定共享编码器特征 `F_A,F_B`，在像素/Token 位置 `p` 取固定 3×3 的 8 邻域 `N_8(p)`，将特征按**相同映射/尺度/曲率**投影为 `z_t(p)`。定义一个时相内部的**8 条局部关系边**：

\[
 e_t(p,k)=d_c\big(z_t(p),z_t(p+\delta_k)\big),\quad t\in\{A,B\},\; k=1,\ldots,8.
\]

为了过滤“局部距离统一变大”而聚焦于**邻域距离结构是否变形**，对每个位置构成的 8 维边长向量作归一化：

\[
\hat{\boldsymbol e}_t(p)=\frac{\boldsymbol e_t(p)}{\|\boldsymbol e_t(p)\|_2+\varepsilon},\quad
R_{\rm rel}(p)=m(p)\left[1-\hat{\boldsymbol e}_{A}(p)^\top\hat{\boldsymbol e}_{B}(p)\right],
\quad m(p)=\mathbb{1}\left[\|\boldsymbol e_A(p)\|_2+\|\boldsymbol e_B(p)\|_2>\varepsilon\right].
\]

`e≥0`；`m(p)` 是零向量保护：**当两时相的 8 条局部边全部为 0 时，强制 `R_rel=0`，不可出现 `1−0=1` 的伪变化**。当所有非零边长乘同一个正常数时，理论上 `R_rel=0`（忽略 eps 与量化误差）；当某几条边的比例变化，`R_rel>0`。实际实现还必须只保留影像范围内的有效邻边，避免 padding 制造虚假局部关系。**这是建议算子，不是已发表公式**。

与直接点差异的机制差异：

- **不变纹理+共同辐射偏移**：若特征空间内部边关系形状近似保留，`R_rel` 小，即使点对点差异不小；
- **真实新增小结构**：若中心与周围的关系发生局部非均匀变形，`R_rel` 大；
- **阴影新边缘**：也可能让 `R_rel` 很大，这是必须检验的假阳性；
- **1px 错位**：可能把同一几何结构移到邻居，导致对应边向量不匹配，**目前公式并不具备平移不变性**。

因此 `R_rel` 是**局部结构失配证据**，不是“自动真实变化标签”。

### 6.2 用双时相点差异对它进行交叉校验，而不是单看关系

原 CAACP 点差异：

\[
S_{\rm point}(p)=\max(0,1-\cos(F_A(p),F_B(p))).
\]

提出可靠变化分数：

\[
Q(p)=S_{\rm point}(p)\cdot \operatorname{clip}(R_{\rm rel}(p),0,1).
\]

这里不是“换个距离当 score”，而是要求同一位置的两种变化线索**共同成立**。`S_point=0` 或 `R_rel=0` 时 `Q=0`，避免 rank-only 在全零变化图上制造权重非均匀；`Q` 不超过原始 `S_point`。对于 small-object，这个**乘性可靠性**可能过度保守，降低 Recall。因此主报告必须同时测 **FP 减少多少、small pooled Recall 损失多少、F1 是否净增**。若训练前发现 small 漏检严重，宁可否决此方式，不能偷偷改成另一个超参权重配方刷测试集。

### 6.3 为什么真正的“双曲特性”仍是待证的？

`e_H` 与 `e_E` 在分布变化上的敏感度不同，前者还受**点的径向位置**影响。但如果层内范数无表达层次的意义，双曲放大可能只是在放大噪声。应该只在具备以下三类证据时讨论其必要性：

1. **空间适配性**：局部 TinyViM HF / LF 特征的四点 δ-hyperbolicity（含采样/归一化控制）呈现可解释的树状结构，而非仅在树木 ROI 分类论文中存在。
2. **非退化性**：在完全相同输入/8 邻域归一化公式下，`R_H` 与 `R_E` 的排名、正负样本 AUPRC、扰动稳定性存在显著差别；且这差别不是单纯向量范数变化造成。
3. **下游因果性**：经过相同训练预算，去掉双曲评分（换为同式欧氏）会使目标 precision/recall/IoU 有稳定、同方向退步，且机制 ON/OFF 扰动影响与边界、小目标区域吻合。

缺一个，就只可称“使用双曲算子尝试改变几何归纳偏置”，不可断言双曲几何有独立价值。

## 7. 如何适配 CASA-CD，且不违规增加推理分支？

> **重要修订**：前一版讨论过“在 Stage0 64×64 高频输出后直接保留一个动态几何 gate 到 deploy”。考虑本项目强调部署分支可折叠、延迟与 ≤5M，**这次把它降为非首选**。建议更节制的方案：**HF 仅训练期几何条件化，LF 替换已有的变化评分，不创建一条新的部署期 HF 动态支路**。

### 7.1 高频：Geometry-Conditioned HFAE（训练期存在，deploy 完整删除）

当前 Run7 E9：

`local_conv(x_high)` tap（Stage0: 64²、Stage1:32²）→ `[A,B,|A-B|]` → `HFEdgeHead` → 现有边缘监督（原 `λ=0.2`）→ 梯度回到原 RepDW 高频支路。**辅助头推理期整个删掉**。

建议**保持现有头形态与监督目标不变**，增加训练期双曲关系置信度：

\[
R^{\rm HF}_{\rm rel}=\mathrm{GTRC}(H_A,H_B),\quad
H_t^{\rm train}=H_t+\gamma_{\rm aux}\cdot R^{\rm HF}_{\rm rel}\odot H_t,
\]

- `γ_aux=0` 初始化：**主网络输出 epoch-0 不变；训练期 HFAE 也在 gate=0 时完全维持原构型**。
- 两时相**同一个** `R_HF`，交换 A/B 不改变 score；原 HFAE 边缘 loss 原样保留，**不设计新 loss**。
- 并非“流形空间精确标记 1–15 px 坐标”，而是借其局部几何条件调整**已有边缘辅助损失作用到 HF 编码器的梯度分配**。
- 训练完 `switch_to_deploy()` **删除整套 GTRC_HF + γ_aux + HFAE head**。部署期 TinyViM 高频 RepDW 仍是官方折叠路径，**0 额外推理参数、0 额外 HF 几何推理 FLOPs**。
- **梯度风险**：若 `R_HF` 经 `no_grad`，其自身不被训练，但输入 `H` 与已有头的梯度仍可流回 RepDW；`γ_aux` 可训练且初始导数需测。若要学习新的投影，不可一边 `no_grad` 一边声称投影得到了梯度；建议首轮 GTRC 用**无额外可学习投影**的特征/固定缩放，节省自由度。
- 需要用现有 Run7 E9 作为**同期唯一对照**。否则变更既有 HFAE 监督也会被错归因到流形。

**注意**：训练期动态辅助打分不是“训练多卷积→部署折叠为单卷积”的 STR 结构重参数化；它的推理删除属于 **training-only regularization through existing auxiliary head**。论文须明确，不把 HFAE 数学几何门控写成“卷积可折叠”。

### 7.2 低频：Geodesic-Reliability CAACP（只改原有 scorer）

在现有 `16×16` Stage3 prefix `F_A,F_B` 上计算 `Q_L`，替代旧 scorer，**低频聚合位置、形状、网格不动**：

\[
 w_i=\frac{1+Q_L(i)}{\sum_{j\in cell}(1+Q_L(j))},\quad
c_{\rm geo}=\sum_{i\in cell}w_i x_{\rm low}(i),
\]
\[
c=c_{\rm avg}+\beta(c_{\rm geo}-c_{\rm avg}),\qquad \beta=0\ \text{初始化}.
\]

- 当四个 `Q=0` 时，**`w_i=1/4`**，精确恢复 uniform pool。
- A/B 使用**同一份** `Q,w`；仍从 `16×16 → 8×8` 规则 pool，再执行官方四向 SS2D；`dense local_conv(x_high)` 路径不变。
- 只是替换原有 `no_grad` CAACP 路由的参数自由计算，不增加独立 `Conv/Attention` 分支，**deploy 仍含动态 scorer**（CAACP 原本即如此），不可声称整个 CAACP 可折叠。
- LF GTRC 最多做 `16×16 × 8 邻居` 的局部距离，禁止 `256×256` 全局两两矩阵；复杂度约 `O(BHWCk)`，`k=8`，但 `asinh/sqrt` 等核实际延迟仍须测。
- `β=0` 应与官方预训练 epoch-0 前向 **bitwise 逐位一致**，744 个继承键不变（实际数量以当前代码 smoke/服务器为准）。
- **关键难点**：Diag1 的 CAACP 修正项只有 0.19%。即使 GTRC 的 AUPRC 提升，`βΔC` 依然微弱的话，可能不改变 F1。必须测 `mean|βΔC|`、cell entropy、`β ON/OFF` 预测变化、最终 F1，对弱作用诚实报告。

### 7.3 两处是否存在“必须协同”？不能预设

**HF-only**：训练期 HF 边缘梯度更关注稳定几何变化，但 LF 仍按余弦 rank 压缩；**LF-only**：上下文池化可能更可靠，但前端 HF 表征未得到相应训练；**HF+LF**：同一个关系原则训练特征、随后用于低频扫描前的可靠加权。

必须计算每数据集交互项：

\[
I=F1_{\rm HF+LF}-F1_{\rm HF-only}-F1_{\rm LF-only}+F1_{\rm CTRL}.
\]

如果 `I≤0` 或 joint 与 strongest single branch 持平，就不能讲“两个模块必须协同”。如果双曲 joint 与同式 Euclid joint 持平，也不能讲“负曲率是收益来源”。

### 7.4 数学/数值约束与 FLOPs 的诚实描述

- 曲率 `c=1` 在第一轮**预先固定**，不能在 test 上搜索；欧氏/双曲使用同一份输入、通道、邻居集合、前处理与评分后处理。
- 为保留双曲径向信息，**不能把每个 token 都 L2-normalize 到完全固定范数再声称利用负曲率分层**。可先 `v=F/√C` 与固定截断 `||v||≤r`（r 在训练前指定），在 fp32 Exp/Distance 后检查投影是否全部靠近零或球边界。
- 全量低频 `16²×8` 关系评分必须在 RTX 5090 上**独立 profile**。参数=0 不代表 FLOPs=0；`fvcore` 可能把特殊函数显示为 unsupported，需同时记录计时、显存和手工运算量解释。
- 只有训练辅助支路可完全删除；Stage3 原有动态 CAACP 仍不可重参数化为静态单卷积。TAR/DCR 原来的 train→deploy 折叠仍需要 `0.5` 二值 disagreement **严格为 0**。

## 8. 该如何判断“真的区分了伪变化”？先设计正确的只读诊断

### 8.1 伪变化不能等价于“所有背景像素”

真实四库 GT=0 只表示标注不变；它包含真正平滑背景、强纹理建筑、阴影、季节性差异与配准假边缘。**未经额外审计不能把所有 GT=0 都叫“伪变化”。** 首先按空间/场景类型建立可复核的诊断子集：

- **A：真变化**：由 256² GT 连接域得到小/中/大真实变化位置；
- **B：背景强响应**：GT=0 且现有 `S_cos` 或 Run7 模型概率较高的像素，视为**疑似伪变化候选**，不能自动认定具体原因；
- **C：辐射扰动（控制实验）**：构造 `A'=A, B'=g(A)` 且真实变化严格为 0 的**只读合成样例**，`g` 为单侧亮度/对比度/色温等常规扰动。这只是**诊断，不参与正式模型增广或训练**；
- **D：配准扰动**：`A'=A, B'=shift(A,1px)`，零变化语义但会出现错位边缘，用于测 FP 风险。记录边界填充范围，评价排除无效 padding；
- **E：阴影/季节人工核查子集**：从原四库既有测试图挑选、提供样本 ID 与可见证据；不把它当额外训练标签，也不通过挑有利例子换超参。

**非常重要**：若在测试集诊断决定候选公式或超参，再用同一测试集宣称未见数据上的泛化，属于信息泄漏。本项目现有 test-as-val 流程需如实披露；最好使用**训练集内部冻结诊断子集**决定算子和停止规则，将 test 仅按当前统一协议作最终测评。

### 8.2 必测的排序、扰动、分离和下游四级证据

| 层级 | 指标 | 能回答什么 | 不足之处 |
|---|---|---|---|
| 几何适配 | four-point δ/diam、径向分布、角径相关性、球边界夹紧率 | 当前 TinyViM 特征是否有负曲率适配依据 | δ 小本身不保证 F1 提升；必须做采样/尺度对照 |
| 分数本身 | changed vs unchanged score AUPRC、Spearman、Kendall、rank overlap、cell 权重熵 | GTRC 比 S_cos/欧氏关系多出什么信息 | GT=0 含多类伪变化，不能单独归因阴影 |
| 伪变化稳健 | 人工/合成单侧扰动后的 FP ratio、score percentile、模型 0.5 假阳性数 | 能否降低亮度/阴影/1px错位伪报 | 过强抑制可能同时损害真实 small 变化 |
| 小目标 / 预测 | tiny 1–15、16–63、64–255 pooled R、Hit@25、ObjP/ObjR、边界带 PR、F1/IoU | 是否真正改善小目标和整体 BCD | 需完整部署预测，不能只报局部注意力热图 |

建议按当前正确的 `tvim_object_metrics.py` 算法复算对象指标：**4 连通、256² native mask、GT 面积分组、真实对象匹配**；8 连通可作为敏感性，不可用已作废的 `run2_zero_cost_diag.py::component_pr` 伪指标。

### 8.3 针对“伪变化”的关键混淆对照

1. **S_cos**：现有 `1-cos` / rank；
2. **Point-E**：相同特征欧氏 A/B 点距；
3. **Point-H**：相同映射位置的双曲 A/B 点距（HES 风格概念对照）；
4. **Relation-E**：8 邻域欧氏**同式关系形状分数**；
5. **Relation-H**：8 邻域双曲**同式关系形状分数**；
6. **Relation-H fixed radius**：锁住每个点的半径，证实是否仅余弦/角度起作用；
7. **Norm-only**：`||F_A||,||F_B||` 的差异，判断所谓双曲收益是否不过是放大模长；
8. **No-neighborhood control**：只看同位置双曲变化，隔离邻域结构贡献。

**致命失败标准**：`Relation-H` 与 `Relation-E` 排名几乎同序且对正/伪分离无稳定改善 ⇒ **双曲空间没有显现独立判别价值**。如果 Relation-E 已显著提升且 Relation-H 不能再加，论文应改称“欧氏关系驱动的频率协同”，不得继续包装双曲创新。

## 9. 小目标为什么可能检测不到：双曲空间不能突破空间信息损失

CASA-CD 原始大小 256×256，Stage0 1/4 只有 64²，Stage1 1/8 是 32²，CAACP 前 1/16 是 16²，pool 后 8²，Stage4 1/32 也是 8²。输入目标 1–15 px 时，映射到 1/16 的面积常不到一个 token；即使双曲几何在 Stage3 计算得再精确，**若早期特征已经无法区分它与背景，则不能恢复缺失证据**。这一事实与 Diag1 观察到 SYSU small margin 向深层衰减相吻合。

**能合理期待的好处**：

- 高频 64²/32² 仍可保留一部分小边缘的结构关系；利用同样的 HFAE 边缘监督、改变训练辅助分支中的几何条件，可能让真正新增小目标与不变纹理的表征更有区别；
- 低频 CAACP 在规则 2×2 cell 里优先保留**已经存在且可信**的变化特征，减少平均稀释；
- 但低频主要是改善上下文汇总，**不是将 8² “升回” 256² 恢复所有像素**。

**需要警惕的代价**：真实小目标的边缘常弱、面积小；乘法 `Q=S_point·R_rel` 会抑制局部关系分数不明显的真变化，Recall 可能进一步下降。对 SYSU 的 small 问题，绝不能把“FP 减少”冒充“小目标检测提升”。

## 10. 候选方法比较：推荐哪一个？

| 方案 | 高频侧 | 低频侧 | 主要优势 | 根本风险 | 与项目约束 | 裁决 |
|---|---|---|---|---|---|---|
| A. Point-H 直接距离 | 对 HF A/B 算双曲点距做 gate | 换 CAACP 的 1-cos 为 dH | 简单 | 与 HES 重合、rank 退化、无法自动抑伪 | 部署若保留 HF gate 有不可折叠新支路 | **否决为论文主机制** |
| **B. GTRC：训练期 HF 关系条件 + 原位 LF 可靠聚合** | 利用已有 HFAE `aux_only`，双曲邻域关系只在训练辅助头中出现，deploy 删除 | 用同一个关系公式替换当前 CAACP score，保留 β=0/规则 cell | 两边共同服务“真结构变化可靠性”，不加推理 HF 支路；可严谨做 Euclid 同式 | 负曲率效果未证、β 可能极小、强关系门损 tiny recall | **最接近现有约束** | **首选研究假设，先诊断后决定是否实现** |
| C. 双曲 class-prototype / uncertainty | 学变化/不变/阴影多个原型 | 原型置信度引导 pooling | 有潜在语义分离力 | 二值标签无影子类监督，容易构造伪层次/额外 loss，现有文献多模态重 | 不符合主线冻结协议 | **暂不采用** |
| D. 部署期 HF 64² 双曲关系注意力 | 高频逐位置重型几何计算 | LF 再做双曲关系 | 表达力强 | 额外动态支路不可折叠、非线性核开销、TinyViM 延时失控 | 默认否决 | **不进入主方案** |

**首选不是说 B 已成功**，而是它给出了符合预算且能让审稿人看到“为什么高低频和流形几何可能协同”的**明确可证伪试验**。若只读分数证据支持 Euclid 而不支持 Hyperbolic，立即转换论文命题或停止，不靠增加模块挽救双曲设定。

## 11. 必要消融、参数/FLOPs、训练/部署图、完整实验协议

### 11.1 首先做“冻结模型”与“同式”只读诊断

同一个 E9 checkpoint、同一图像 A/B、同一同源特征 tap，批量输出：

`S_cos / Point-E / Point-H / Relation-E / Relation-H / Relation-H-fixed-radius / norm-only`

在四库**训练侧冻结诊断集合**评价 changed-vs-unchanged AUPRC、强纹理背景得分、合成辐射/1px错位假阳性、tiny/small 与背景 AUPRC、score 排名差异；提供图片与样本名、特征直方图和 clipping 率。此处**不得用 GT 调 loss、阈值、曲率或者空间分数公式**。

如果没有 Relation-H 独立优势，**不必启动 20 次 80K**；但也应承认冻结模型上前测失败不能严格否证 end-to-end 联合训练可改变特征几何，只是说明当前投入价值低。

### 11.2 正式四库消融矩阵（同一训练协议；不使用历史 Run7 当同期对照）

| 组 | Run7 HFAE | HF 双曲关系训练条件 | LF 几何可靠 CAACP | 用途 |
|---|---|---|---|---|
| G0 | E9 `aux_only` | 无 | 原 score | **同期唯一 CTRL** |
| G1 | E9 `aux_only` | 无 | 双曲 GTRC | 低频收益与 CAACP β 功效 |
| G2 | E9 `aux_only` | 有，deploy 删除 | 原 score | 高频训练期几何贡献 |
| G3 | E9 `aux_only` | 有，deploy 删除 | 双曲 GTRC | 联合主机制与交互项 |
| G4 | E9 `aux_only` | **同式欧氏**关系 | **同式欧氏**可靠池化 | 证明负曲率必要性的关键反事实 |

如果预算有限，G0、G3、G4 是最小方法鉴别集；但它们**不能证明 HF/LF 协同必要性**。必须增加 G1/G2 才能检验交互。

**训练统一**：`BCE+Dice` 主 loss + **同样 Run7 HFAE 原辅助 loss**（权重锁定 `λ=0.2`），不新增任何 loss；Adam `(lr=2e-4,β=(0.9,0.99),wd=1e-4)`；poly(0.9) + warmup 200；严格 `80,000 optimizer.step`；batch 32；256²；seed 16；A/B/label 同步几何增强，`gray≥128`；相同 test-as-val 模型选择、0.5 判定、训练/测试脚本代码身份。**不混淆有 HFAE 的 E9 与没有 HFAE 的旧 M1**。

**部署**：

- G0/G2：HF HFAE 和训练期 GTRC 都从 deploy 删除；
- G1/G3/G4：只有 Stage3 CAACP 原位更换 scorer，未新增第二个推理动态模块；
- 所有组 TAR/DCR 按原方式折叠为静态卷积，部署参数量应**接近或等于 E9 的 4,880,190**（首选 score 无新增可训练推理参数）；不能只做理论宣称，必须以 `switch_to_deploy()` 后实测总参数确认 ≤5M；
- FLOPs 以 256²、同一统计器 + 额外 unsupported op 清单与 RTX 5090 推理 latency 辅助报告；无报告前不得宣称“零增加 FLOPs”。

### 11.3 实验验收：哪些读数值得论文解释

**P0（必须）**：

1. 从 `tinyvim_s_1000e.pth` 继承原有 key 的数值逐一一致，新 `β=0` 和 HF train-only `γ_aux=0` 时模型主输出与 Run7 对照在 epoch-0 **bitwise 相同**；
2. HF 路径梯度回到 TinyViM Stage0/1 `local_conv`；`γ_aux` 梯度 finite 非零；LF β 与 `x_proj/A_logs` 梯度完整；如果分数 `no_grad`，不能声称它所在的参数参与学习；
3. A/B 交换分数一致、score shape 正确、2×2 A/B 完全相同权重、相同样本加载顺序、无超时 Hook 重复注册；
4. `train→deploy` 折叠二值 disagreement=0（真实 batch + 随机 batch），HF aux 真实被删除；模型输出 NaN/Inf=0；
5. deploy ≤5M，FLOPs、unsupported ops、latency、VRAM 被**实测**；训练 batch32 能完整干跑 3 步。

**机制级（必要且可证伪）**：

- GTRC-H 与 GTRC-E 的 score/rank 不同，但**仅分数不同还不够**；
- `S_H` 对“真实 small 变化 / 高误报背景”的 PR-AUC 净好处必须存在，不能只展示四张热图；
- LF `mean|βΔC|`、`βΔC/c_avg`、entropy、对比 β ON/OFF 的 F1 与小目标命中变化，必须显示**实际作用**，而不是重新产生 Diag1 0.19% 的几乎无效校正；
- G3 在 ≥3/4 库整体 F1 不低于同期 G0，SYSU F1 严格增益；SYSU small pooled Recall 与 Hit@25 双改善且未匹配小预测不过度增长；CDD/WHU 守门事先冻结，建议 F1 回落幅度不超过 0.002；
- G3 相对同式欧氏 G4 具有四库同方向、可解释的净收益，而不只是某一库 ±0.1pp 波动（单种子不能称普适）。

**失败即缩减故事**：

- G3>G0，G3≈G4 ⇒ 提升来自**邻域关系归纳偏置**，不是双曲几何本身；
- G1 或 G2 有益、G3 不更好 ⇒ 没有“必须协同”的证据；
- LF β 始终近零、替换 score 预测不变 ⇒ **CAACP 路由实际作用太弱**，应停 LF 几何主张；
- 伪变化 FP 减少但 tiny/small Recall 同时下降致 F1 无益 ⇒ “精度-召回权衡”，不是“小目标提升”；
- 1px 错位导致 Geometry-H 更高 FP ⇒ 不可宣称“几何抗伪变化”；
- 若推理延迟显著升高或浮点不稳定 ⇒ 不适合轻量 CASA-CD，停止大规模训练。

**数字阈值是待预注册候选，不是既有实验结果。必须见正式日志前冻结。**

### 11.4 只允许最后完整 TEST 块作为正式结果

对 G0–G4 每个库的 `train_log.txt` 只提取**最后一个完整**：

```
=== TEST RESULTS ===
  Recall, Precision, OA, F1, IoU, Kappa
  Params total/trainable/deploy, FLOPs, train-deploy disagreement
=== END TEST RESULTS ===
```

同时保留训练预算、seed、预训练 key 数、HFAE λ、score mode、源码 commit/SHA、显存/延迟。不得用 validation peak 行、checkpoint 名或 README 汇总代替最终正式指标。当前项目用 test 作为验证、按 test F1 选择 best 是已有协议限制，应在论文中披露，不得在该过程中探索多版本再称无偏泛化。

**有可能改善，但目前最有依据的是“局部结构关系的跨时相稳定性”这一机制，不是负曲率这个名字。** 真伪变化的本质难点在于辐射干扰、空间错位与微小真实结构改变的耦合；双曲空间如果能改变局部关系表示的判别边界，可能增益，否则只是一个更贵的距离函数。CASA-CD 目前最值得投入的是：**用严格同式欧氏对照首先证明双曲是否真有新增可分信息；若成立，才把它放入训练期 HFAE 的梯度条件和 Stage3 现有 CAACP 评分，而不是增添一条无法折叠的高频推理网络。**
