# CASA-Pyramid Run10：同类邻域几何压缩

日期：2026-10-31。

本文件记录九邻域候选的结构与八项四轮探针设计，未启动该候选的正式四库队列。实际短训见[配对比较](../../experiments/CASA-Pyramid/Run10/selection/neighborhood/probe_comparison.md)；源码、探针及冻结分析保存在 `outputs/CASA-Pyramid/Run10/selection/neighborhood/`。区域内类别归属候选见[独立方案](../CASA_Pyramid_Run10_区域几何归属方案.md)。

## 目标与证据

Run10 将几何关系用于压缩内容的形成：像素在相邻的同类原型之间分配质量，再构造共同的 K/V 内容。完整 Q、224 个跨尺度 KV、约 2M 参数的主体保持；双曲与匹配欧式版使用相同结构和训练协议。

### 固定区域与均值偏置

Run9 的 β=1 精炼在固定网格内执行：先按变化/背景权重求均值 P0，再将原权重乘以 exp(cos(X,P0))。每个像素只能参与原网格的原型，跨越网格边界的对象不能通过分配重组。

取同一类别中的两个正交单位特征 a、b，初始权重分别为 0.9 和 0.1，则 P0=0.9a+0.1b。两种特征与 P0 的余弦相似度分别约为 0.9939、0.1104。β=1 后，少数内容的质量为：

\[
\frac{0.1e^{0.1104}}{0.9e^{0.9939}+0.1e^{0.1104}}
\approx 0.0439.
\]

少数内容从 10% 降至约 4.39%。这个构造说明均值相似度重加权会强化主导模式；如果少数模式承载小目标或边界，它可能进一步减少有效内容。该性质不要求数值失稳，也不等同于真实数据中少数内容必然是正确变化。

### 冻结 checkpoint 的实际干预

在 Run9 停止后保留的双曲 checkpoint 上，使用固定 256 张 LEVIR val 图像进行干预。表中 F1 来自同一 batch8、FP32 评价：

| 干预 | F1 (%) | 相对完整模型 (pp) |
|---|---:|---:|
| 完整模型 | 91.0789 | — |
| 关闭全局上下文 | 91.1318 | +0.0528 |
| 关闭局部残差 | 90.8255 | -0.2534 |
| 固定双曲半径 | 91.0876 | +0.0086 |

差值由原始未四舍五入 F1 计算。

独立的 batch1、FP32 逐像素干预统计中，全局上下文纠正 6072 个错误，同时新增 6694 个错误，净增加 622 个错误。两组统计的 batch 不同，分别报告，不将逐像素计数直接代入上表的 F1 变化。

该 checkpoint 的局部路径已贡献可观察收益，全局上下文尚未形成净纠错收益，半径干预的输出影响较小。这是停止时权重和固定 val 子集上的机制证据，不是 Run9 最终训练结论，也不是双曲几何无效的证明。

## 模块结构

```text
TAR 四尺度 T_s
       |
     LN(T_s) = X_s ------------------> 完整 Q_s = lift(Wqk X_s / sqrt(32))
       |                                              |
       +--> guide --> 变化/背景 membership             |
       |                 |                            |
       +--> 固定格内初始类别均值 P0 --> 初始 K0         |
       |                                     \        |
       |                          同类 3x3 邻域几何竞争
       |                                     |
       +-------------------------------> 质量加权聚合 P1
                                             |
                    +------------------------+----------------------+
                    |                        |                      |
           K = lift(Wqk P1/sqrt(32))     V = Wv P1           一阶类别 support
                    |                        |                      |
完整 Q ------------+----> 联合 224 KV 检索 --+----------------------+
                                  |
                    内容门控相对写回 + 原 TAR 残差
                                  |
                             DCR 与预测头
```

四尺度网格为 `(8,4,4,4)`，变化/背景各一个原型，因此 token 数仍为 `(128,32,32,32)`。细两层局部残差保留。双曲版使用 Lorentz 测地距离，匹配欧式版在压缩和检索两个位置均使用相同空间投影坐标的欧式距离；两者不等同于历史普通 QKV。

### 1. 初始内容与完整查询

设像素 i 的两类 membership 为 m_i,+ = p_i、m_i,- = 1-p_i，并令：

\[
b_{i,c}=(m_{i,c}+\varepsilon)^2,\quad \varepsilon=10^{-6},\qquad
P^0_{r,c}=\frac{\sum_{i\in r}b_{i,c}X_i}{\sum_{i\in r}b_{i,c}}.
\]

Q/K 共享 64→32 投影，以现有直接 Lorentz 提升 L 构造：

\[
Q_i=L(W_{qk}X_i/\sqrt{32}),\qquad
K^0_{r,c}=L(W_{qk}P^0_{r,c}/\sqrt{32}).
\]

### 2. 同类邻域竞争

N(i) 是像素原网格及周围八个有效网格。每一类别独立竞争：

\[
\alpha_{i,r,c}=\operatorname{softmax}_{r\in N(i)}
\left[-\frac{d(Q_i,K^0_{r,c})^2}{2\tau_a^2}\right],\qquad
a_{i,r,c}=b_{i,c}\alpha_{i,r,c}.
\]

压缩温度 τ_a 是一个四尺度共享的可学习标量，初始化为 0.5，与检索温度独立。相对原固定压缩结构只增加 1 个参数。边界外候选在 softmax 前屏蔽，因此角点、边缘、内部区域分别使用 4、6、9 个真实候选。

逐像素逐类别满足：

\[
\sum_{r\in N(i)}a_{i,r,c}=b_{i,c}.
\]

竞争改变质量的目标原型，不额外压低这个像素的类别质量。P0、距离、分配与聚合全链路可微。

### 3. 内容、支持度与读出

\[
P^1_{r,c}=\frac{\sum_i a_{i,r,c}X_i}{\sum_i a_{i,r,c}},\qquad
s_{r,c}=\frac{\sum_i a_{i,r,c}m_{i,c}}{\sum_i a_{i,r,c}}.
\]

\[
K_{r,c}=L(W_{qk}P^1_{r,c}/\sqrt{32}),\qquad
V_{r,c}=W_vP^1_{r,c}.
\]

几何分配直接改变被读取的内容，K/V 保持同源。一阶 support 是同一聚合内容的类别占比，不解释为独立正确性概率。联合检索保留现有尺度偏置、来源数量校正、条件 softmax 和内容门控相对写回。

## 任务对应与文献依据

LEVIR、WHU 的建筑和边界可能跨越固定网格，邻域分配允许边界两侧的内容选择不同代表。SYSU 的变化外观更丰富，类别内竞争提供跨原网格重新组织内容的自由度。CDD 的季节和光照干扰仍须由训练学习区分；变化 guide 与几何关联共同控制进入上下文的内容，不能仅凭距离大小判断真伪变化。

[SSN（ECCV 2018）](https://varunjampani.github.io/papers/jampani18_SSN.pdf)提供局部邻域软关联和可微内容聚合的基础依据；[STViT（CVPR 2023）](https://arxiv.org/abs/2211.11167)及[官方代码](https://github.com/hhb072/STViT/blob/main/models/stvit.py)展示视觉 token 的九邻域关联。Run10 使用变化/背景分类质量、几何竞争和共同 P→K/V，按本项目公式独立实现。论文全文与来源见[双曲邻域压缩文献](../../参考文献/双曲邻域压缩/README.md)，现有参考代码见[STViT官方核心实现](https://github.com/hhb072/STViT/blob/main/models/stvit.py)。

## 验证与训练安排

短训在 LEVIR、SYSU 上各运行四组，每组 4 个完整 epoch，共 8 项：

| 组别 | 压缩与距离 | 目的 |
|---|---|---|
| H_BASE | Run9 固定网格类别池化及 β=1 均值精炼，双曲检索 | 本次修改对应的旧结构参照 |
| H_NEIGHBOR | 双曲邻域压缩与双曲检索 | 检验新完整路径 |
| E_NEIGHBOR | 欧式邻域压缩与欧式检索 | 同构几何对照 |
| CTRL | 不使用上下文模块 | 主体参照 |

八项均从 MobileNetV2 预训练独立初始化，不续训停止时的 checkpoint。保持共同初始化种子、数据流、训练损失和优化设置；主损失加 0.1 guide，retrieval 权重为 0。短训观察前期训练损失、val 分割与边界指标、类别质量守恒、邻域分配、任务梯度及部署折叠。将真实变化/边界位置的内容纯度与背景位置分开统计，避免大量空区域主导均值。

正式训练为 LEVIR→SYSU→WHU→CDD，每库 H_NEIGHBOR、E_NEIGHBOR、CTRL，共 12 项，仅物理 GPU1，按实测显存安排并行。全部从 MobileNetV2 预训练全新初始化；40K 目标按整 epoch 上取整。正式仍按用户指定每 epoch 在 test 选模，最终结果明确标注 test 参与选模。短训与停止项不作为正式指标。

数值检查应检测具体实现风险：边缘重复候选、质量丢失、P/K/V 聚合不一致、压缩路径梯度断开、几何零距离梯度或部署折叠异常。若这些问题出现，修正后再启动正式队列。精度判断以同协议结果为准，分配更尖锐、半径更大或残差更强均不能单独视为收益。

## 局限

- 邻域原型相似时，关联可能接近均匀并扩大内容混合；需要由内容纯度、边界和漏检统计判断实际影响。
- 每个区域每类仍只有一个代表，同一小区域内多个外观模式未必被完全分开。
- 双曲半径由任务学习，不预设置信或层级语义；新结构也不把加权内容均值称为双曲 Fréchet 均值。
- 冻结 checkpoint 干预只能描述该权重的依赖，四轮短训主要判断实现与初期行为；不能替代完整训练或多 seed 稳定性验证。
- 文献支持邻域关联机制，不保证双曲优于欧式或达到 SOTA。运行开销需要实测，参数变化小不等于延迟变化小。
