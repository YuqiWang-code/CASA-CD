# CASA-CD Exp1-v2（STG_V2）：鲁棒池化 + 跨尺度一致性门

> 2026-10-17。在 Exp1-v1 的 `MECHANISM-FAIL`（LEVIR −0.08pp / SYSU −0.20pp，
> γ=0.382/0.201 被采纳但 F1 未升）之后，按归因报告 §5 的方案 **A** 实现 v2。
> 判据**沿用 v1 已冻结的两库口径，一字未改**（这不是新阈值，只是新臂）。

## 1. 为什么改这两处（来自 v1 的实测签名，不是猜测）

| v1 观测 | 诊断 | v2 对策 |
|---|---|---|
| SYSU 未匹配 <256px 预测 **+49%**（2950→4393）、ObjPrecision **−7.91pp** | `max_shape`（4×4 cell 取单点最大）**放大孤立噪声** | 池化改为 **cell 内 top-4 均值**（上四分位均值） |
| SYSU 的 FP 主体是"细尺度独立假变化/边界碎片"（Run5 §10：66% 4px 内无 GT、32% 贴边界） | 单尺度证据无法区分"真结构变化"与"细尺度伪差" | 追加 **1 个跨尺度一致性通道** `min_σ d_shape` |
| SYSU κ_mean 0.61 vs LEVIR 0.43（纹理更密集、方向更不稳） | 同上 | 同上 |

**两处都是零新增超参**（k=4 由「2×2 结构保底」推出，非搜索；跨尺度 min 无参数），
**不调 γ / 阈值 / σ / seed**——符合项目纪律。

## 2. 数学/实现

* 池化（`_cell_topk_mean`）：把每个 4×4 cell 的 16 个值取最大 4 个的均值。
  - 单点尖峰 V → V/4（v1 的 max 给 V）；
  - 2×2 真实小结构 V → **V（无损）**（v1 也是 V；纯平均池化只会给 V/4）。
  单测 T14 固化了这条性质。
* 跨尺度门：`gate = min_{σ∈{1,2,4}} d_shape(σ)`，作为第 16 个输入通道。
  真实结构变化在多尺度上一致；配准/纹理伪差通常只在最细尺度出现。
* 输入通道 15 → **16**；ST-GEO 参数 6,977 → **7,021**（仅 +44）。
* `form` 标记升级为 `stgeo_spd2_v2`（写进 arch.json / run_manifest / TEST 区块，fail-closed）。

## 5. 判据（沿用 v1，冻结）

接受：LEVIR 与 SYSU 的 F1 **均 ≥ CTRL_R8**（0.9121 / 0.8188）且 **SYSU 严格提升**，机制自检全过；
守门：F1 降幅 ≤0.002、中大对象 pooled Recall 降幅 ≤0.02；
机制门：`worst_diff==0`、epoch-0 逐位（已实测）、折叠 disagreement=0（或刀锋像素带证据）、
`[ACTUAL-OPT-STEPS] 80000`、`[STGEO-GAMMA]` 不得休眠。

**v2 专属的可证伪预测（写在结果之前）**：
* V2-P1：SYSU 的未匹配 <256px 预测数相对 v1（4393）**下降 ≥20%**（即回到 ≤3514）；
* V2-P2：SYSU 的 ObjPrecision 相对 v1（0.4189）**回升 ≥3pp**；
* V2-P3：LEVIR 的 small pooled Recall 保持 v1 的正向（≥+0.5pp 相对 CTRL）。
若 V2-P1/P2 均不成立 ⇒ "碎片化来自池化与单尺度"这一归因被否证，
   下一步改走 **C（Beltrami/各向异性扩散）** 或 **B（监督形态，需批准新增损失）**。
