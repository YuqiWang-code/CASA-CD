## §0 一句话结论

**Run6 的唯一机制候选不是"再加一路证据"，而是在**既有 STR(TAR) 多尺度变化证据**上做「尺度间一致性 / 对象内部一致性」门控——但在通过「冻结特征可分辨性前测」之前，Run6 **不训练**。**

前测要回答的唯一问题：**冻结的 Run1 `M1_FULL` 既有特征里，是否已经存在能把「FP-like 未匹配小预测」与「真实 small 变化」分开的信息？**

- 门（预注册，见 §4.5）：胜出候选的冻结线性 probe 在 **test** 上 `AUC ≥ 0.80` **且** `AP ≥ 0.35`，
  且 CI 下界 `> 0.75 / > 0.25`，且比手工证据通道上限 **0.5992** 至少高 **0.15 AUC**。
- **过门** → 按 §5 实装**唯一一个**门控（C1 或 C2，由前测二选一），跑 1 CTRL + 1 实验 × 4 库。
- **不过门** → `NO_80K`，并给出**可发表的否定结论**：在本冻结协议下，"可折叠的读出层结构增益"已被穷尽，
  剩余 SYSU/LEVIR 差距不在读出层可获取的信息里；论文按 §7.6 重述贡献与局限。

**科研判断**：本方案**不预测**能达到论文硬目标 CDD≥98.00 / LEVIR≥92.50 / SYSU≥85.00 / WHU≥95.00。
Run1 主线为 97.18 / 91.07 / 83.47 / 95.07，差距 **+0.82 / +1.43 / +1.53 / 已达标**（[F02]）；
而项目自带的 29.57M VMamba-Tiny 参照在 SYSU 上只有 **83.45**（[F03]）——即 SYSU≥85.00 高于
一个 6 倍参数骨干的实测值。Run2–Run5 的**七个**独立结构机制对 SYSU F1 的影响都 ≤0.1pp
或在只读前测阶段即被否证（[F07][F08][F09]）。因此 Run6 定位是**最后一个结构性尝试 + 决定性的机制判定**，
不是"冲线方案"。

### 1.2 证据支持的推断 `[I]`

- **I01**：SYSU small 失败的**主要形态不是"证据缺失"，而是"判别失败"**。F12 显示 FP 处原始变化能量**高于**真实漏检 small 变化；F05 显示读出层对信息的线性可读性随深度**上升**而不是下降；⇒ 继续加大"证据带宽"（更高频、更细尺度、更强边缘）在方向上就是错的，Run5 的 NO_80K 与 F14 从两条独立路径一致确认。
- **I02**：FP 集合是**两个机制不同的总体**（F10）：约 32% 是紧贴 GT 边界的碎片（空间精度/过分割），约 66% 是远离任何 GT 的**独立假变化**（中位 30px），而两者在边缘重叠、变化能量、面积上几乎相同（F12/F13）⇒ 它们**不能用同一个手工判据**区分；唯一剩下的信息只能在**学习到的多尺度表征**里。
- **I03**：由 F14，**任何"再设计一路手工证据通道 + 阈值门控"的方案都应被否决**——包括边缘图、高频增强、变化幅值门、纹理能量门、以及它们的逐图归一化版本。这为 Run6 的候选集合先划出禁区。
- **I04**：由 F11，**不配准/错位不是 SYSU 的主因**；论文中不得再用"配准误差"解释小目标假阳性。
- **I05**：由 F05 + F07，**末端 head 与 post-refine 旁路已被反复否证**（Run2 FRH、Run4 FET1 都在 refine 之后）；Run6 若要动，必须在**多尺度证据汇合处（TAR 输出 → DCR 输入之间）**，而不是末端。

## §5 仅在 K0–K7 PASS 后实施：唯一变量的技术规格

### 5.1 C1（首选）：跨尺度一致性门控

在 `MultiScaleTAR` 输出之后、`DCRDecoder` 之前。设 `f_s ∈ R^{B×96×L_s×L_s}`（s=1..4，`L_s = 64/32/16/8`）：

```python
# 训练与推理同一路径；只读既有 f_s，不新增任何张量入口（P0 约束）
raw_s = f_s.abs().mean(dim=1, keepdim=True)          # (B,1,L_s,L_s) 固定统计量，无参数
# 跨尺度：统一重采样到 1/4 分辨率后比较
r_s   = F.interpolate(raw_s, size=(L1, L1), mode="bilinear", align_corners=False)
m     = torch.stack([r_1, r_2, r_3, r_4], dim=1)     # (B,4,L1,L1)
mu    = m.mean(dim=1, keepdim=True)
d_s   = (r_s - mu) / (mu.abs() + 1e-6)               # 尺度间一致性偏差（零均值）
d_s_up = F.interpolate(d_s, size=(L_s, L_s), mode="bilinear", align_corners=False)
f_s  := f_s * (1.0 + gamma_s * d_s_up)               # gamma_s 零初始化 → epoch0 逐位恒等
```

- **统计量口径说明**：`f_s` 是 TAR 已经融合好的单路特征（无 A/B 之分），因此"变化证据强度"用
  **既有融合特征自身的固定统计量** `f_s.abs().mean(dim=1)` 度量；**不**从 `ss2d.py` / `caacp_ss2d.py`
  内部再取张量。若 §4 前测显示"TAR 内部差分分支幅值"是更好的载体，**仍不改主干**——
  只能通过 `str_tar.py` 自身暴露既有分支输出（P0 记录该接口变更，且不得改变其计算）。

- **唯一可训练参数**：`gamma`（4 个标量，`zero-init`），可选 `beta_s`（4 个，`zero-init`，作为加性项）。
  若 K5 判为"纯幅度即可"，则**固定**为 §5.3 的标量形态（`d_s` 换成 `raw_s` 的尺度均值归一），参数不变。
- **不存在双零门**：`gamma=0` 时 `f_s' = f_s` 逐位相同，而 `∂L/∂gamma_s = Σ_p (∂L/∂f_s')·f_s·d_s ≠ 0`
  在首步即非零（这是 Run4 FET1 `γ`+`W=0` 双零门死锁的直接纠正，见 F07）。
- **不改** `ss2d.py` / `caacp_ss2d.py` / `str_reparam.py` / `str_dcr.py` 的任何现有算子。

### 5.2 参数 / FLOPs 与部署硬门

| 项 | C1 | C2 |
|---|---:|---:|
| 新 deploy 参数 | `gamma` 4 + `beta` 4 = **8**（+ 可选共享 1×1 共 **105**） | DW 864 + 1×1 97 = **961** |
| deploy 总参数（硬门） | **4,880,198 ≤ 5,000,000** | **4,881,151 ≤ 5,000,000** |
| 剩余预算 | **119,802** | **118,849** |
| 额外 MAC（B=1） | ≈ `4×96×L_s²` 的两次逐元素运算 ≈ **< 0.0005 G** | `64²×96×9 + 64²×96 ≈ 0.0039 G` |
| 可折叠 | **否**（推理真实模块，先例 CAACP） | **否** |

**必审限定**：两个候选都**远低**于 5M 硬门，因此任何"参数不够所以效果差"的解释都不成立；反过来，
`train 图总参数 ≠ deploy 参数`，两者必须分别记录。fvcore 实测 `unsupported_ops` 必须录入，不得填预测值。

### 5.3 降级形态（K5 触发时）

若 K5 显示"纯幅度基线"与一致性统计量差距 <0.10，则**锁定** `d_s := raw_s / (mean_s raw_s + 1e-6)`（不含跨尺度项），
参数与折叠性质不变，且**在论文中不得声称"跨尺度一致性"是本机制的贡献**——只能称"尺度归一化门控"。

### 5.4 epoch-0 位同、RNG 与预训练

1. 新参数用 `torch.random.fork_rng(devices=[])` + 固定局部种子 `16` 构造，**不推进**全局随机流；
   旧模型（encoder/head/tar/decoder）的全部同名参数与 buffer 必须 `torch.equal`。
2. `gamma=0` 时 `forward` 输出与 `hf_route`/门控关闭的 CTRL **`torch.equal`**（synthetic 8 张与真实 16 张各测一次）。
3. 预训练加载统计（`retained` / `worst_diff`）必须与 Run4/Diag1 基线一致（`worst_diff==0`）。

**层 B（SYSU 机制命中；绝对门与同期 Δ 门必须同时满足）**

| 指标 | Run1/Diag1 冻结参考（**只用来定阈值，不充当分母**） | E8 必须同时满足 | 机制含义 |
