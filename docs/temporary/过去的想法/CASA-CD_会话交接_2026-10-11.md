## 7. Run6 设计要点（不看全文也能执行）

**唯一问题**：冻结的 Run1 `M1_FULL` 既有特征，能否把「FP-like 未匹配小预测」与「真实 small 变化」分开？

**两候选（K7 二选一，互斥）**：
- **C1 跨尺度一致性门控**：TAR 四级输出之后 / DCR 之前。`raw_s=f_s.abs().mean(dim=1)` →
  重采样到 1/4 比较得 `d_s=(r_s−mu)/mu` → `f_s *= (1 + γ_s·d_s_up)`，`γ` 零初始化（**首步即有梯度**，纠正 Run4 双零门）。
  新参数 **8**（+可选共享 1×1 = 105）→ deploy **4,880,198**。
- **C2 对象内部一致性门控**：`decoder.refine` 之后 / head 之前，3×3 DW + 1×1 产生"碎片 logit"，
  `γ` 零初始化。新参数 **961** → deploy **4,881,151**。
- **K7 规则**：按 **train-CV AUC** 降序；相差 ≤0.005 取**参数更少者 C1**；再平局按字典序。**test 不参与选一**。

**前测（只读）**：拟合 = `train.txt` 的 D3 **sha1-hash 90% train**；评估 = **test 全量 4000**；
probe = 标准化线性 logistic（L2 由按图 5 折 CV 选），test AUC/AP 用**图像级 bootstrap 1000、seed 16**。

**K 门（已冻结，不得改）**：K1 `n_pos≥300 & n_neg≥2000`；K2 `test AUC≥0.80` 且 CI 下界 `>0.75`；
K3 `AP≥0.35` 且 CI 下界 `>0.25`；K4 `winner−0.5992≥0.15`；K4b `winner−baseline_full≥0.05`；
K5 `winner−amplitude基线≥0.10`（否则 `gate_stat=amplitude`，且论文不得称跨尺度一致性贡献）；
K7 见上。**K2/K3/K4/K4b 任一 FAIL ⇒ NO_80K，训练次数 = 0**，论文按文档 §7.6 收口。

## 8. 工程纪律与踩过的坑（**务必遵守**）

1. **远端命令一律写成 `.sh`/`.py` 文件再上传执行**。PowerShell 会破坏 `$?`、`$D`、`$(...)`、
   heredoc（`<<'PY'` 直接语法报错）⇒ 不要在 PowerShell 里内联复杂 shell。
2. **绝不删除产物**。失败/作废产物改名隔离：`_INVALID_<stamp>` / `_SUPERSEDED_<stamp>`，保留原文件。
3. **先 DRY 排练再全量**。Run5 的排练（`--limit 600`）抓出了一个真实缺陷。
4. **必须做独立最小复算审计**。Run5 靠它发现 `missed_small` 漏掉面积组过滤（1250 vs 正确 295）。
   审计脚本与主脚本必须是**不同代码路径**，并写 `INDEPENDENT_AUDIT.json`。
5. **列表哈希口径**：Diag1 的 list 锁是 `sha256_text_lines`（`rstrip('\r\n')` + 每行补 `\n`），
   **不是** raw bytes sha256；两者在同一文件上不同。
6. **`--limit>0` 恒为 `DRY_ONLY`，永不 PASS**；`--out-dir` 必须全新/为空，禁止覆盖。
7. **commit + push**：长提交信息写成文件再用 `git commit -F <file>`（PowerShell 内联长 `-m` 会静默失败）。
8. **`pkill -f '<长路径>'` 会杀掉 SSH 会话自身**；用括号模式 `[t]rain.py`。
9. GPU 上跑 `python analyse/...py` 前记得 `LD_LIBRARY_PATH`，否则 `selective_scan_cuda_oflex` 导入失败。
10. `--pretrained_weight_path`（DeiT）是历史必填占位；`casa_tvim_str` 实际用 `--tinyvim_pretrained_weight_path`。
