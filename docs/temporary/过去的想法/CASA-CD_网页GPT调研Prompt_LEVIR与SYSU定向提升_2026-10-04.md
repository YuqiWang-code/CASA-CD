## 一、背景与硬约束

- 任务：极轻量遥感**二值变化检测**，输入双时相 256×256（A/B），标签阈值 gray≥128。
- 四数据集硬目标（F1，必须同时全部达到）：**CDD ≥98、LEVIR ≥92.5、SYSU ≥85、
  WHU ≥95**（IoU 与 F1 同方向）；**有效推理参数 ≤5M**。
- 固定训练协议（不允许改）：BCE+Dice 损失、Adam(2e-4, 0.9/0.99, wd=1e-4)、
  poly(0.9)+200 warmup、80,000 steps、seed 16、test 集当验证集选 best
  （当前 batch 32、双卡 4 数据集并行）。**禁止**：损失调参、数据增强、阈值调参、
  多 seed 包装、模块堆叠；**创新必须是结构性的**。任何涉及训练策略变动的建议
  必须标注「需导师批准」。
- 验证纪律：**每次改动都必须 4 数据集完整从头训练**（无单数据集 gating），
  且不得回退 CDD/WHU 现有指标。

## 二、当前架构（CASA-TViM-STRNet，deploy 4.880M ≤5M，FLOPs ~2.9G）

- **TinyViM-S-Slim**（ICCV 2025，官方 5.6M → 4.645M 瘦身：Stage4 删 2 个
  LocalBlock，保留 Local×3+final TViM；ImageNet-1K 1000e EMA 权重 744 键逐位
  继承；backbone 可训练 @0.1× LR，BACKBONE-ADAPT 审计 rel_L2 drift 9-14%）。
- **CAACP-SS2D（创新一）**：只改 Stage3（1/16）末个 TViM 的低频路径——均匀
  AvgPool2×2 → 双时相 change-score（1−cos、rank 归一化、参数自由）加权的
  **2×2 cell 聚合**（A/B 共享权重、规则 8×8 lattice、无 TopK、四向 CrossScan
  几何不变）；`c = c_avg + β(c_ca − c_avg)`，β=0 初始化精确继承预训练；高频
  RepDW 残差路径完整保留。训练后 β=5.6e-3~3.9e-2（被训练采纳）。
- **TAR/DCR（创新二）**：可重参数化二时相 bridge + 解码器（推理折叠单路径），
  encoder_dims=(48,64,168,224)，D=96。
- 特征层级：1/4(48ch, 64²)、1/8(64, 32²)、1/16(168, 16²)、1/32(224, 8²)。

## 三、当前结果（16/16 个完整 80K run，全部从头训练、单 seed、折叠门槛全过）

F1 / IoU（%）：

| 变体 | CDD | LEVIR | SYSU | WHU |
|---|---:|---:|---:|---:|
| A0 基线（plain） | 96.76 / 93.73 | 91.08 / 83.62 | 82.38 / 70.06 | 94.78 / 90.08 |
| M1 完整（CAACP+STR） | **97.18 / 94.51** | 91.07 / 83.60 | **83.47 / 71.63** | **95.07 / 90.60** |
| A1 只 CAACP | 96.75 / 93.70 | 91.03 / 83.53 | 82.11 / 69.65 | 94.84 / 90.19 |
| A2 只 STR | 97.11 / 94.39 | **91.19 / 83.81** | 83.21 / 71.25 | 94.53 / 89.63 |

消融（ΔF1 vs A0）：CAACP 主效应 ≈0（−0.01/−0.05/−0.27/+0.06）；STR 主效应
（+0.35/+0.11/+0.83/−0.25）；CAACP×STR 边际 M1−A2（+0.07/−0.12/+0.26/+0.54）。

上游参照（29.57M VMamba-Tiny + 同一 TAR/DCR，full_last2）：
98.42 / 91.44 / 83.45 / 95.14——我们以 1/6 参数达到接近水平。

**本轮目标（保持 CDD ≥97.18、WHU ≥95.07 不回退）**：
- **LEVIR F1 91.19 → ≥92**（远期 92.5）；
- **SYSU F1 83.47 → ≥84**（远期 85）。

数据集特征：CDD 抗伪变化（季节/光照，10K train，当前已近饱和）；**LEVIR 稀疏
小建筑、约 54% 图像零变化**（7.1K train）；**SYSU 密集多类别通用变化、变化像素
占比高**（12K train，IoU 70.06 明显低于 WHU 的 90.08）；WHU 建筑（5.9K train）。

- 特别请查：轻量 CD 模型在 LEVIR-CD-256 与 SYSU-CD 上「F1 卡在 90/83 附近」的

  结构差异）。
