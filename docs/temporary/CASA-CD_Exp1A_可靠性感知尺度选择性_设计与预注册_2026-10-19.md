> 采纳第三方咨询文档的建议方向 **A**，但做了两处关键的方法学修正（见 §2 "本实现的不同之处"）。

⇒ 缺的不是"更强的几何响应"，而是两件事：
**(i) 判断某处结构变化是否值得改表征（可靠性）；(ii) 让修正不去动大目标赖以生存的低频响应（尺度选择性）。**

## 2. 三个组件（除 1 个零初始化 γ 外**全部参数自由**）

**(1) 可靠性 r（无阈值、无超参）**
```
r_support = box_mean_{5×5}(s) / (s + box_mean_{5×5}(s))     ∈ [0,1)   中心-邻域一致性
r_xscale  = min_σ s_σ / (max_σ s_σ)                        ∈ [0,1]   跨尺度一致性
r = r_support · r_xscale
```
两者都是**非负量的比值** ⇒ 没有可调阈值。语义：真实小目标的结构变化在邻域内有支撑、
在多尺度上同现；孤立纹理响应两点都不满足。

**(2) 局部零均值（detail-only）修正**
```
Δ = γ · ( r ⊙ z − AvgPool_{9×9}( r ⊙ z ) )
```
减去局部均值 ⇒ 修正的 **f=0（DC）分量严格为 0**，因此它只锐化局部结构，
**不能抬高/压低大目标依赖的整体激活水平**。这是对"v2 大目标召回受损"的直接对策。
实测（冒烟）：`|global mean|/mean|Δ| = 3.5e-5`；33×33 低频残留比 1.0%（**非 0，如实记录**）。

**(3) 同式欧氏对照（`--stgeo_geom euclidean`，回答"负曲率是否必要"）**
在同一 (κ, θ) 特征上把双曲距离换成**切空间欧氏距离**：
`w = artanh(κ)·e^{iφ}`（过原点的切空间），`d_euc = √2·|w_A − w_B|`（√2 使其在恒等附近同尺度）。
⇒ 同一输入、同一池化、同一门，**只换度量**。若 `hyp ≈ euc`，只能声称"局部结构统计有用"，
**不得**声称负曲率必要。

## 3. 本实现与咨询文档建议的两处不同（理由）

1. **可靠性不用"双时相都要有相同边缘"作判据**：新增/消失的小目标本就只在一侧有结构。
   r 只度量"该结构变化是否在空间与尺度上被支持"，与目标是否新增无关。
2. **不采用"深层上下文决定是否抑制浅层证据"的硬决策**：按文档第三点的提醒，用**软选择**
   （逐像素乘 r，∈[0,1]）而不是二值保留/删除，避免重新造成深层漏检。

## 4. 预注册（**见结果之前冻结**）

协议 `exp1_stgeo_exact80k_v1`：80,000 optimizer.step、batch 32、256²、seed 16、
Adam(2e-4,0.9/0.99,wd=1e-4)、poly^0.9+200 warmup、test-as-val、prob>0.5、gray≥128；**只跑 LEVIR + SYSU**。
对照 = `CTRL_R8`（**epoch-0 前向逐位相同**，已实测 `torch.equal=True, max|d|=0`）。

| 预测 | 阈值 | 意义 |
|---|---|---|
| **A-P1** | LEVIR ≥ **0.9121** 且 SYSU ≥ **0.8188**，且 SYSU 严格提升 | 净 F1（主目标） |
| **A-P2** | SYSU large pooled R ≥ **0.8000** | 局部零均值是否真的保护了大目标 |
| **A-P3** | small pooled R：LEVIR ≥ **0.6760**、SYSU ≥ **0.1695** | 小目标收益是否保住 |
| **A-P4** | 未匹配 <256px：LEVIR ≤ **585**、SYSU ≤ **2950** | 是否复发 v1 的碎片化 |
| **A-P5**（机制） | \|γ\| ≥ 1e-3 且 diag 的 `out_mean/out_abs_mean ≈ 0` | 门被采纳 + 局部零均值生效 |

**失败判据（预先写死）**
* 若 A-P2 或 A-P3 有一项不成立 ⇒ "可靠性 + 局部零均值"未解决尺度冲突，本轴到此为止；
* 若 A-P2/P3/P4 全成立而 F1 仍 < CTRL ⇒ **局部收益转化为净 F1 的路径不在本轴**，
  应转入分析型收尾（写负结果 + 机制归因），不再加模块；
* 曲率：A 跑完后按需补 `STG_REL_EUC`；若 `hyp ≈ euc`，撤回"负曲率必要"的任何表述。
