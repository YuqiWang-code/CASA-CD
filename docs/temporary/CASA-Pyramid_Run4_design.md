# CASA-Pyramid Run4：可靠原型与相对上下文修正

共享MobileNetV2、TAR、DCR主体，比较CTRL、普通QKV和双曲QKV，共四数据集×三组。两模块共用压缩、内容与回写规则，关系度量分别为欧氏与双曲；完整Q、压缩KV的约束不变。

项目目标是在普通RGB全监督二值变化检测中兼顾有效性、准确率与推理开销。LEVIR F1≥92%、SYSU≥84%、WHU≥95%、CDD≥97.5%是用户指定的努力目标，不是已核实同口径SOTA门槛或当前实测成绩。少量有用参数增量可以接受，机制收益及可归因性优先于极端压参。

## 证据与选择

Run3数值稳定，两个模块有非零输出和随query变化的检索，但LEVIR接近持平、WHU均下降约0.28个百分点。普通版建筑库S1上下文残差可超过TAR幅度两倍；双曲版LEVIR/WHU最粗层约75%的输入对触发裁剪，约99%的注意力留在本尺度。SYSU后期训练损失下降而选模损失上升；CTRL在三个数据集也低于Run2。见[Run3分析](../experiments/CASA-Pyramid/Run3/analysis.md)。

这些记录支持检查映射尺度、检索坐标、压缩内容和回写方式，不支持两个模块已整体失活的结论。同尺度偏好、较大幅度与精度下降之间尚无单独因果消融。

| 已知不足 | Run4选择 | 要检验的结果 |
|---|---|---|
| 各尺度原始A/B独立投影后跨尺度匹配，最粗层几乎只用本尺度 | context只接TAR64；四尺度共用LN及Q/K投影 | 跨尺度内容是否形成有益更新，边界与主指标是否改善 |
| 强全局内容相加未形成建筑细节收益 | 回写`W_out(AV−V_query)`，保留原TAR | 减少常量广播后误报与漏检是否改善，不能只看残差变小 |
| 压缩难以保留全部局部边界信息 | S1/S2高通TAR经DW3×3、PW1×1修正 | 边界F1与区域完整性是否同时受益 |
| 高裁剪限制径向幅度，几何链复杂、延迟高 | 直接Lorentz坐标、单平方测地距离、欧式V | 半径分布与梯度正常，并获得合理的精度/开销收益 |
| CTRL也退步，共同设置与模块影响混杂 | 恢复骨干LR倍率1.0，移除边界辅助损失，三组guide均0.2 | 同轮模块相对CTRL收益；跨轮绝对差异另行解释 |

## 数据流

```text
A / B
  └─ 共享MobileNetV2原生四尺度
       └─ TAR → T1,T2,T3,T4，各64通道
            ├─ CTRL：TAR直接进入DCR；guide用于训练监督
            └─ QKV：共享LN → X1,X2,X3,X4
                  ├─ 共享Q/K投影 → 全部5440个query
                  ├─ guide → 变化/背景权重 → 224个K/V
                  │      K：欧氏池化投影 / Lorentz质心
                  │      V：池化后欧氏线性投影
                  ├─ 欧氏 / 双曲距离检索 → AV−V_query
                  │      └─ 输出投影 × 逐通道gamma_context
                  └─ S1/S2：X−Avg3(X) → DW3 → PW1
                         └─ 逐通道gamma_detail
               原TAR + context修正 + 细层局部修正
                    └─ DCR → 共享预测头
                         └─ 四级训练 / 一级推理
```

## 压缩与可靠性

网格为8/4/4/4，每区域产生变化与背景两个token，数量128/32/32/32，总数224。完整Q为4头×16维，不压缩空间位置。

对一个区域，令`m_i=p_i`或`1−p_i`：

```text
w_i = (m_i + eps) / Σ_j(m_j + eps),  eps=1e−6
P = Σ_i w_i X_i
r = Σ_i m_i² / max(Σ_i m_i, eps)
```

r表示按该类概率加权的置信度。单个高置信变化像素可以有较高r，不会像直接使用变化面积占比那样因目标小而必然减权。guide不可靠时两类原型仍可能混合，需主任务和guide监督共同学习。

```text
logit = −distance²/(2 tau²) + log(max(r,eps))
        + learned_scale_bias − log(source_token_count)
```

tau每头独立，softplus参数化、初值0.5。数量prior只修正来源token数，不强迫均匀检索；分配权重和可靠性prior均保留梯度。普通版LN位于池化前，无bias投影满足`W(ΣwX)=Σw(WX)`，因此K/V先池化再投影减少密集计算，完整Q仍密集投影。

## 双曲关系与欧式内容

共享投影每头输出`z=W_qk X/√16`，构造：

```text
x = (sqrt(1+||z||²), z)
<x,x>_L = −1
radius = asinh(||z||)
```

这是Lorentz双曲面的空间坐标参数化，依据[Hypformer KDD2024](../参考文献/Run4_压缩与双曲检索/README.md)的时间坐标重建，不引入新的激活函数。它取消固定上限裁剪，半径随输入幅度连续变化；投影后的z不单位化。

K由密集双曲Q点按变化/背景权重加权，再做Lorentz归一化质心。Q/K保持共同坐标与曲率；V使用同一权重池化X后欧式投影。检索仅依赖`acosh(−<q,k>_L)²`，不混合第二个切空间差异距离，也不进行局部Log、并行移动或输出Log。

平方测地距离在同点处有有限导数，实现用`z=cosh(d)−1`的解析级数处理零点附近。直接lift不代表任意大坐标都稳定；半径CV、最大半径、流形误差及任务梯度共同说明状态。理论边界见[ICML2023数值稳定](../参考文献/Run4_压缩与双曲检索/Numerical-Stability-Hyperbolic(ICML2023).pdf)。

## 相对回写与细节

`U=W_out(AV−W_V X)`在全部内容相同时为零，不依赖学习标量来抵消常量广播。一般输入下仍可能产生平滑，因此S1/S2保留`H=X−Avg3(X)`的DW3×3/PW1×1分支。该高通来自TAR融合后的变化特征，不是RGB梯度或额外A/B绝对差分。平均滤波与深度卷积使用replicate padding。

局部分支不增加边界预测头或边界辅助损失，有用性由二值分割目标决定。[FreqFusion TPAMI2024](../参考文献/Run4_压缩与双曲检索/FreqFusion(TPAMI2024,arXiv版).pdf)支持分别考察区域一致性与边界细节；本模块没有照搬其自适应滤波与重采样偏移。

`gamma_context[4,64]`、`gamma_detail[2,64]`逐通道零初始化，支路卷积与输出投影正常初始化。初始恒等，gamma开始学习后内部参数接收任务梯度。gamma和输出投影不能同时全部置零，否则会阻断支路启动。

## 历史经验

- 旧HSAM径向退化与Run3高裁剪不同。Run3半径CV非零，不能单凭裁剪率认定半径塌陷。
- 过去普通对比库存在WD压缩弱信号的问题。Run4没有零均值对比库，变化/背景原型保留内容；仍需记录权重、分配与读出幅度，非零不代表有效。
- 面积prior可能压低稀疏变化。本轮prior描述概率可靠性，细尺度仍保留128个token。
- 额外边界监督和高通增强不保证建筑轮廓改善。本轮以共同主分割目标训练局部支路，同时观察完整区域与边界指标。
- 几何运算更多不等于双曲利用更充分。单距离、共享坐标和欧式V将关系建模与内容聚合分开，便于同普通版匹配比较。

## 训练与检查

协议`casa_pyramid_40k_relative_adamwctx_v4`。三组共同采用MobileNetV2预训练全新初始化、256×256、batch32、seed2333、Adam基础LR5e−4、骨干倍率1.0、前200步warmup、poly0.9、40K按整epoch上取整。四级BCEWithLogits＋Dice，guide面积标签BCE权重0.2；无边界辅助损失。context全部Conv/Linear权重使用独立参数组，`decoupled_weight_decay=True`、WD1e−4；其余context参数WD0。encoder与body保持原Adam耦合L2衰减WD1e−4。解耦衰减按`weight *= 1−lr·wd`更新，不把衰减项累积进Adam梯度矩；这样可对context权重正则化，同时避免弱任务梯度被耦合L2更新主导。实现使用服务器PyTorch2.14的[Adam参数组接口](https://docs.pytorch.org/docs/2.14/generated/torch.optim.Adam.html)。

沿用同步裁剪、水平/垂直翻转、90°旋转、时相交换及ImageNet归一化，不增加独立光度扰动。每epoch在test选最佳F1，最终复测不属于独立盲测。三组顺序与并行安排不改变共同训练协议。

正式启动前检查原型压缩语义、同点与流形公式、支路/guide任务梯度、零初始化启动和部署折叠。双曲/普通两模块分别在真实LEVIR短训6个完整epoch、SYSU短训4个完整epoch，在val评价；观察主损失、guide、温度、半径、可靠性、残差幅度，以及主任务和guide梯度的RMS、比例与余弦。短训不计正式指标，正式训练不继承短训权重。NaN、梯度失活、持续异常半径或明确损失异常需先停下确认原因；正常早期指标波动不等于失败。

## 尚待验证

Run4尚无正式精度与效率结论。共享坐标、相对回写和直接Lorentz参数化分别针对已观察不足，但同轮12项仍包含多项结构改动，不能单独分离每个组件的收益。模块有效后，需最小消融检验几何、可靠性及局部分支各自贡献。单seed、test参与选模和首batch模块诊断的局限保持明确；微小提升不能直接称稳定SOTA。
