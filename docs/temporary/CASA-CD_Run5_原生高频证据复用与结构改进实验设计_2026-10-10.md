## §0 一句话结论

**唯一有条件采纳的 Run5 主方案：FHR-TAR（Frequency-native High-frequency Reuse in TAR），只读取 TinyViM 现有 TViM block 的 `local_conv(x_high)` 中间结果，在 `1/8→TAR.stage2.temporal` 或 `1/16→TAR.stage3.temporal` 两对同尺度位置中，用**冻结、不训练的互补性诊断**选出**恰好一对**；训练时把零初始化的高频 1×1 辅助投影加到对应 TAR 时相线性投影的激活前，部署时拼入**原有一层** 1×1 Conv；若诊断不通过，则 Run5 **不进行任何 80K 新结构训练**，转向 SYSU FP 空间画像的只读归因与导师批准的骨干研究。**

**科研判断**：目前**不能预测它会实现** CDD≥98、LEVIR≥92.5、SYSU≥85、WHU≥95；Run4 1/4 直达旁路虽在前测 PASS，却只有 SYSU 小目标 +3.87pp、F1 +0.08pp，说明“浅层边缘/频率证据可分”**不足以**推导“模型会用它”。本方案的唯一机制区别是**复用编码器内部分频后、混合前的原生高频张量**，并在**STR 的早期时相线性融合处**直接训练可折叠系数；不用 post-refine 旁路、`|Q-P|` 高层 tap、末端 FRH，也不新增边缘监督。最可能的失败模式是**`x_high` 只含纹理/配准扰动，缺乏针对漏检变化的增量判别力**；次要失败模式是证据虽存在，但 TAR/DCR 后续混合再次淹没它。**在前测门及两条梯度利用率硬门通过之前，方案状态为 `CONDITIONAL / NO_80K`。**

**实操优先级**：第一件事不是改网络，而是实现 §5 的 **≤600s、已有 checkpoint 冻结** 的选择性前测。其结果决定是否值得付出 8×80K；不能把前测失败解释成“改成 3×3/加个边缘头再试”。

### 1.2 证据支持的推断 `[I]`

- **I01**：`x_high` 在 `out_proj` 之前可以被**复用而不是重新高通滤波**，并且现有卷积/SS2D 本身不需多算一次；从 `local_conv` 输出用 forward hook 接线是最小侵入实现。注意它是**局部路径表征**，并非经实验证明只保留“变化边缘”。
- **I02**：Run4 γ 值很小不等价于“任何高频都无用”；它更明确地否决了**1/4 外部混合 tap→post-refine 且 γ 双零门**这条实现路径。新机制要把辅助权重本身置零，使其第一个 backward 即可获得梯度。
- **I03**：边缘图可能放大高变化先验 SYSU 的纹理噪声（SYSU ObjP=0.5320），优先在**变化时相代数**处判断，而不是给 decoder 末端逐像素锐化。

| **C3：FHR-TAR 原生中间高频复用（主案）** | **只观察** TViM final `op.local_conv`（未合并），同尺度 `TAR.stage2` **或** `stage3` 的时相投影输入，训练额外零卷积辅助线性基，部署合并原 TemporalRep1x1。 | R1 只做单时相特征频率分流；R3 时空 CD；R6 Rep 原理。首次针对本项目测试“混合前 HF 的**时间变化判别互补性**”。 | stage2：**+6,144**, **+0.006291456 G MAC**；stage3：**+16,128**, **+0.004128768 G MAC**；二选一。 | **是**：`Conv1x1(2C+2H→96)` 单卷积，不新增 scan/head。 | novel rescue≥0.10、gap≥0.15、CI下界>0.03；80K 后小目标/ObjR/四库 F1 同时达层 B/C。 | **唯一有条件主案**；先 §5 前测，不先指定某层。 |
| **C4：重写 1/16→1/32 主干下采样及频率路由** | Stage4 embedding/TViM 改写 | Diag1 尺度选择性 margin 下跌是真，但同层可学习 probe 1/32 AP 0.829，**不是总信息丢失**；破坏 R1 的预训练张量结构。 | 参数/算量必须重新审计，无法在未建结构时给确定量。 | 新模块不自动可折叠；预训练兼容待证明。 | 导师批准后独立子课题，用预训练加载 + epoch0 审计。 | **本 Run 否决**；前测失败后唯一可升级的结构研究方向，须导师签字。 |

**主方案选择的必要条件**：从“编码器内特征本就可复用”到“真正补救 M1 漏检对象且不把纹理假阳性一起救回”，必须通过 §5 中同时设定的差异检验。**门不通过就不训练**；并不是“无条件推荐 edge network”。

### 5.2 变量、计算口径与严格分组

1. **对象集合**：GT 4 连通、面积 `[1,255]`、原生 256²、label `gray>=128`；`M1` deploy `prob>0.5`；对 GT 小对象逐个 `r_i=TP_i/area_i`；`r_i<0.25` 记 `missed_small`（与 Run4 前测一致）。
2. **FP-like 集合**：预测 4 连通域按 IoU 最大权重一对一二分匹配，`IoU>=0.10` 计匹配；剩余预测域 `[1,255]` 为 `unmatched_small_pred`（含碎片化 FP，**不能全部称真实伪变化**）。以 `tvim_object_metrics.object_iou_matrix / match_objects` 的索引映射为准。
3. **原生 HF 分数**：`hA,hB ∈ R^{C_H×s×s}`，`u(x,y)=mean_c |hB_c−hA_c|`。在每张图内部对 `u` 作确定性稳定 rank `[0,1]`（ties 用稳定排序 + 平均秩，禁依赖 label）；双线性上采样到 256² 后再次作 256² rank 得 `S_HF`。**不是谱幅度、不是训练型边缘 map；不影响最终分割阈值。**
4. **已有 tap 对照分数**：严格加载 `D3_concat/M1_FULL/probe_L03b_norm2_PROBE_ONLY.pth` 或 `probe_L06b_norm4_PROBE_ONLY.pth`（`encoder_input=concat`、不重拟合）；取冻结 `sigmoid(probe([F_A,F_B,|F_A−F_B|]))`、双线性上采样 256² 再作**同样的逐图 rank**，记 `S_TAP`。若任一权重不存在、协议不是 concat 或 `C_in≠3C`，`NO_80K`，不得自动重训。
5. **边界带**：GT 对象内 `O`，外侧4px 菱形环 `R=(dilate_4(O)\O)∩(~GT)`；`margin(S,O)=mean(S[O])−mean(S[R])`；`R` 为空的对象显式记录 `skipped_no_ring`。同样计算 `S_HF`、`S_TAP` 的 small/medium/large `margin`、`small/large` 比与 **small-vs-background AP**（正样本仅所选 GT 面积组、负样本所有 GT=0，其他 GT 对象像素不进样本；2000-bin AP，参考 D3c）。**不可拿绝对 AP 数值直接判断 HF 比另一概率 probe 好**，应使用同 ranking/calibration 和一致指标。
6. **预注册救回标签**：`hit_HF=1[margin_HF≥0.03]`，`hit_TAP=1[margin_TAP≥0.03]`（**0.03 仅诊断阈值，绝非分割部署阈值/训练超参**）；在 `missed_small` 上记 `n_hf_hit`、`n_tap_hit`、`n_hf_only`；FP-like 上记 `n_hf_fp_hit`。`rescue=n_hf_hit/n_missed`；`fp_like=n_hf_fp_hit/n_fp`；`gap=rescue−fp_like`；**`novel_rescue=n_hf_only/n_missed`**，为新机制最重要的“已给定同尺度 tap 后仍独有的证据”。对照 `tap_rescue`、`hf_minus_tap_rescue`。分组还记录 `GT边界漏检`、`孤立 interior 漏检` 的占比（见 §10），不凭肉眼画图裁决。
7. **统计单位**：4000 张 SYSU test 图像做有放回 bootstrap **1000 次**、seed16；每次抽取图像，**重算计数比**（不是随机抽像素/对象），报告 `gap_ci95`、`novel_rescue_ci95`、`small_margin_diff_ci95`；同一图内 GT 对象与预测组件自动保持配对。`n_missed_small`、`n_fp_like` 均是被统计成功的样本数，`skipped_no_ring` 另报，不能悄悄丢弃。
8. **互补的更严格反证**：若 `HF` 与 `TAP` 高重叠（`novel_rescue<0.10`）即便 `rescue>0.50` 也 FAIL——Run4 证明大 rescue 本身不足以带来可用收益。若相邻深层 `P00` 已有相同信号，使用 M1 原始 `prob` 对同一对象的 `margin`/recall 判断独有差异，不能只观察 high-pass 能量。`x_high` 的参数没有更新，诊断只作只读 forward。

## §6 主方案 FHR-TAR 技术规格（**仅 G0–G8 PASS 后实施**）

### 6.1 机制定义、张量、计算位置

仅在 `Pair-s`（`s=2` 表示 1/8；`s=3` 表示 1/16）开启，**两者互斥**。`C_s =64/168`、`H_s=32/84`、空间 `L_s=32/16`、`D=96`：

- 输入两时相原始 stage tap：`P_s,Q_s ∈ R^{B×C_s×L_s×L_s}`；**原生内部分频局部输出**：`H_A,H_B ∈ R^{B×H_s×L_s×L_s}`，取自 `encoder.network[2][-1].op.local_conv`（Pair-2）或 `encoder.network[4][-1].op.local_conv`（Pair-3）；该张量在 `cat(x_low,x_high)` 和 `out_proj` 之前被 hook **直接读出**。**不对 stage tap 再做 AvgPool/FFT/DWT、不取 `res`、不做 edge GT**。
- 保留 TAR 原 `TemporalRep1x1` 的 Concat、Sum 与 signed-Diff 训练分支：

\[
 Y_0(P,Q)=\mathrm{BN}_c(W_c*[P,Q])+\mathrm{BN}_s(W_s*(P+Q))+\mathrm{BN}_d(W_d*(Q-P)),
\]

  其中 `*` 是 1×1 卷积，`W_s/W_d` 已在 STR 中按原方法零初始化；**不修改其初始化**。
- 新辅助线性基：

\[
 E_s(H_A,H_B)=W_H * [H_A,H_B],\quad W_H\in\mathbb R^{96\times (2H_s)\times1\times1},\quad W_H|_{t=0}=0,
\]

\[
 Y=Y_0(P,Q)+E_s(H_A,H_B),\qquad T_s=\mathrm{RepLocalBlock}\bigl(\mathrm{SiLU}(Y)\bigr).
\]

  **这里没有 γ 参数**；**等价零门就是 `W_H=0`**。与 Run4 `γ(U+V)` 不同，`∂L/∂W_H = (∂L/∂Y)⋆[H_A,H_B]` 在 epoch0 就可能非零，不会因 γ=0 截断新分支梯度；使用 `W_H=0` 而不是“γ=0 且 W=0”，避免双零死锁。若训练首步实际为 0（非空 GT/正常损失下），T4 直接失败。
- DCR 输入还是 `[t1,t2,t3,t4]` 四级 96 通道；跨尺度上采样、`fuse3/2/1`、`block3/2/1`、`refine`、`head` **完全不改**。CAACP `rank/current` 同样完全不动。**没有第三个模型创新**：只是 STR 的 TAR 分支增加一类已有主干 HF 输入代数基。

**训练图**：`TinyViMSlim (2B)` → 4 taps + **只在指定 TViM 捕获 `local_conv(x_high)`** → `TAR.stage{s}.temporal` 的原三支 + `hf_aux=Conv1x1(2H_s→96,bias=False,W=0)` → **原 SiLU/RepLocalBlock** → 原 DCR/head。hook 仅保存 tensor 引用，**不 `.detach()`**；保留梯度回 encoder。**部署图**：同一 encoder 内部读取已经计算的 `x_high`，`torch.cat([P,Q,H_A,H_B])` → **一个 `Conv1x1(2C_s+2H_s→96,bias=True)`** → 原 SiLU/RepLocalBlock（已独立 reparam）→ 原 DCR/head。部署必须删除 `hf_aux` 等训练额外分支，绝无推理 teacher / edge head / FET1。

### 6.2 扩展 TAR 的原位代码修改契约（伪代码为可照抄的接口规格）

**`models/model/str_tar.py::TemporalRep1x1`** 增加状态 `self.hf_channels=0`，新接口 `attach_hf_branch(hf_channels:int, local_seed:int=16)`，只允许在整个老模型（encoder/head/tar/decoder）实例化**结束后**调用；`hf_channels∈{32,84}`；使用：

```python
# attach_hf_branch: 只在 Run5 实验组中调用；旧模型初始化流完全不动
assert not self.deploy and not hasattr(self, 'hf_aux')
with torch.random.fork_rng(devices=[]):
    torch.manual_seed(local_seed)
    self.hf_aux = nn.Conv2d(2 * hf_channels, self.out_channels, 1, bias=False)
    nn.init.zeros_(self.hf_aux.weight)      # 唯一新增零门（直接可获得梯度）
self.hf_channels = int(hf_channels)

# TemporalRep1x1.forward(P,Q,hf_pair=None), 原所有代码原样按相同顺序运行：
y = self.bn_c(self.proj_c(torch.cat([P,Q], 1)))
if self.use_aux:
    y = y + self.bn_s(self.proj_s(P+Q)) + self.bn_d(self.proj_d(Q-P))
if hasattr(self, 'hf_aux'):
    assert hf_pair is not None and hf_pair.shape[1] == 2*self.hf_channels
    y = y + self.hf_aux(hf_pair)            # 新权重=0 → 旧 Y0 逐位相同
return y

# 注意在上述训练分支之前，还必须添加 deploy 入口：
if self.deploy:
    if self.hf_channels > 0:
        assert hf_pair is not None and hf_pair.shape[1] == 2*self.hf_channels
        return self.proj(torch.cat([P, Q, hf_pair], dim=1))
    assert hf_pair is None
    return self.proj(torch.cat([P, Q], dim=1))
# 上述入口应位于 forward 的首行，不得放在训练计算 return 之后。
```

修改 `TARStage.forward(P,Q,hf_pair=None)`：传给 `temporal(P,Q,hf_pair)`，**不要**在 SiLU 之后相加。修改 `MultiScaleTAR.forward(pre_feats,post_feats,hf_pair=None,hf_stage='none')`：仅在 `hf_stage=='2'` 时传给 `stage2`，`=='3'` 时传给 `stage3`，其余保持老路径；`hf_stage` 与模型构造参数相符，`hf_pair is None` 不能静默忽略。

**`models/model/casa_tvim_str_net.py`**：`__init__(..., hf_route='none', hf_stage='none')`，合法 `{('none','none'),('native_localconv','2'),('native_localconv','3')}`；`assert not fine_tap` 与新路由互斥（**不要混 Run4 消融**）。在**已有** `self.decoder=...` 后调用 `self.tar.stage{s}.temporal.attach_hf_branch(...)`（fork_rng）；对于指定 `self.encoder.network[2][-1].op.local_conv` 或 `[4][-1].op.local_conv`：

```python
# hook 必须以 module 参数存放引用，避免 deepcopy 后闭包误指原模型
@staticmethod
def _record_hf(mod, inputs, output):
    assert not hasattr(mod, '_hf_out'), 'stale or reentrant HF capture'
    mod._hf_out = output            # 注意：不 detach，不能改 output

# 在 init 注册：只存 RemovableHandle；不要用 self._hf_mod=nn.Module 注册重复别名
# （直接赋值 nn.Module 会被 PyTorch 登记到 _modules，导致 state_dict 额外别名键）。
def _hf_module(self):
    return (self.encoder.network[2][-1].op.local_conv if self.hf_stage == '2'
            else self.encoder.network[4][-1].op.local_conv)
self._hf_handle = self._hf_module().register_forward_hook(self._record_hf)

# encoder 走完后、tar 前取走。生产实现必须 try/finally 清理，异常也不留 graph 引用
hf_mod = self._hf_module()
hf_2b = hf_mod._hf_out
assert hf_2b.shape == (2*B, HF_CH, S, S)
ha,hb = hf_2b.chunk(2, dim=0)
hf_pair = torch.cat([ha,hb],dim=1)
delattr(hf_mod, '_hf_out')
feats = self.tar(pre_feats, post_feats, hf_pair=hf_pair, hf_stage=self.hf_stage)
```

**P0 注意**：实际生产实现用 `try/finally` 清理 `_hf_out`，且 `forward` 开始 `assert not hasattr(self._hf_module(),'_hf_out')`（不可悄悄使用旧 batch）；**禁止把原有 `nn.Module` 引用赋给模型的普通属性造成重复注册**；T2 必须 assert 原有 `state_dict` 无额外重复 alias key。`deepcopy(model)` 后测试新模型 hook 捕获的是**复制后的 module**。可加 `remove()` 关闭（非本 run 功能）；**不修改 `ss2d.py` 或 `caacp_ss2d.py` 的 forward 计算**，因为 `RepDW` 输出在 module hook 处已经存在。T1 还需检查 Stage3 只选择**最终** TViM，不抓中间 TViM。

**为什么不可将 `HF` 先与 `P,Q` 做非线性注意力门？** 若在投影后生成空间变化权重再乘 feature，`W_H` 不能并入静态 1×1 卷积；因此本轮**没有** edge-gate、softmax 权重或按 GT 选择路径。

### 6.3 完整折叠代数证明（训练多分支 → 推理单 Conv）

对原始 `TemporalRep1x1`（`P,Q` 各 `C`）：先用现有 `str_reparam.fold_conv_bn` 将三分支得到 FP64 `(W_c,b_c),(W_s,b_s),(W_d,b_d)`；`W_c=[W_{cP},W_{cQ}]`。新 `W_H=[W_{hA},W_{hB}]`，无 bias、不需 BN：

\[
 W_P = W_{cP}+W_s-W_d,\quad W_Q=W_{cQ}+W_s+W_d,\quad b=b_c+b_s+b_d,\\
 W_{deploy}=\mathrm{cat}_{in}(W_P,W_Q,W_{hA},W_{hB}),\quad b_{deploy}=b.
\]

于是 `Conv(W_deploy,cat(P,Q,H_A,H_B))+b` 严格对应 `Y0+E`（仅存在浮点舍入差）。**全部 FP64 合并，最后对 `W_deploy,b_deploy` 各 cast FP32 一次**。`hf_aux` 从 deploy 图删除，`self.proj=Conv2d(2C+2H_s,96,1,bias=True)`；`self.hf_channels` 留作非权重元数据，`self.deploy=True`；二次 `switch_to_deploy()` 必须幂等。非注入的 `stage1/3/4` 保持原折叠操作。训练图任何 `SiLU` 都发生在三路与 HF 求和**之后**；若在激活后相加，该折叠公式**无效**，判 `P0_INVALID`。

### 6.4 参数/FLOPs 算式：全部从基线的 `4,880,190` 出发

| 指标 | Pair-2（选 stage2） | Pair-3（选 stage3） |
|---|---:|---:|
| 源 tensor | `2B×32×32×32` → `(HA,HB)` | `2B×84×16×16` → `(HA,HB)` |
| 现有 TAR temporal deploy 输入 | `2C=128` | `2C=336` |
| 新 HF 输入 | `2H=64` | `2H=168` |
| 新 `hf_aux` **训练期**参数 | `96×64×1×1=6,144`；bias 0 | `96×168×1×1=16,128`；bias 0 |
| 新部署参数（仅扩大原 Conv） | `(192−128)×96=6,144` | `(504−336)×96=16,128` |
| **训练图总参数（推算）** | `5,084,017+6,144=5,090,161` | `5,084,017+16,128=5,100,145` |
| **deploy 总参数（明确硬门）** | **`4,880,190+6,144=4,886,334`** | **`4,880,190+16,128=4,896,318`** |
| **剩余 5M 预算** | `5,000,000−4,886,334=113,666` | `5,000,000−4,896,318=103,682` |
| 额外部署 MAC（单时相 pair B=1） | `32×32×96×64 = 6,291,456` | `16×16×96×168 = 4,128,768` |
| 理论 fvcore deploy GMac | `2.6747+0.006291456≈2.6810 G` | `2.6747+0.004128768≈2.6788 G` |

**必审限定**：FLOPs 这里的 `G` 沿用 fvcore 把 Conv MAC 计为 1 的约定；若按“一次乘一次加=2 FLOP”的定义，新增算术 FLOP 约是上述 MAC 的 2 倍。hook、cat、sigmoid、rank 的**rank 只在诊断中用**，部署不含 rank；部署新增 concat 的访存开销不被 fvcore 全部算到 FLOPs。运行 `train.measure_flops(deployed_model,size=256)` 记录 `unsupported_ops` 分类型、对照和实验同套 profiler，**不能把 fvcore 2.68G 当包含全部 selective_scan 的真实算力**。任何实际参数 >5M 立即禁止 80K；**不需降通道，因为两种合法候选均有 >103k 余量**；形状与参数若不吻合不能借口“反正没超”继续。

**禁止的预算偷换**：把训练图总参数 `≈5.09–5.10M` 当部署约束；错。反之，部署 `≤5M` 不等于总模型训练参数可不记录。报告分别记录 train total/train trainable/deploy total/deploy trainable，且独立于 checkpoint 文件大小。

```text

D7: A+B+C全 PASS、四库硬目标全 PASS → PAPER-TARGET-PASS；仍须披露 test-as-val、单seed
```

## §10 机制风险、替代解释与区分实验

| 风险/替代解释 | 与现有事实联系 | 分辨证据/预设量化硬门 | 不满足后的动作 |
|---|---|---|---|
| **R1 `x_high` 主要是背景纹理、配准伪差** | SYSU 变化先验 0.236、ObjP 低；高频≠变化 | G5 `gap≥0.15,CI_low>0.03` + G6 独有率≥0.10；训练后 ObjP≥CTRL、未匹配小 CC≤CTRL×0.95 | **停止高频/边缘线**；不转加 edge map。 |
| **R2 原生 HF 与 norm2/norm4 旧 tap 完全冗余** | 原频域分解已被主干消费并混合 | G6 `novel_rescue≥0.10/CI_low>0.02`，G7 rank margin 改善≥0.02 | 停止；在论文中明确重用不贡献独有信息。 |
| **R3 小对象本身真实变化证据弱，不是下游可读性问题** | Diag1 small margin 递减，但不证明具体漏检对象内部仍能读出 | G4 ≥0.25、G7 margin；32张规则抽样是否集中于高噪声边界 | 前测 FAIL 就只读 FP/GT 结构归因，不做 edge head。 |
| **R4 旧 FET γ 极小只是“双重零门”优化困难** | Run4 γ≈1e−5 | Run5 仅 W_H=0、首步 grad>0；E7 10/100/1000 step `weight_norm` 及 `||E||/(||Y0||+eps)`，1000 步若 **`weight_norm≤1e−8` 或 ratio≤1e−5** 标注 `WEAK-UTILIZATION`（诊断提示，**不提前选择优化器**） | 技术死梯度 P0 修复；数值虽学但最终 B FAIL 仍停止。 |
| **R5 插入后抢占 medium/large 特征** | CAACP 已在 small 与 medium/large 间存在权衡 | B 层 medium、large pooled Recall≥CTRL−0.02；C 层四库 F1 守门 | 机制/守门 FAIL，不试多级补偿。 |
| **R6 本轮只是从 test 标签选择最优层造成选择偏差** | 当前任务已 test-as-val；继续在 test 挑两层会加重 | **只用 train SHA1 10% val 选**、锁 `selection_val.json`，全 test 对选中模型只有一次诊断；test 不切换，gate 全部固定 | 如发现 test 选择/多次调阈值 → `INVALID`。 |
| **R7 Run4 与 Run5 LR/步数/BN 随机性不一致** | Run4 CTRL 与 Run1 历史 F1 已不同 0.2–0.3pp | 同期 CTRL 完整 80K、代码 SHA 配对、每 dataset 六指标；不能只与历史 M1 比 | 任一协议差 → INVALID，不出比较结论。 |
| **R8 推理虽参数小但原生 hook 增加 latency/图编译不稳定** | hook 存活与引用、SS2D 原 kernel 自建 | T1/6/8：100次 eval 取 p50/p95 毫秒，warmup20、batch1、固定 TF32 off、分别 CTRL/E7；**p50 延迟增幅 >5%** 判工程告警 `LATENCY-REGRESSION`；若 forward 错误/状态泄漏则 P0 FAIL | 不更换为动态新模块救指标；报告参数/GMac之外真实延迟。 |

**失败后的替代方向（明确止损）**：Run5 G0–G8 FAIL 或正式层 B FAIL，唯一立即动作是**只读 SYSU FP 空间画像**：借 `tvim_small_error_audit.py` 与 `tvim_object_metrics.py` 按预测 <256px 未匹配组件，计算 `(i) 与 GT 边界距离≤4px 的比例、(ii) 变化图与 A/B 单时相边缘重叠、(iii) 组件面积/纹理能量、(iv) 与错位邻域关系`，按**图像 bootstrap** CI 报告，不增模型不跑80K。若发现结构主要受 1/16→1/32 表征尺度影响，再组织导师会审骨干级改动，**需写明不再保证 ImageNet epoch0 对应**的代价并重新立项；不得冒用 Diag1 过时“信息总量丢失”论据。

## §12 全部显式假设、不确定项、执行前的三项关键核验

### 12.1 所有假设逐项列出

- **A01（代码静态假设）**：`network[2][-1].op.local_conv` 与 `network[4][-1].op.local_conv` 只在对应 forward 调一次；CAACP 的覆盖实现也沿用 `local_conv`。**T1 运行时查 shape/call count，假即停止**。
- **A02（术语限定）**：称 `local_conv(x_high)` 为“原生高频/局部路径”只是沿论文 Laplace mixer 的**架构命名**；它不是带严格频率截止特性的滤波输出。其对 GT 边缘的相关性属于 H5a，前测不通过则不应在论文中宣称高频能救小目标。
- **A03（代码可改动假设）**：把新输入线性基并入 `TemporalRep1x1` 保留了旧 1×1 卷积空间配置；若 `switch_module_to_deploy` 的遍历/嵌套造成早删新权重，T5/T6 立即 FAIL，不通过 `strict=False` 逃避。
