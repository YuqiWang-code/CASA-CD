# CASA-Pyramid Run5：选择性压缩与自参照检索

Run4是保留的正向基线：两版在LEVIR、SYSU、WHU均高于同轮CTRL，CDD基本持平。Run5保持主体、损失和优化协议，检验原型内容选择与query自身竞争能否进一步改善净收益。普通版和双曲版仍为两个独立模型，共四库×三组正式训练。

## 附件问题逐项核对

附件中的Run4 F1差值、LEVIR首层残差比3.575/3.183、CDD普通版前三层1.020/1.207/0.999、guide辅助梯度比例与SYSU后期损失均可由对应日志复现。大幅写回不是失活证据，也不是有害的充分证据。

| 问题 | 核实结论 | Run5处理 |
|---|---|---|
| QKV只能读取TAR融合后的信息 | 数据流事实；不能据此证明TAR丢失了必要信息 | 保留有效主体；不同时改变时相编码器，避免归因混杂 |
| CTRL已有多尺度融合与局部细化 | 正确；新增检索需要提供有效选择 | 用关闭/均匀检索干预检查增量，不以注意力存在证明收益 |
| 两原型仅含均值和guide相关对比方向 | 对Run4线性概率权重成立，忽略epsilon可直接推导；K的Lorentz均值另有非线性 | 改为平方概率选择，提高有限224KV的内容纯度；不声称已保存所有子类型 |
| 完整Q无法恢复KV已混合的细节 | 正确 | 保留完整Q、原TAR与细层局部支路，同时改进KV压缩 |
| 稀疏变化可能被背景数量稀释 | 结构风险已在固定val子集测得，见下表 | 使用区域内概率平方归一化，降低大量低分背景的累计权重 |
| guide同时决定内容与prior，没有独立正确性证据 | 正确；guide高分不等于纠错可靠 | prior称“类别支持度”；增加query自身候选，使距离不匹配时采用比例下降 |
| 模糊区域两原型重复，原prior总量抵消 | 正确：常数p时原两prior之和为1 | 改为二阶支持度，常数p时总支持为p²+(1−p)²；p=.5对应.5，p接近0/1对应接近1 |
| guide辅助梯度有时较大且与主任务冲突 | 指定短训样本可复现：末轮比值2.73/8.40/2.68/3.18；SYSU第2轮约63/65、余弦−.467/−.635 | 保留0.2共同辅助权重并继续测量；这些局部梯度不足以支持减弱整网监督或detach guide |
| 相对写回可能主要依赖负的逐点变换 | 是可检验假设；LEVIR/WHU干预不支持它是主要解释 | 保留检索和相对差值，自身候选使两项系数一致、可按位置缩小 |
| 注意力不同不保证读出内容不同 | 数学上正确 | 新日志分别记录检索RMS、逐点V、减项、读出空间差异及两者余弦 |
| 缺少query级“不采用”选择 | 正确，Run4原型权重总和恒为1 | 每个query加入自身K/V候选，原型权重总和可小于1，无额外门控网络 |
| 欧氏距离受原型范数、尺度语义及位置影响 | 正确性质；未证明是错误来源 | 保留共享Q/K与尺度先验，不同时改余弦距离或加位置偏置；通过更纯净原型减少混合影响 |
| 双曲主要改变关系，V内容仍相同 | 正确 | 改善共同V内容；自参照比较还让绝对几何距离影响上下文采用比例 |
| 双曲空间自动形成四尺度层次 | 没有证据支持 | 不做该宣称、不附加没有任务标注依据的层次损失 |
| Lorentz质心存在额外径向收缩 | 公式正确，正权归一化分母≥1；收缩不等于错误 | 保留合法质心，平方选择减少混合；不把半径强行固定或取消几何约束 |
| 当前半径塌陷或需要可学习曲率 | Run4半径、CV与无裁剪实现不支持塌陷结论；曲率建议缺少依据 | 保留曲率−1、直接Lorentz坐标与稳定平方距离 |
| 几何排序近似、未转化为预测差异 | 实测部分支持：多数top1仍一致，同权距离互换的F1变化很小 | 同时检查内容与query采用量，不靠增加几何运算扩大数值差异 |
| SYSU后期泛化不足 | 明确成立，且CTRL也存在 | 保持Run4共同协议作为对照，记录逐轮损失与best epoch；不预先宣称模块能解决全部泛化问题 |
| CDD缺乏跨尺度交互导致收益小 | 不成立：已有较多跨尺度质量，原始结果基本持平 | 分析传递内容与局部收益，不能简单提高跨尺度权重 |

## Run5公式与数据流

```text
A/B → 共享MobileNetV2 → 四级TAR → T_s
  ├─ 原TAR残差
  └─ X_s=LN(T_s)
       ├─ 完整Q：共享W_qk投影；E欧氏 / H直接Lorentz
       ├─ guide p → 每区域(p²,(1−p)²)归一化选择
       │    ├─ E：池化X → K/V线性投影
       │    └─ H：Lorentz点质心K；相同权重的欧式V
       │    224个跨尺度原型 + 二阶类别支持度
       ├─ 每个query自己的K=Q、V=W_vX
       │    └─ 自身与224个原型联合softmax
       └─ Σ_j A_ij(V_j−V_i) → W_out → gamma_context
  + S1/S2高通DW3/PW1 → gamma_detail
  → DCR → 四级训练/一级预测
```

对于类别隶属度`m=p`或`1−p`：

```text
w_i = (m_i + eps)² / Σ_l(m_l + eps)²
P = Σ_i w_i X_i
r = max(Σ_i w_i m_i², eps), eps=1e−6
```

LN仍位于池化前，w与r都保留梯度。平方是固定的概率选择规则，不是新增特征激活函数。稀疏高置信类别可保持接近1的支持度；均匀模糊区域的两个重复原型总支持低于明确区域。r仍不是独立校准的正确性概率。

普通K为`W_qk P/√16`；双曲K为密集`L(W_qk X/√16)`的同权Lorentz归一化质心。两版欧式V均为`W_v P`。Q保持5440个位置，4头×16维，KV保持128/32/32/32。

```text
l_ij = −d(Q_i,K_j)²/(2 tau²) + log(r_j)
       + scale_bias[head,query_scale,source_scale] − log(M_source)
l_i,self = 0
A_i = softmax([l_i1, ..., l_i224, 0])
g_i = Σ_j=1..224 A_ij = 1 − A_i,self
U_i = W_out(Σ_j A_ij V_j − g_i V_i)
```

自参照项的几何距离恒为0、支持度为1，不需要额外投影、参数或sigmoid门控网络。上述相对读出等价于`W_out(Σ_j A_ijV_j + A_i,self V_i − V_i)`；**减项必须乘g_i**。若候选都远或支持低，g_i下降；所有内容相同时更新仍为0。source-count校正只用于共享压缩池，自身候选不参与源尺度数量校正。gamma仍零初始化，out正常初始化。

双曲版的改变体现在更明确的内容原型，以及相对于自身距离零点的采用决策；不声称它必然优于欧式。没有新增半径目标、可学习曲率、流形V或额外几何链。

## 数据集、历史经验与归因

- LEVIR/WHU：保留已经有效的检索与局部支路，平方分配针对稀疏变化混合，自身竞争减少弱匹配对建筑细节的改写；仍看边界与内部召回。
- SYSU：类别外观多，纯度和采用比例须联合观察。late overfit同时存在于CTRL，Run5不通过改变共同LR/损失来掩盖模块效果。
- CDD：已经有跨尺度交互，重点是季节外观造成的低支持原型及无效改写；不把轻微差异解释为稳定改善。
- 保留Run4的context解耦衰减、共享Q/K、无硬裁剪Lorentz与欧式V。避免旧版弱分支被耦合L2压缩、固定半径、双重零初始化和面积prior抑制小目标。
- Run5不增加参数：H/E训练2.064537M、部署1.953222M、context0.017605M。开销重新实测；效率与精度同时报告。

## 审查与训练

检查范围覆盖压缩/投影交换、稀疏类别、模糊支持度、自身归一化、常量保持、空间与通道reshape、跨尺度梯度、guide梯度、Lorentz公式及同点导数、TAR/DCR折叠与共同初始化。主体卷积、残差、SiLU、concat、RGB读取、同步增强、loss、选模与优化器分组逐项审查，未发现需要与本轮结构一并更改的实质问题。

协议`casa_pyramid_40k_selective_selfref_v5`。Run4共同训练设置不变：batch32、seed2333、Adam全网5e−4、context权重解耦衰减、主分割＋.2guide、40K整epoch。每epoch test/F1选模，正式测试非独立盲测。短训使用train/val，LEVIR两模块各6epoch、SYSU各4epoch；正式使用预训练骨干全新初始化。优先LEVIR→SYSU→WHU→CDD，两GPU按测量显存并行，12项。

## 已知限制

验证干预是固定子集的同权重敏感性，不等于重训消融。平方分配仍依赖guide，高分误报可能被强调；一类一个原型仍无法表达任意多模态。自身竞争不保证任务可靠性，gamma与尺度偏置仍可学习较强写回。辅助梯度冲突、尺度语义对齐及SYSU长期泛化尚未有单独因果结论。单seed、test参与选模与首batch诊断的局限保持明确；正式收益以同轮完整结果为准。
