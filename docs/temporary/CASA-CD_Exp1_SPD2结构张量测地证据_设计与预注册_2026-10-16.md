## 0. 一句话与结论先行

**把每个像素的局部结构张量 J 当作 SPD(2) 流形上的一个点（det=1 切片 ≅ 曲率 −1/2 的双曲平面），
用仿射不变黎曼度量的测地距离度量双时相「结构变化」，作为**参数自由（0 参数）**的几何证据注入
解码器最细尺度。** 该算子对**任意仿射辐射变化严格不变**（命题 2，可数值证伪），
因此直接针对本项目已实测的最强失败模式——FP 区域的原始变化能量**高于**真实漏检小目标。

**为什么值得做**：Diag1/Run5 把 SYSU 小目标瓶颈定性为**判别失败**而非证据缺失
（FP change_abs 0.9730 > 真实漏检 small GT 0.8626 > 背景 0.6063）；
Run4（FET1 末端旁路，raw 证据）与 Run6（读出层门控）已两次证明「再读一路**幅度型**证据」无效。
本算子的区别是：它不是幅度，而是**结构的二阶统计在双曲平面上的距离**，
且带一条可证伪的不变性定理。

## 2. 数学（完整推导见 `models_v1/model/layers/st_geodesic.py` 文件头）

**结构张量（Di Zenzo 矢量版）** `J_t(i) = Σ_c G_ρ * [I_{c,x}², I_{c,x}I_{c,y}; ·, I_{c,y}²]`，
特征值 λ₁≥λ₂≥0 给出「梯度能量 + 主方向 + 各向异性」。

**坐标**（尺度不变、良态）：`z = ((Jxx−Jyy) + 2i·Jxy)/(Jxx+Jyy) ∈ ℂ`，`|z| = κ = (λ₁−λ₂)/(λ₁+λ₂) ∈ [0,1]`，
`arg z = 2θ`（双角度朝向）。对任意 c>0：`J ↦ c²J ⇒ z ↦ z`（**精确**，逐元素比值）。

**命题 1（几何）** det=1 切片在 AIM `⟨V,W⟩_J = tr(J⁻¹VJ⁻¹W)` 下是**曲率 −1/2 的双曲平面**，
拉回度量 **`ds² = 2du² + 8sinh²u·dθ²`**（u = artanh κ）。测地距离闭式：
`cosh(d/√2) = cosh u₁cosh u₂ − sinh u₁sinh u₂cos(2Δθ)`。
⚠️ 陷阱（本文件同时充当反面教材）：常见的 `z = tanh(u)e^{2iθ}` **不是**该度量的等距盘坐标
（其诱导度量为 `4du²+16tanh²u dθ²`，仅在 cosh u = 2 时成比例）；直接套 Poincaré 盘距离公式
会系统性偏离真实 AIM 距离（实测最大偏差 **1.25**，随各向异性单调增大）。单测 T1b 专门守这条。

**命题 2（不变性，可证伪）**
  (i) 纯增益/对比度 `I_B = c·I_A ⇒ J_B = c²J_A ⇒ d_shape = 0`（精确）；
  (ii) 纯偏置 `I_B = I_A + d ⇒ d_shape = d_scale = 0`（精确）。

**命题 3（分解）** `d²_AIM(J₁,J₂) = d²_shape(Ĵ₁,Ĵ₂) + 2(log σ₁/σ₂)²`，`σ = √(det J)`
⇒ 形状（抗辐射）与尺度（对真实变化敏感但**不**抗辐射）正交，二者一起给网络。

**数值纪律（逐条都有实测支撑，见单测）**：
1. 恒等附近 d 按 √ 放大 ⇒ 改用**平方量之和** `W = sinh²(Δu/2) + sinh u₁sinh u₂ sin²(Δθ)`，
   `d = √2·arccosh(1+2W)`，在恒等附近**线性**；
2. 朝向项必须有理化：`(1−cosΔφ)/2` 在 Δφ→0 时被 FP32 抵消吃掉（实测假距离 2.6e-3）
   ⇒ 用 `s²/(2(1+cosΔφ))`（s² 由叉积直接给出），且**必须区分 cosΔφ 符号**
   （误用 |cos| 会得到 (1−|cos|)/2，实测 z₁=(−0.4,0.2)/z₂=(0.1,−0.6) 时 0.8435 vs 正确 1.5184）；
3. κ 截断 `KAPPA_MAX = 1−1e-3`（κ→1 处 det 灾难性抵消 + artanh′ 放大）；
4. 距离死区 `d < 1e-3` 记 0（量程 0–8 的 0.0125%）。

**验收（`models_v1/test_st_geodesic.py`，20/20 全过，服务器与本地都跑）**：
T1 生产实现 == eigh 参考（5.7e-5）· T1b 错误公式被判不一致（1.25）· T2a/T2c/T11 纯辐射变化下
d_shape **恒为 0**（含 κ→1 最坏条纹图）· T4/T4b 分解恒等式与 τ 参考一致 · T7 解析特例 √2·u ·
T8 梯度有限非零 · T12 8×8 真实结构变化 ⇒ d_shape = 1.06。

## 6. 预注册判据（**见结果之前冻结，不得事后放宽**）

**A. 机制自检（必须全过，否则本轮判 `INVALID`）**
1. `[PRETRAIN-LOAD] worst_diff == 0`（VMamba 官方权重逐位加载）；
2. epoch-0 与 `CTRL_R8` **逐位相同**（已实测 True）；
3. train↔deploy 二值 disagreement == 0，或非零但附 `KNIFE_EDGE_ARTIFACT` 证据（Run7 §7.6 同一判据）；
4. 最后一个完整 TEST 区块含 `[ACTUAL-OPT-STEPS] 80000` 与 `[PROTOCOL-VERSION]`；
5. **`[STGEO-GAMMA]` 不得为「休眠」**：|γ| < 1e-4 时本臂判 **MECHANISM-DORMANT**（见 §7-F1）。

**B. 接受标准（`primary`，两库口径）**
`STG_INJ` 满足：**LEVIR 与 SYSU 的 F1 均 ≥ 同期 CTRL_R8**，且 **SYSU F1 严格 > CTRL_R8**，且 A 全过。
（即原"≥3/4 库 + SYSU 严格提升"在 2 库上的严格化：不允许任何一库退步。）

**C. 守门（沿用已冻结口径，不新造阈值）**
F1 降幅 ≤ **0.002**（原作用于 CDD/WHU，此处对称应用到 LEVIR/SYSU）；
中大对象（≥256px）pooled Recall 降幅 ≤ **0.02**。

**D. 机制证据（只作归因，不参与判定）**
LEVIR/SYSU small(1–255px) pooled Recall 与 Hit@25；未匹配 <256px 预测连通域数量；ObjP/ObjR。

**E. 可证伪预测（写在结果之前）**
P1 LEVIR（小目标 + 极不平衡、阳性稀疏）受益于**边界/结构**通道：F1 上升且 Precision 不下降；
P2 SYSU（变化密集、辐射伪变化多）受益于**不变性**：未匹配 <256px 预测数下降；若上升，
   说明几何证据在放大噪声，不变性叙事被数据否证；
P3 两库 small pooled Recall 至少一库上升 ≥1.0pp，否则"结构证据救小目标"被否证。
