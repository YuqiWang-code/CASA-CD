# 双曲半径线：仿真结论与下一步改码准备（2026-11-26）

配套仿真目录：`docs/simulation/radius_semantics/`（`results/SUMMARY.md` 是结论汇总，
`results/decision_table.md` 是判定表）。本文只写"这些结果对改码意味着什么、下一步怎么动"。

---

## 1. 这次仿真确定了什么（可以当既定事实用）

1. **半径 = 投影后向量长度，没有别的信息**：`d(0,π(z)) = asinh‖z‖` 误差 0.0e+00；
   我们模块里 ρ = `asinh(‖qk(LN(x))‖/√32)`，LN 在前 ⇒ **对输入强度/对比度免疫**
   （残留只来自 `LayerNorm(eps=1e-5)`，eps=0 时严格为 0）。
2. **半径承载的是"形状与权重的吻合度"**：天花板 `asinh(σ_max√(C/D)) = 1.093`，
   随机方向典型值 0.5437，而 12 个真实权重的 Q 半径中位数 0.5435 —— **和随机方向一样**，
   说明训练并没有把像素"推远"。参数 α（沿 W 顶奇异方向的能量占比）从 0→1 时 ρ 从 0.540→1.093。
3. **近/远不是"变化/背景"**：四个真实数据集上背景与变化的 ρ 中位数只差 0.004–0.008，
   只用 ρ 判变化的 AUC 0.508（CDD）–0.601（SYSU/SYSU 0.601）。半径地图上"亮"的是纹理与边缘。
4. **角度可分辨量有硬上限 C = 2·min(ρ_Q, ρ_K)**（误差 1.8e-14）。实测 (0.470, 0.345) ⇒ 只剩 73%。
   这一缩水由"池内方向相关 c"决定：`ρ_K = asinh(A·sinh ρ_Q / √(cosh²ρ_Q − A²sinh²ρ_Q))`，
   `A = √(c+(1−c)/n)`；由实测反解 c(n=1024) ≈ 0.573。**与池大小 n 几乎无关**（n=64 只让 ρ_K 从 0.345 到 0.347）。
5. **五种池化算子差别可忽略**：层级顶层保留率 55.2%（我们的 Minkowski 均值）vs 55.6%（OEM p=2），
   检索 top-1 差 0.002–0.009。OEM 只有在池内半径 cv 很大时才有用，实测 cv≈0.13–0.15 ⇒ OEM 只 +0.1%~+0.6%。
6. **几何改动的收益上限 = 排序翻转率**：实测 cv≈0.145 时测地↔欧氏 top-1 翻转率 2.3%
   （800 次里 18 次）；同半径重锚连 argmax 都不改（99.1%–100% 不变）。
   同协议重跑噪声 σ=0.39pp ⇒ **< 0.8pp 的改动不可区分**。
7. **跨尺度是半径唯一"有作用"的地方，但那里已经有偏置**：4 尺度键半径 [0.15 0.25 0.35 0.47] 时，
   误到别的尺度 26.0% → 半径重锚 21.6% → 只用一个每尺度常数偏移 22.8%（差 1.2pp）。
   而模块里 `scale_bias(heads,4,4)` + `source_bias=−log count` 正是这一族参数
   （旧仿真测到它们吸收 92.6%–93.6% 的壳层 logit 偏移）。

---

## 2. 因此，三条"看起来像创新"的路都不做

| 路线 | 为什么不做 |
| --- | --- |
| 给键加**径向重锚**/可学习半径（M1） | 能把角度对比度 73%→100%（s*=1.95），但 top-1 −0.001；同半径时 argmax 不变；跨尺度部分与 `scale_bias` 重复 |
| 把池化换成 **OEM / Einstein** | 半径只多 0.1~0.6pp，top-1 差在噪声里；0 参数也不值得引入新算子 |
| **拆开 Q/K 共享 qk** | 可让 ρ_K 独立增大 36%，但收益仍受翻转率约束；先要证明"跨尺度误配"是瓶颈（目前没有证据） |

如果仍想给径向自由度，"唯一有信息量"的形态是**跨尺度**的（4×4=16 个偏置），
而它已经在 `scale_bias` 里了 —— 再加就是重复计数，还会在参数表上多出无法归因的行。

## 3. 下一步该动的地方（按性价比排序）

### P0：把"内容"这条线做实（已有实现，缺复现与归因）

- 现成开关：`--module manifold`（`ManifoldContext`，K/V 从 `difference` 流池化，0 新增 KV）。
- 旧仿真（H2）给出 **+22.84±7.92 pp（p=7.5e-10）**，远大于 0.8pp 的噪声地板，这是目前唯一"值得花 GPU"的候选。
- 需补的实验：LEVIR 2 seeds（Run10 只跑了 SYSU 侧的 12 项）；
  并把 `--module hyperbolic`（K/V 来自归一化特征）作为同参数对照，保证只有"内容来源"不同。
- 验收（AGENTS.md 硬性项）：训练/部署参数量、部署折叠一致性 ≤2e-4、no-op 守卫（输出必须与对照不同）、
  被替换层梯度非零、test 侧 per-image TP/FP/FN；`selection_split` 写进 manifest。

### P1：逐像素支持度（0 参数，但需先证明没被吸收）

- 机制菜单里的吸收指数 A = mean_{Ω+}(a − q)；预注册判据 A(LEVIR) − A(WHU) ≥ +0.10 才算有效。
- 仿真侧已能算（`support` 与 `radius` 的可分性），**但真实值必须从权重 diag 里测**：
  在 `collect_diag` 里加一行 `support_mean`（1 行代码，+0 参数），跑 1 个 epoch 的 diag 即可。

### P2：结构清理（0 风险）

- τ：AUC 对 τ 严格不变（S 系列旧 H4：0.00e+00），BCE 会把 τ 吸收进 bias ⇒ 冻结或删除。
- 曲率：AUC 随 c 单调下降（0.8311@0.25 → 0.7516@4）⇒ 固定 −1，不引入可学习曲率。
- `lift`/`radius_mode` 的字符串分支可以收敛为一个函数（纯重构，不改行为）。

## 4. 还需要（只能上服务器）的仿真

本地没有训练权重，所以下面两项只能读 diag，不必重训：

1. **真实 logits 上的 D0 门**：从已有 Run9/Run10 的 diag 里取 `radius`、`key_radius`、
   `radial_gap_attention_mean`，算 top-1 翻转率（测地 vs 欧氏 logits，bootstrap 95% CI，800 张 val）。
   判定：<10% 关闭所有径向机制；10–25% 只留 M2；≥25% 才允许排队。
   本地仿真给的上界是 2.3%，预期 D0 会关闭。
2. **per-scale 键半径**：`collect_diag` 目前只记全局 `key_radius_mean`。加 `key_radius` 的 per-scale 版本，
   验证"半径按尺度分层"是否真的存在（旧合成实验显示半径编的是 cell 内像素数，不是感受野）。

## 5. 一句话给决策

**半径这条线到此为止**：几何自由度能改变排序的比例只有 2.3%，任何"改几何"的改动都进不了可测区。
把预算放到 **KV 内容（差分原型）** 与 **支持度** 上；`τ`/曲率/`lift` 可以顺手冻结清理。
