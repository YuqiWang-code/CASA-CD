## 10. 对下一轮（Run4）的建议（§14.4；**已按 §11 的 S1 证据重排**）

**主方向（零 80K，优先级最高）：把小目标分层评价接入 probe —— 回答"为什么整体可读性 0.90、小目标召回却只有 0.20"。**
- 机制问题：现有 pooled probe AP 是**像素加权**的（大目标主导像素数）。§11 显示 1/16–1/32 的整体可读性已达 0.79–0.83，而 D1 显示 small(1–255px) pooled pixel Recall 仅 0.1974。两者并不矛盾：**"变化整体可分"与"小变化可分"是两个不同命题**，必须按 GT 面积分组重算 probe AP / 分数 margin 才能定位。
- 做法（复用已保存的 `probe_*_PROBE_ONLY.pth`，无需重新拟合）：对 `L05/L06b/L07/L08b/DOUT/P00` 各跑一次分层的 test 评估，输出 `small vs 背景`、`medium vs 背景`、`large vs 背景` 三组 AP 与 per-object margin，并做 image-level bootstrap。
- 成本：约 5–10 分钟 GPU，零训练 80K，零结构改动。
- 决策价值：若 **small 组 AP 在 1/16–1/32 明显低**（例如 <0.3）⇒ 瓶颈在"小变化的可读表示"，指向细尺度证据强化；若 **small 组 AP 也高**（≥0.5）⇒ 瓶颈在**决策/读出阈值行为**（大量小 FP 碎片 + 漏检并存），指向决策路径而非特征。

**候选 A（条件：分层 probe 显示 1/16–1/32 的小目标可读性显著低于其中/大目标）——细尺度变化证据的"保留式"接入。**
- 直接证据：D1（small 65pp 落后）、§11（1/4–1/8 的整体可读性最低：0.547/0.623，而决策路径偏好 0.79–0.91 的粗尺度）。
- 机制要求：把 1/4–1/8 的双时相差分证据以**可折叠、零初始化门控**的方式送入 DCR 的 64² 层级（`γ=0` → epoch-0 逐位一致），deploy 增量必须 ≤5M、FLOPs 增量实测。
- 与 E5_FS-TAR 的区别（E5 已 FAIL）：E5 只改了 1/4 处**时相代数的核形状**（1×1→3×3），未改变"细尺度证据是否进入决策路径"；本条要求的是**显式接入 + 零初始化门控**，且需先用分层 probe 证明细尺度小目标信息确实可读。
- 失败判据：SYSU small pooled Recall / Hit@25 无提升，或 CDD/WHU 任一低于 97.18/95.07，或 deploy 超 5M。

**候选 B（条件：分层 probe 显示小目标可读性已足够高）——决策路径的尺度平衡（不动特征，改融合权重分配）。**
- 直接证据：§11 的 1/32 `L07`(0.8286) → `L08b`(0.6744) 同分辨率 **−0.155** 是全编码器最大跌幅，说明 stage4 blocks+norm 降低了线性可读性；同时 decoder/head 达 0.905（由粗尺度特征主导）。
- 机制：让 DCR 在 64² 层级对细尺度 t1（1/4）证据的利用可学习、可折叠、零初始化（不改 TAR 代数形式），从而让决策同时依赖细/粗证据。
- 失败判据：同候选 A；此外若 small 与 large 召回同时下降 ⇒ 融合权重假设错误，停止该线。

**明确不建议（基于本轮证据的否定清单，已更新）**
- **S2-HCAACP（CAACP 前移 Stage2）**：动机"Stage3 CAACP 伤害 small"已被正确指标否证（paired Δrecall 小目标 +1.2~+1.4pp）；且 §11 显示 CAACP 边界仅 −0.04 AP。
- **"1/16→1/32 信息衰减"驱动的任何改动**：§11 已否证该 proxy 推断（L07 是最可分层）。
- **SP-DCR（删末端 DW3）／Fine-STR r24→48／FRH 类再锐化**：D3/§11 未显示读出瓶颈（head = decoder = 0.905）。
- **任何 β / score 归一化再调参**：D4 显示 β 修正幅度 0.19%，关掉它 ΔF1≈−2e-6。
- **多 seed / 阈值 / loss / 增广**：仍在固定协议禁止范围内，本轮未触碰。

   - `L07 → L08b`（stage4 blocks + norm6，1/32，**同分辨率**）：**−0.1542**（0.8286→0.6744），是编码器路径中**最大的同分辨率可读性下降**，且此前未被任何诊断捕获。
   - 之后 TAR/DCR 又把可读性抬回 0.905（decoder/head），故**输出端仍不是瓶颈**。

4. **仍未回答的关键问题（转为下一轮首要补证）**：上述 probe AP 均为**像素加权 pooled AP**，由中/大目标主导；因此"整体可读性高"与 D1 的"小目标召回 0.1974"并不矛盾。必须以 **GT 面积分层的 probe 评价**（small/medium/large 各自 vs 背景的 AP 与 per-object margin）才能判定瓶颈在"小变化的可读表示"还是"决策路径"。这一项使用已保存的 probe 权重即可完成（零拟合计时主要花在 test 前向）。
