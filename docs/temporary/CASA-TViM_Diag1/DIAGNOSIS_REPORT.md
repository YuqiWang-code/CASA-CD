   - 容量口径说明：concat 输入通道为 3C（容量更大）。但 1×1 conv 在 `abs(F_A−F_B)`（C 维）上本就能实现该差分向量的任意线性泛函；concat 额外提供的正是**每时相特征自身**（而非仅其差）。故 +0.26AP 主要归因于"时可分信息可用"，而非单纯通道数（已在 `probe_protocol.json:capacity_caveat` 标注）。

2. **D2 的"1/16→1/32 首次稳健衰减"推断被否证（proxy 失效）**：cosine proxy 显示该边界 pooled AP 0.578→0.340（−41%），但**同层的可学习 probe 显示 1/32 的 `L07` 是全编码器最可分节点（0.8286 > 1/16 的 0.7893）**。按文档 §6.4"若 S0 与 S1 相反，优先认定表示方式变化/原始 proxy 失效"，**该边界不得再被写成信息丢失**；D2 的 `stage_profile` 仅作为"cosine 表示方式的层间差异"保留。

3. **同分辨率内仍有两处 S1 级下降（新证据）**：
   - `L05 → L06b`（CAACP 所在块，1/16）：absdiff −0.0363、concat **−0.0387** ⇒ 两口径同向、幅度小（≈0.04），是**稳健但有限**的可读性下降；但由 D4/内部统计，**与 β 修正项无关**（`||βΔC||/||c_avg||=0.19%`，β 置零 ΔF1≈−2e-6）。
   - `L07 → L08b`（stage4 blocks + norm6，1/32，**同分辨率**）：**−0.1542**（0.8286→0.6744），是编码器路径中**最大的同分辨率可读性下降**，且此前未被任何诊断捕获。
   - 之后 TAR/DCR 又把可读性抬回 0.905（decoder/head），故**输出端仍不是瓶颈**。

4. **仍未回答的关键问题（转为下一轮首要补证）**：上述 probe AP 均为**像素加权 pooled AP**，由中/大目标主导；因此"整体可读性高"与 D1 的"小目标召回 0.1974"并不矛盾。必须以 **GT 面积分层的 probe 评价**（small/medium/large 各自 vs 背景的 AP 与 per-object margin）才能判定瓶颈在"小变化的可读表示"还是"决策路径"。这一项使用已保存的 probe 权重即可完成（零拟合计时主要花在 test 前向）。

**对 §10 的影响**：原"主方向 = 补 concat 口径"已完成；**新的主方向改为"分层 probe 评价"**，候选 A/B 的取舍由其结果决定（见 §10 更新版）。

## 12. D3c：分层 probe 可读性（SYSU，concat 口径，4000 张 test，图像=抽样单位）

**目的**：D3 的 pooled AP 是**像素加权**的（被大目标主导）。本阶段把 probe 按 GT 面积分层评价，回答"probe 能否读出**小**变化"。
**口径**：正样本=指定面积组像素；负样本=全部背景像素（GT=0，其它 GT 对象像素剔除）；AP 由 2000-bin 直方图累计
（分母 = 正样本 + 背景，避免 >1 伪值）；margin = 对象内 probe 概率均值 − 外侧 4px 环带均值。

**结论（[F] 数值 + [I] 推断）**
1. **[F] 整体可读性几乎完全由大目标贡献**：`large vs 背景` AP ≈ pooled AP（如 1/16：0.7893 vs 0.7893；1/32：0.8296 vs 0.8286），
   而 **small vs 背景 AP 仅 0.00045–0.00428**。小目标正类先验为 35,837 / 189,325,618 ≈ **1.89e-4**，故 small AP 仍高于随机基线
   约 2.4–22 倍，但绝对可分性比大目标低 **3 个数量级**。
2. **[F] small margin 随深度单调坍塌**：1/4 **0.0779** → 1/8 0.0400 → 1/16 0.0238 → 1/16(CAACP 后) 0.0152 → 1/32 **0.0022**；
   而 large margin 反升（0.1208 → 0.2098 → 0.1668）。**small/large margin 比从 0.64 掉到 0.013**（1/32），决策头 P00 为 0.075
   （small 0.0281 vs large 0.3732 ⇒ **13× 失衡**）。
3. **[I] 因此"变化信息不足"与"输出端不足"都不是答案**（§11 已排除），真正的结构事实是：
   **表示的尺度选择性——浅层（1/4–1/8）对小/大变化可比（margin 比 0.64/0.29），而决策所依赖的深层（1/16–1/32）对小变化几乎不可读（比 0.013–0.11）。**
   这直接解释了 D1 的 small pooled Recall 0.1974 与大量小 FP 碎片（小变化在决策特征里既弱又不稳定）。
