# 参考文献索引（CASA-CD）

> 本目录存放 CASA-CD 普通RGB全监督二值变化检测的调研文献PDF；当前部署约2M参数，准确率与实际推理开销共同评价。
> 最新定向检索：2026-10-26；历史分组保留原检索范围。检索原则：2024–2026 为主体，优先 CCF-A（CVPR/ICCV/ECCV/AAAI/
> NeurIPS 等）与权威 SCI（Pattern Recognition / IEEE TGRS / ISPRS JPRS）；
> 会议与期刊层级分开标注；只采用出版社、CVF/ECVA/AAAI 官方页、arXiv、官方
> GitHub 可核验的信息（不用盗版源）。
> 当前定向调研见[CASA-Pyramid Run4](Run4_压缩与双曲检索/README.md)；历史设计记录位于`docs/temporary/`。

## 目录结构

| 文件夹 | 含义 |
|---|---|
| `baseline/` | 骨干、训练策略及压缩注意力参考，包括WDMF-Net、SAT与历史ChangeViT |
| `Run4_压缩与双曲检索/` | 2026-10-26新增：直接Lorentz坐标、数值稳定、轻量变化表达及细节融合，共5篇开放全文 |
| `2024-2026主证据/` | 2024–2026 主证据（CCF-A 会议 / 权威 SCI 期刊） |

status。SAT 官方 GitHub 标注为 `CVPR 2026 Findings`（arXiv 2604.07994），
正式论文引用时**不写 main-track**。
