# 参考文献索引（CASA-CD）

> 本目录存放 CASA-CD 课题（极轻量遥感二值变化检测，<3M 参数）的调研文献 PDF。
> 检索截止 2026-10-01；检索原则：2024–2026 为主体，优先 CCF-A（CVPR/ICCV/ECCV/AAAI/
> NeurIPS 等）与权威 SCI（Pattern Recognition / IEEE TGRS / ISPRS JPRS）；
> 会议与期刊层级分开标注；只采用出版社、CVF/ECVA/AAAI 官方页、arXiv、官方
> GitHub 可核验的信息（不用盗版源）。
> 调研结论与创新空白分析见 `docs/temporary/` 下各 Run 决策文档（Run5–Run7）。

## 目录结构

| 文件夹 | 含义 |
|---|---|
| `baseline/` | CASA-CD 基线论文（ChangeViT 及其创新点来源 SAT） |
| `2024-2026主证据/` | 2024–2026 主证据（CCF-A 会议 / 权威 SCI 期刊） |

**层级标注约定**：`CCF-A` = CVPR/ICCV/ECCV/AAAI/NeurIPS 等顶会（本项目沿用
STR-RepNet 的约定口径）；`SCI` = Pattern Recognition / IEEE TGRS / ISPRS JPRS
等权威期刊；预印本/非主会明确写 `Preprint` / `Findings`。注意：ECCV 在 CCF 官方
目录中为 B 类，此处按项目统一口径与顶会并列，写作时按需核对最终 bibliographic
status。SAT 官方 GitHub 标注为 `CVPR 2026 Findings`（arXiv 2604.07994），
正式论文引用时**不写 main-track**。
