# Sources

CASA-Pyramid uses native MobileNetV2 feature extraction adapted from [WDMF-Net](https://github.com/LYT-Works/WDMF-Net), reference revision `453c5493b2aab88c908ced9135b677285059ec70`. The reference implementation remains in `others/WDMF-Net`. HFEA is absent from this architecture. The backbone ends at the last used 320-channel feature; the pretrained 1280-channel tail and classifier are not loaded.

TAR performs temporal fusion and channel projection. DCR provides foldable decoding. `PyramidContext` implements a shared four-scale prototype pool after TAR, with complete spatial queries and compressed keys/values. The asymmetric query/context principle follows [SAT](https://arxiv.org/abs/2604.07994). The current layout uses 224 prototypes (128/32/32/32), a shared Q/K projection, Euclidean values, and class-support priors `r = sum(m²) / sum(m)`. Supervised change/background assignments, support-weighted retrieval and the matched Euclidean/hyperbolic variants form this project's experimental design.

[Object-Contextual Representations for Semantic Segmentation (ECCV 2020)](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123510171.pdf) provides a reference for supervised soft-region feature aggregation. The class-support formula above is developed for this project's prototype retrieval.

Poincare geometry and clipping refer to [Hyperbolic Neural Networks](https://arxiv.org/abs/1805.09112), [Hyperbolic Attention Networks](https://arxiv.org/abs/1805.09786) and [Deep Change Monitoring](https://arxiv.org/abs/2503.00643). These references motivate the geometry; they do not establish this model's detection accuracy. Training source and configuration archives accompany each experiment round.

The [official ChangeMamba implementation from June 2024](https://github.com/ChenHongruixuan/ChangeMamba/blob/72597fa4a1fde0bffa94c94302a6dc848898be13/changedetection/script/train_MambaBCD.py#L115-L131) evaluates the test split every 500 steps and selects checkpoints by Kappa. CASA-Pyramid Run2 uses test-based checkpoint selection with evaluation every epoch and selection by F1. Its final test evaluation is therefore not an independent held-out evaluation. Earlier validation-selected results retain their original protocol labels.
