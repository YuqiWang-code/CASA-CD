# Sources

CASA-Pyramid uses native MobileNetV2 feature extraction adapted from [WDMF-Net](https://github.com/LYT-Works/WDMF-Net), reference revision `453c5493b2aab88c908ced9135b677285059ec70`. Core reference code remains in `others/WDMF-Net`. The backbone ends at the 320-channel feature; the unused 1280-channel tail and classifier are not loaded. TAR performs temporal fusion and channel projection; DCR provides foldable decoding.

The current paired contexts follow the project's [Run3 design](../docs/temporary/CASA-Pyramid_Run3_design.md). Both receive corresponding encoder A/B features and TAR features. The complete-query/compressed-context arrangement refers to [SAT](https://arxiv.org/abs/2604.07994). [Object-Contextual Representations for Semantic Segmentation](https://www.ecva.net/papers/eccv_2020/papers_ECCV/papers/123510171.pdf) provides background for supervised soft-region aggregation.

`paired_euclidean_context.py` implements separate regional-mean and change-contrast banks, independent Q/K projections and dense paired-difference detail. `paired_hyperbolic_context.py` implements paired midpoint/common-tangent differences, aligned uniform/change prototypes and joint geometric retrieval with Euclidean values. The token construction, fixed unit pseudocount in the Euclidean contrast bank, paired retrieval and supervised detail paths are this project's design, not components attributed to the cited reference implementations.

Poincare maps and tangent clipping refer to [Hyperbolic Neural Networks](https://arxiv.org/abs/1805.09112), [Hyperbolic Attention Networks](https://arxiv.org/abs/1805.09786) and [Deep Change Monitoring](https://arxiv.org/abs/2503.00643). `lorentz_pair_ops.py` implements curvature−1 Lorentz inner products, the exact equal-weight two-point midpoint, logarithmic residuals and parallel transport to the origin. Regional key compression uses a normalized Lorentz weighted sum; it is not presented as an exact arbitrary multi-point Fréchet mean. These mathematical tools do not establish a detection advantage without matched experiments.

Run3 adds boundary supervision from the change mask and a 0.1 learning-rate multiplier for the pretrained backbone. Main segmentation, guide and boundary losses have coefficients 1, 0.2 and 0.05 respectively. The boundary label is a replicate-padded 3×3 morphological gradient, max-pooled to each supervised feature footprint. These are training support choices rather than claimed geometric innovations.

The [official ChangeMamba implementation from June 2024](https://github.com/ChenHongruixuan/ChangeMamba/blob/72597fa4a1fde0bffa94c94302a6dc848898be13/changedetection/script/train_MambaBCD.py#L115-L131) evaluates the test split every 500 steps and selects checkpoints by Kappa. CASA-Pyramid Run2 and Run3 evaluate every epoch and select by F1. Their final evaluation is test-selected, not an independent held-out evaluation. Earlier validation-selected results retain their original protocol labels. Actual training source and configurations are archived for each experiment round.
