# CASA-Pyramid

共享MobileNetV2原生四尺度(24/32/96/320通道) → TAR时相融合至64通道 → 联合跨尺度QKV → DCR → 共享预测头四级输出。骨干结束于320通道，HFEA不参与该模型。

当前工作代码使用`grid_sizes=(8,4,4,4)`，对应每尺度KV数`(128,32,32,32)`，联合224个KV。已完成的CASA-Pyramid/Run1为历史128-token版本，其正式结果与冻结源码保留，本方案已作为CASA-Pyramid/Run2启动，实际源码基线`986fe75`。

## 224个跨尺度KV

`model/layers/pyramid_context.py`实现欧氏Q/K、双曲Q/K和CTRL三种模式，两种注意力模式都使用欧式V。共享LayerNorm与65参数评分头预测变化概率；每个区域构造变化/背景两个原型，同一套可微分配权重用于K/V。细尺度分为8×8个区域，其余三尺度为4×4。Q保留5440个位置，四头、每头16维，每个头访问全部224个原型。Q/K/V与输出投影跨尺度共享，保留每头4×4尺度偏置与每尺度零初始化gamma。

| 尺度 | 特征尺寸 | 网格 | 每区域特征大小 | KV数 |
|---|---|---|---|---:|
| 1 | 64×64 | 8×8 | 8×8 | 128 |
| 2 | 32×32 | 4×4 | 8×8 | 32 |
| 3 | 16×16 | 4×4 | 4×4 | 32 |
| 4 | 8×8 | 4×4 | 2×2 | 32 |

普通版：`X=LN(T)` → 变化/背景加权池化 → 共享线性K/V投影并拆头，均除以sqrt(16)。Q仍在完整特征上投影。固定相同分配时，池化与无偏置线性投影交换保持前向和梯度等价；分配权重保留梯度，LayerNorm位于池化之前。以负欧氏距离检索，用`A @ V`读出内容。

双曲版：Q为`投影→拆头→Exp`；K为`投影→拆头→Exp→Lorentz质心压缩`；V为`LN特征池化→欧式线性投影→拆头`。双曲距离/2参与注意力计算，内容直接由`A @ V`欧式聚合。V不经过Exp、Lorentz转换、几何质心或Log。双曲曲率固定-1，切空间截断2.3，复用原poincare_ops.py公式。

两版logits均增加`-log(M_source)`，按128/32/32/32扩展。各尺度相似度相同时，总注意力先验各占1/4；可学习尺度偏置继续表达尺度偏好。拼接四头后输出投影，`T + gamma * update`残差回接；out正常初始化、gamma初始化为0，没有额外局部分支。

CTRL保留共享归一化、评分头和辅助监督，直接将TAR特征送入DCR。标签面积平均至四个评分分辨率，仅用于BCEWithLogits；原型分配始终用预测概率。总损失为四级BCE+Dice求和，加0.2倍四级评分BCE求和。

## 优化与诊断

入口`train_CASA.py`；`forward(a,b)`返回四级预测，`return_aux=True`额外返回四级评分logits。协议`casa_pyramid_40k_qk_euclideanv224_v2`。仅context.q/k/v/out的四个投影weight采用WD1e-4；context其他参数（评分头、LayerNorm、温度、gamma、尺度偏置）WD0；网络其余参数仍WD1e-4。CTRL的context没有四个投影，其评分头与归一化仍WD0。训练manifest记录网格、各尺度KV数、Q/K几何、V模式及精确的投影衰减参数名。

诊断按实际KV分段统计四尺度注意力质量，保留熵、温度、gamma、原型分配TV及双曲半径等。新增`feature_rms`、`residual_rms`与`residual_to_feature_rms=RMS(gamma*update)/RMS(T)`。`query_attention_tv`为同一图像/头内各query的注意力分布相对query平均分布的平均总变差距离，0表示各位置使用同一分布；`query_attention_tv_per_head`分别记录四个头。诊断只观测，不改变前向结果。

骨干预训练、四级主损失、评分监督0.2、40K预算、seed2333与独立验证选模保持一致。TAR具有有序时相输入，整网不声称严格交换不变或相同输入恒零。

参数不增加：CTRL训练2,047,125/部署1,935,810；两个QKV均训练2,063,581/部署1,952,266。`profile_CASA.py`使用同一模型与优化器配置测量batch32的峰值显存和步耗时，报告协议、网格与V模式。旧Run1脚本对应v1协议；本方案脚本位于train_scripts/CASA-Pyramid/Run2，不能用旧脚本覆盖历史运行。

## 代码检查与性能测量

等价性检查覆盖普通K/V池化前后顺序的前向值及输入、分配权重、投影权重梯度；尺度先验检查覆盖均等相似度下四尺度各1/4，以及可学习偏置仍能改变偏好。双曲值路径检查验证不受球半径约束的欧式V被直接加权读出。四级形状、跨尺度任务梯度、残差恒等、优化器分组、恢复及TAR/DCR折叠检查通过，三种模式二值预测差异均为0。

RTX5090，LEVIR真实训练batch32、256×256，FP32，单进程：同步计时6个优化步，前2步预热，后4步取平均。context配置和优化器与训练入口一致。峰值分配显存不含CUDA进程开销；保留显存为PyTorch缓存分配器峰值。测量只用于资源评估，不作为正式训练或指标。
